# 就业指导

用目标岗位的要求逐项核对已有经历，形成岗位选择、简历修改和求职行动建议。可以只修改一条项目经历，也可以生成完整的就业指导报告。

## 准备一组可以对照的材料

1. 提供目标地区、求职阶段和岗位，例如「广州、应届、软件测试」。
2. 贴一份岗位描述，保留必需条件与优先条件的原文。
3. 上传匿名简历或粘贴项目经历，说明你本人承担的任务、成果和可核实的材料。再写出时间、通勤等会影响选择的限制。

> 我准备在广州找软件测试实习，附件是匿名简历和两份 JD。请比较哪份岗位更符合我现有经历，改写一条项目描述，并给出未来两周每天可检查的准备动作。

## 怎样用结果

正式报告以 HTML 交付。先看「结论与优先动作」，再读岗位匹配和简历修改建议。若某项要求缺少证据，可以补作品、测试记录或实习反馈，让同一对话重新评估。只需要一段简历文案时，直接指定原句和目标岗位即可。

地区薪酬与学历结构取决于样本筛选。读图时看地点、岗位、分母和数据范围。简历里的量化成果只填写自己能核实的数字。
