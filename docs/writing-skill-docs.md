# 给技能写文档

在与技能实现同级的 `docs/` 下写 Markdown。网页和仓库索引都读取这里的原文。已有示例可直接参考 [PDF 翻译指南](../.agents/skills/doc-translate/docs/index.md) 与 [专题页](../.agents/skills/doc-translate/docs/review.md)。

## 新建一页

```text
.agents/skills/<skill-id>/
├── SKILL.md
└── docs/
    ├── index.md
    └── examples.md
```

`index.md` 是技能首页，首行写一个一级标题，紧接着写一段纯文本简介。目录用这段简介帮助读者选择技能。正文至少给出一次读者能照做的任务，写明需要准备什么、如何发起、去哪看结果和哪些条件会影响结论。比如双栏 PDF 的指南需要提醒读者核对图注和分页。

同一目录可继续加专题页，每页同样以一级标题开头。文件名用小写英文字母、数字和连字符。首页排在最前，其余按文件名排序。在公开文档中用 `[更多示例](examples.md)` 跳转到同技能的另一页，用完整的 HTTP(S) 地址引用外部网页或图片。公开页的原始 HTML 会转义。开发文档直接在仓库中阅读，可使用普通的仓库相对链接。

## 编排目录和可复制的提示词

左侧目录自动收录技能首页与专题。正文用二级标题划分读者要完成的步骤，当前文章的这些标题会出现在左侧目录中。

将适合直接发送给智能体的文字写在独立的 `prompt` 围栏中。每个示例会有自己的复制按钮，读者复制到的是围栏里的原文，换行和缩进会保留。普通引文仍用 `>`，命令仍用对应的语言围栏。

````markdown
```prompt
请将附件第 2–5 页译成简体中文。
保留原图，并翻译每一幅图的图注。
```
````

## 通用指南和阅读顺序

项目级的「在线运行与 API 指南」在 `docs/guide.md` 维护。它和技能文档使用同一阅读器，顶层的 `bash`、`sh` 示例会显示复制命令按钮。网页的“下一页”按左侧完整目录排序，从文档首页进入通用指南，再依次阅读每个技能的首页与专题。搜索只筛选目录，最后一篇结束分页。

## 汇总与发布范围

- **仓库索引**收录顶层技能目录（以 `SKILL.md` 识别）及广场已注册的专业技能。嵌在其他技能里的脚手架模板随所属技能说明。[查看完整索引](skill-index.md)
- **网站文档中心**按后端专业技能注册表选出公开页面。地址为 `#/docs/<skill-id>` 或 `#/docs/<skill-id>/<文件名去掉.md>`。目录、链接和正文在开发服务与生产构建时生成，浏览器阅读无需运行模型或连接数据库。
- **内置提示词技能**也在 `.agents/skills/<skill-id>/docs/` 写指南。只有文档的目录不会改变后端安装状态。

## 本地预览与检查

从仓库的 `web/` 目录执行以下命令。

```sh
npm run docs:index  # 更新仓库内可点击的 Markdown 索引
npm run docs:check  # 验证文档格式、公开页的章节链接和索引是否最新
npm run dev         # 浏览 http://127.0.0.1:4188/#/docs
```

开发服务会随公开 Markdown 的增删改刷新。运行 `npm run build` 后，将生成的静态站点按项目原有流程发布。正文只维护一份，提交时带上已更新的仓库索引。
