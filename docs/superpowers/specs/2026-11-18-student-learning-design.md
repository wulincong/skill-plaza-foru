# 学生个性化学习规划设计

状态：用户已确认最终方案并授权实施。

学生填写目标岗位（必填）、学习目标、当前基础、可投入时间四项信息。知识库 ID 由宿主配置，默认万维自建课程知识库。目标是生成基于岗位的分阶段学习路线、课程顺序、每日任务、时间、阶段成果及真实教材链接。

先查分类（课程包），再按分类查教材和阅读大纲，最后编排计划。完整匹配沿用教材；部分匹配补充任务；确无匹配自主规划并标明来源边界。上游失败与无匹配区别处理；关键缺证等待用户选择。不得编造课程、课时、章节和链接。

选择保留 Python 检索工具，扩展分类与文档能力；不用第二套 Node 检索实现或新增模型。Node 宿主通过会话受限中继调用 Python，保存上游凭据；低权 Pi 只接收受限调用凭证。报告由 report-rendering 交付 HTML。匹配到的教材必须绑定到任务，材料入口为平台生成的逐文档随机授权链接，与现有报告一样持链接可访问，不要求学生输入上游 Key。只开放配置知识库的已验证文档，不做任意 URL 代理。Word 可下载，PDF 可内联，主动内容附件下载。

首期不含打卡、进度追踪和自动重排。验收覆盖四字段、分类分页和筛选、来源核对、时间预算、真实教材链接、无匹配自主规划、上游失败停止、密钥不泄露、低权会话可调用及重启后教材入口有效。
