# 岗位胜任力测评 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement task by task.

**Goal:** 从真实JD反推能力指标，对照学生原始材料，交付可解释的胜任力初评网页。

**Architecture:** 复用job-matching的查询、附件解析、来源快照与Pi工具；独立skill处理能力框架、证据映射和报告。后端按当前轮绑定来源，前端提供任务表单，报告通过report-rendering确定性渲染。

**Tech Stack:** Python标准库、Vue/TypeScript、Pi原生工具、共享HTML渲染器。

- [x] 1. 编写并运行失败测试：未知不补零、伪造引文拒绝、无个人材料拒绝、资格单列、来源绑定。
- [x] 2. 实现能力校验与报告构建；补充技能入口、JSON格式、用户说明。
- [x] 3. 接入广场卡片、表单、runner与当前轮材料；验证结构化字段和既有岗位匹配回归。
- [x] 4. 运行构建、文档索引、报告渲染与浏览器检查；服务无任务时重启当前克隆后端，验证健康与技能入口。
- [x] 5. 更新开发手记127，注明实测边界与扩展路线。

决策：岗位方向取5–10份同层级代表JD，若相关样本不足5份须在报告说明覆盖限制；具体岗位只分析本轮候选中的一个ID。等级采用AI分析量表，不伪称企业标准。所有分值来自有引文的材料；未知保留null，任一指标未知不生成完整综合分。

实测：16项新增Python、16项既有Python、23项Node回归通过，生产构建、文档索引与技能格式通过。真实Flash首测67秒，1份JD不足5份时有范围限制、未知项不生成综合分。桌面/窄屏表单和成品网页已验。审查修复：续聊保留岗位选择、学历或偏好不满足能力材料门槛；真实样例增加框架误推与工具缺证语义约束。多份JD模型质量尚待更多样本。
