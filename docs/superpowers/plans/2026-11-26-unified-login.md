# 统一登录闭环实施计划

范围：按用户确认，仅登录、回调、当前用户、刷新恢复和退出；移除演示登录，不改变聊天权限。

设计：复用教育平台同环境 appId、unionLogin 和用户资料接口。后端以限定路由代理平台请求，token 放入广场专属 HttpOnly Cookie；登录事务用短时随机 state 和 Cookie 绑定。回调走 /api/auth/callback，成功返回原 hash 页面。默认采用 .env.test 的测试 ID，支持显式覆盖 development ID。生产配置使用原 production ID。

取舍：不直接复制 Nuxt Cookie 工具，不共享父域 TOKEN，不新增广场用户数据库。代价是平台请求依赖现有后端且需确认新回调地址受原 appId 允许。全平台退出通知和聊天用户隔离留待后续。
