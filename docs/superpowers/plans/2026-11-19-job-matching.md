# 岗位智能匹配实施计划

用户已确认实施：下拉字段传字典Key，查询最多100条候选，通过JD与简历匹配推荐最多20条并交付报告。

1. 核对公开接口的分页、字典、薪资、工作性质与详情入口；以实测为准，未知参数不猜。
2. 新增job-matching技能的只读查询与固定评分构建器。候选按ID去重，上限100；取数失败不伪装为空，先生成来源快照再评估。程序检查推荐ID、JD与简历引文、评分及推荐上限。
3. 复用通用表单添加下拉映射、简历上传与补充说明，查询工具显式挂载。报告用共享minimal渲染，不重复让模型生成HTML。
4. 测试分页、重复、失败、字典、缺简历、来源、排序、20条上限；构建与浏览器表单验证；真实接口和低权Pi验证。
5. 更新126开发手记和文档索引，确认无任务后只重启当前副本后端，验证LAN入口。保留现有用户改动，不操作wlc服务。

约束：匹配度不是录用概率；没有简历不输出完整匹配分；不足20条如实展示；不自动放宽用户条件。简历原文和联系方式不进入公开目录。字典与结构化字段冲突时对照JD并提示待确认。岗位链接仅使用核实的详情路由。
