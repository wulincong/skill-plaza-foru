03

技术架构

技术架构采用六层结构。业务请求从三端向下协同，Agent 可按任务确定性与开放度选择运行方式，并调用模型、数据与工具返回业务结果。

六层目标技术矩阵

接入层

  • 个人端
  • 企业端
  • 院校端

业务应用层

  • 产业需求对接
  • 人才培养方案制定
  • 课程建设
  • 实训实践体系建设
  • 就业能力测评

模型服务层

优才知路产教融合大模型（Lumi LLM） 产教融合领域微调模型 · 展开生产流程收起生产流程

基于开源大模型，融入平台领域数据与业务规则，形成 Lumi LLM 专属模型能力。

  1. 01数据治理

    产业、岗位 JD、课程、培养方案、政策与报告

    清洗去重 · 脱敏 · 字段标准化

  2. 02样本构造

    专家黄金样例 → 强模型扩增 → 人工抽查修正

    形成训练样本，并独立保留评测集

  3. 03三阶段训练

    开源基座 + 领域语料 + 业务样本

    1. CPT
      继续预训练

      学习产业、岗位与课程的领域知识

    2. SFT
      监督微调

      学习业务任务、结构化输出与工具调用

    3. GRPO + DPO
      规则与偏好对齐

      强化业务规则，优化输出风格与结构

    训练产出 Lumi LLM 垂类微调模型

  4. 04知识增强与接入

    RAG 检索与引用溯源、工具调用、结构化校验

    通过 API 接入平台业务

  5. 05评测验收

    独立评测集验证，对比通用模型，专家抽检

    检查领域准确性、结构与引用

  6. 06灰度上线

    重点产业、岗位与课程场景先行，逐步扩展

    收集人工修正、专家意见与用户反馈

↺ 线上反馈 → 样本更新 → 迭代训练 → 效果验证
