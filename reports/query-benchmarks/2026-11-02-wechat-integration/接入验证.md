# wechat-report 共享查询接入验证

本轮替换旧直连入口、SQL生成和Python重复聚合；报告统一使用 talent-data-query 1.2。查询与报告通过公开CLI和JSON契约连接，没有复制数据库配置或导入查询内部模块。

真实只读样本：广州、低空经济产业子树、大专/高职、全时间在招。总体319条记录，包含独立职教子样本。显式方向和技能规则见 plan.json，不代表官方产业赛道分类。

- 一次live收集约17.518秒，统计批次14.858秒（含建连传输），10条SQL，32个指标结果。
- 最终编译器生成的10条SQL与实际证据完全相同；最终统计代码重建的结果contentHash与原保存结果相同。
- 使用同一保存结果完成17页大纲/图片/长图、文章、内部核查工作簿和公开ZIP；后续重适配未重新查库。
- 数据/投影绑定、缺图检查、实际渲染检查通过；人工查看热力图、附录和页脚。
- 公开ZIP按manifest打包，不包含内部核查表、report_binding或查询工件。
- 自动测试57/57，web构建通过。完整摘要见 validation.json，真实工件留本地 raw/session（不提交）。

限制：单个小范围样本，非省域耗时承诺。运行使用开发用户，低权Pi在线入口和服务重启后的新会话未验收。本轮未重启服务、未执行索引DDL、未调用微信。既有热力图检查使用定向探针兜底，不能称逐格OCR验证或所有版式问题已解决。
