# 岗位胜任力测评

从目标岗位的真实招聘说明出发，结合你提交的经历与技能，回答“哪些能力已有材料支持、哪些存在差距、哪些还不能判断”，帮助决定投递及学习优先级。

## 如何提交

目标岗位必填，可选择工作性质，并补充工作或实习经历、项目、技能、简历及说明。表单不再单独填写具体岗位ID、期望城市、学历专业与毕业状态；简历已有的教育信息仍可用于核验任职门槛。无需每项都填，但至少有一项实际技能或经历。附件支持文字PDF、DOCX、TXT、Markdown。请先删除联系方式与不适合分享的信息。

默认按岗位方向初评，从相关候选中挑选5–10份同层级、尽量覆盖不同企业的JD。需要评估某个具体岗位时，可在对话中明确选择候选。相关样本不足时报告说明范围，不用高级岗位要求替代实习标准。

## 分析逻辑

1. 查询招聘平台真实岗位，最多100份候选，个人材料不会发给招聘接口。
2. 从所选JD提炼知识、技能和任务能力，区分岗位明示与AI推导，保留原文依据。
3. 把学生真实经历映射到能力指标。学历、年限、证书等门槛独立核验，项目不当工作年限。
4. 对照要求与材料支持等级，形成优势、明确差距及待补证据清单。
5. 生成网页报告，给出可交付成果与验收方式明确的提升任务，以及真实岗位入口。

不使用岗位群画像代替具体岗位要求。JD只写通用编程任务时，不把特定框架推成企业必需条件；未使用某种工具也不直接等同缺少更广义的能力。报告是基于材料的初评，不能代替实操、面试或企业认证。技能自述、项目描述和成果描述的证明力度不同，模型会据实说明。

## 指标如何理解

等级为AI分析量表：0明确尚未掌握、1理解概念、2在指导下完成、3独立完成、4处理复杂问题并优化；不代表企业正式标准。各项能力权重共100%。

完整综合符合度是各项“材料等级÷要求等级（最高按1）×权重”之和。只要一项未知就不输出完整总分。材料可评估覆盖按有等级指标的权重相加，反映信息覆盖，并非真实能力、录用率或证明材料真实性。未提及不按零分处理，也不填1或2作为折中；缺少更高层级记录不直接证明较低等级，跨能力推断须有对应任务过程。明确差距与缺少描述分开呈现。

## 报告和证据门槛

报告包含结论、指标、门槛核验、能力画像对比、JD与经历短引文、提升与验证行动、岗位原文及资料日期。每个非空能力等级必须有学生原话，所有指标有JD依据。查询失败、没有相关JD或没有实质个人材料时先补问；核心问题仍无法回答时由你选择调整范围、补材料或按有限证据继续，等待期间不出终稿。

生成时校验本轮来源、岗位ID、引文、权重和分值，再使用共享report-rendering生成HTML。交付检查真实网页的桌面与窄屏阅读、指标、链接、隐私与引文。报告只展示相关摘录，不公开原始简历；分享前仍应自行核对摘录。
