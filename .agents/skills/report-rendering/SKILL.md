# 报告网页设计

从内容中识别读者、要回答的问题和重要信息，设计能顺畅阅读、核对数据的网页。先查看[元素设计](references/elements.md)和[主题系统](references/themes.md)，选表时查[表格图鉴](references/tables.md)。可打开 [纸感组件陈列](examples/gallery/index.html) 或 [极简组件陈列](examples/minimal/index.html) 对照效果。

## 整理内容

接受文字、Markdown、JSON、表格及其组合。字段名、章节数、来源编号和数据形状沿用原材料。编写内部文件前读取[页面模型](references/page-model.md)，由 Agent 在工作区转换，无需用户改输入或填写 schema。Markdown 可以直接渲染成基础页面，再按阅读需要提升为摘要、指标或图文段。复杂 JSON 先理解键与上下文，逐块映射，保留未映射的有用内容。未给出的地点、日期和主体采用中性表述，示例中的内容仅用于理解组件。

已有业务报告以审核后的正文、数字和来源为准。内部整理保留原文定位和数值口径，矛盾就标出具体位置。只有会改变含义的歧义才追问。文字材料正常排版，数据按读者要做的比较搭配表格与统计图。单位或分母缺失时如实呈现，避免据此生成比例或排名结论。业务流程正在等待补证或用户选择时，由业务技能处理后再交接成稿。

## 设计页面

默认 `paper` 提炼广州具身智能报告的暖白纸感、深绿重点、琥珀强调和纵向论证节奏。`minimal` 用白底、灰阶、蓝色点缀和圆角。用户指定风格时按主题 token 和布局变量设计主题文件。组件组合、列数、摘要和指标数量随内容调整。

**图表尽可能多样化。** 按[图表选型与组合](references/chart-selection.md)识别比较、趋势、构成、分布、关联、变化、区间、矩阵与地域关系。多图报告的数据支持多种关系时，应组合相应图型，避免所有内容默认使用柱状图。排版前复核整篇图型分布；换方向或颜色仍属同一种图型。选型须满足真实数据前提，缺少时间序列、个体观测或流向数据时保留已有比较与表格。同类比较适合统一图型时保持一致，在内部复核中记录理由。

**读取最新绘图能力。** 每次生成或修订需要选图时，读取磁盘上最新的 [chart-visualization 入口](../chart-visualization/SKILL.md)，再按其索引读取相关规格和示例。同一会话再次选图也刷新入口。本技能的图型表用于说明选型思路，支持范围以共享绘图技能当前实现为准。新增图型只要已在其入口登记、满足所选数据条件，并能按现有图稿协议生成和复验，即可通过通用 figure 块接入。

先排标题、摘要与主要章节，再把数据放到支撑它的段落旁。精确比较用表，表达关系时调用 [chart-visualization](../chart-visualization/SKILL.md) 绘制并复验。图注附来源、单位、分母和展示范围。用内部 `figure` 块嵌入完整图稿，或运行 `scripts/embed_chart.py` 填充自定义 HTML 中的 `<!-- chart:图稿ID -->`。图形、图注和数值表一同保留。图表不可用时给出已有数值表与实际原因。

```sh
python3 <技能目录>/scripts/render.py 工作区/page.json --out 工作区/output/public/site
python3 <技能目录>/scripts/render.py 原稿.md --theme paper --out 工作区/output/public/reading
```

输出目录用新修订路径。脚本提供可复用起点，特殊布局可以用同一 CSS 组件编写 HTML。内部模型和自定义主题均由 Agent 维护。改样式复用原内容，改数据核对受影响的文案、表格、图稿和图注。

## 验收与交付

打开实际页面，核对原稿中重要文字与各组数据，检查零值、缺测、单位、范围和来源。以 320/390 和 1280 像素检查标题、长段落、表头、图注与长链接。宽表和宽图在各自区域滚动，表区可用键盘操作。打印时检查表头和分页，打印样式通过不等于已交付 PDF。成品展示读者需要的信息。

公开目录只放 HTML、CSS 和所需公开资源。按[平台交付](references/delivery.md)把网页追加到已有 delivery.json，返回平台生成的真实链接。设计原则、输入示例和方法来源见 [使用文档](docs/index.md)。
