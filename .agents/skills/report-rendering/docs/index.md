# 报告网页设计

给出文字和数据，就可以生成可打开、可分享的报告网页。输入可用 Markdown、JSON、表格或粘贴材料，智能体在内部整理内容，选择摘要、指标、论证、表格、图表、行动和来源。

## 从内容到页面

先识别读者和用途，再整理判断、数据含义与来源。已有结论和数字按原材料保留，全文采用开篇总览、中段展开、结尾回到意义与行动的顺序。涉及业务决策时，由业务技能判断证据是否足够，再交接排版。产教报告交接已构建的正文、指标、来源与未决项；图型、主题、表格设计及页面验收统一在本技能维护，无需业务稿预先填写绘图规格。

缺少单位或来源时如实标注材料范围，会改变判断的歧义需要确认。只有文字也能呈现。Markdown 的章节、JSON 的对象数组或嵌套字段均由智能体整理内部结构。

```prompt
把这些会议材料和表格整理成纸感风格的报告网页。开篇放主要发现，中间解释数据，最后列行动安排。保留材料中的单位和出处。
```

## 元素与主题

元素包括标题、范围标签、摘要、指标、论证、摘录、图文块、表格、条件说明、行动和来源。数量与章节按材料选择，主题集中管理颜色、字体、间距、边框、圆角和布局。

首个主题“纸感简报”提炼自广州具身智能报告，以暖白、深绿和琥珀强调首屏结论与逐段论证。第二个主题“极简白”使用白底、灰阶、蓝色与轻圆角。同一内容可换主题，也可按品牌创建主题文件。[首个主题的参考报告](http://biubiubiu.vip:14188/p/990b3946916f6836bcb0025e33c7c84f/0/index.html)

## 按数据选表和图

属性用键值表，群体用对比表，数量和比例用构成表，逐期观测用时间表，双维交叉用矩阵，核对记录用明细表，分工用行动表，回查材料用证据表。数字右对齐，单位、分母明确，零与缺失分别呈现。

选型参考 chart-visualization 的“读者问题、数据前提、表达方式”结构。统计图由该技能绘制、复验，网页保留完整图块、图注和数值表。表格保留标题、行列头及关联，辅助技术也能读取关系。[W3C 表格设计依据](https://www.w3.org/WAI/tutorials/tables/)

## 图表尽可能多样化

多图报告根据内容组合不同图型。数量比较可用柱状图，时间变化用折线，个体分布用点分布、直方图或 ECDF，关联用散点，交叉结构用矩阵，地域差异用地图。构成、流向和多维轮廓按相应数据条件选择，并通过共享绘图技能支持的出图方式制作。

排版前检查整篇报告是否把不同关系都画成了柱状图，优先改用能直接表达该关系的图型。图型选择以实际材料为依据，缺少时间序列就保留当前快照；同类比较适合相同图型时保持统一。柱状图改变颜色或横竖方向仍属于同一类表达。组件陈列展示类别比较、趋势、散点和矩阵四类示意图。

## 跟随绘图技能扩展

每次需要选图时，智能体读取 chart-visualization 的最新入口和相关规格。新增图型在绘图技能中登记后即可被发现；具备生成、复验能力并沿用完整图稿协议时，可直接嵌入报告。图型索引、输入字段和绘制方法统一维护在绘图技能，报告侧负责按内容选择和排版。设计文档已经登记但绘图实现仍待完成的能力，会按其实际状态处理。

## 怎样验收

成品包含材料中的重要内容，数字、单位、来源和限制一致。手机可读正文，宽图和宽表局部滚动。交付前实际打开桌面和手机页面，核对图表及链接。HTML 提供打印样式，正式 PDF 需检查实际导出。

仓库 examples/gallery/index.html 与 examples/minimal/index.html 展示同内容的两种主题。组件示意数据明确标记为样例，业务成品使用自己的材料。设计原则、表格选型、内部结构与参考来源随技能维护。
