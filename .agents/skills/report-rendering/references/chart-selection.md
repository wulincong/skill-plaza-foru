# 图表选型与组合

先列本报告要表达的数据关系，再选择图型。多图报告包含多种关系时采用相应的图型组合，避免逐段默认画柱状图。选型及理由由 Agent 在工作区整理，外部输入继续接受文字、Markdown 和 JSON。

| 分析目的 | 适用图型 | 必要数据 |
| --- | --- | --- |
| 类别、数量与排名 | 柱状图、横条图 | 同口径类别与数值，长标签优先横向 |
| 趋势与多组演变 | 折线、分组折线、分面趋势 | 真实时间或有序数值坐标，缺测断线 |
| 整体构成 | 堆叠柱、百分比堆叠 | 类别互斥、总量及分母可核对；跨组比较同口径 |
| 分布与集中程度 | 点分布、直方图、ECDF | 原始观测，或适合既定分箱的频数；均值和中位数仅作为已有汇总展示 |
| 两个量的关联 | 散点图 | 同一对象的两列配对数值，标明观测层级 |
| 同一对象前后变化 | 配对图、变化分布 | 对象 ID、两个阶段、对应观测；分别统计的组均值无法恢复个体轨迹 |
| 估计与不确定性 | 区间图 | 估计、上下界及区间方法；薪酬 P75 与置信上界分清含义 |
| 行列交叉与结构 | 矩阵图 | 两个维度与每格指标，同量纲，零与缺失区分 |
| 地域差异 | 分省地图、行政区填色图 | 匹配区域编码或名称、边界及同口径指标 |
| 来源与去向 | 桑基图 | 可核验的来源、去向和权重，核对流量关系 |
| 多维能力轮廓 | 雷达图 | 维度含义明确、量表和方向一致，归一化方法可说明 |

图型与字段以 [chart-visualization](../../chart-visualization/SKILL.md) 的最新入口为准。每次需要选图时重新读取该入口，沿索引查看相关规格、示例和实现状态。上表只给出分析目的与图型的对应示例，新增能力可以直接参与选型。可执行的 kind 和字段从当前[独立图稿规格](../../chart-visualization/references/figure-spec.md)读取。

渲染层通过共享 render/verify 接收完整图块，按通用 figure 协议嵌入。新图型沿用该协议时，报告侧无需增加类型分支。只有专题设计文档而出图尚未实现时，先在共享绘图层完成出图和复验。若新能力改变了图稿协议或依赖外部脚本，再核对网页嵌入与平台静态托管的兼容性。

## 组合与复核

1. 每张图写清要回答的问题、可用数据及图型选择，优先从已有材料识别不同关系。
2. 跨期数据配趋势图，个体观测配分布或散点，交叉数据配矩阵，区域数据配地图。将互补图放到相关判断旁，精确值用数值表补足。
3. 复核整篇报告的图型。全为柱状图时，逐张检查是否遗漏了可表达的趋势、构成、分布或关联。若各图确实都在做同类比较，统一图型有助于读者对照，内部记录理由即可。
4. 变换颜色、改横竖方向或重复同一组数据不增加分析维度。相同对象在不同图中保持名称、颜色含义和单位一致，可比较的图复用尺度。
5. 观察不足时呈现现有证据。构成需要分母，趋势需要时间序列，分布需要观测，流向需要连接关系。图型数量由内容决定，保留真实的缺测与限制。

例如，只有岗位总量、学历构成与薪酬分位数的快照，可以组合数量比较、学历结构表/矩阵及薪酬比较表。若另有多期岗位统计，可加入趋势；若有逐岗位薪酬观测，可加入分布。素材支持到哪一层，表达就到哪一层。

组件陈列使用标明来源的示意数据，展示类别比较、趋势、散点和矩阵四类图，两个主题共用同一图稿。
