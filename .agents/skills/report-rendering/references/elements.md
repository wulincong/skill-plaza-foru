# 报告元素

按阅读任务组合元素。全文从总览进入论证，再回到行动或意义。论证段先给判断，再给依据与影响。纯记录类材料保留原有顺序。

| 元素 | 信息职责 | 设计与适配 |
| --- | --- | --- |
| 封面标题 | 主题、问题或结论 | 一个 h1，30–52px、1.22 行高、自然换行；标签在上，读者说明在下 |
| 范围标签 | 地域、对象、时间、版本 | 胶囊自动换行，长口径放正文 |
| 摘要 | 主结论、依据、条件 | 浅底重点区，结论 24–34px；限制直接可见 |
| 指标组 | 支撑结论的量 | 数字、单位、对象、说明分层；桌面最多四列，手机最多两列；长数值可换行 |
| 章节标题 | 当前子问题 | h2 加分隔线与留白，章内 h3 表达判断 |
| 论证段 | 判断、证据、意义 | 正文 16px/1.75，自然流动；影响可用浅色边注 |
| 图文段 | 直观关系 | 文前图后，短文可双列；窄屏单列，图注相邻；按数据关系组合不同图型，见[图表选型](chart-selection.md) |
| 表格 | 精确比较和核对 | 按表格图鉴选型，caption、行列头、单位、来源齐全 |
| 原文摘录 | 有出处的原句 | blockquote 加细边线和出处，与分析分开 |
| 提示与限制 | 影响解释的条件 | 普通灰阶、关注事项琥珀色加文字；关键限制展开 |
| 行动 | 事项、负责人、期限、条件 | 短任务用顺序卡，多人分工用表；未知字段如实表达 |
| 来源与方法 | 回查依据 | 文末列表或来源表，公开标题、日期、页码/表号可定位 |

默认正文宽 1000px、左右留白 24px、章节间隔 48–56px、段内 12–20px。普通正文采用开放布局，摘要、行动等重点模块使用面板。原报告的四个数字属于具体内容选择，新的材料重新选择。

公开类名使用 `report-` 前缀。token 管理色彩、圆角、间距、宽度与排印。图中 SVG 属性由绘图技能维护，主题控制周围容器。
