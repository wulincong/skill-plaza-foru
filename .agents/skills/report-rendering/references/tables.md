# 表格图鉴

沿用 chart-visualization 的选型方式，先问读者要比较什么，再核对每一行代表谁。模式改变排列与阅读重点，数字含义来自原材料。

| 问题与数据 | 模式 | 列与视觉重点 | 图表搭配 |
| --- | --- | --- | --- |
| 单对象的属性 | `key-value` | 属性作行头，值自然换行 | 通常单表即可 |
| 方案或群体的差异 | `comparison` | 对象作行头，同单位数值右对齐 | 类别量配 barh |
| 整体构成 | `composition` | 类别、数量、占比并列，表注写分母 | 互斥且穷尽时配构成图 |
| 逐期观测 | `time` | 时间升序、固定单位、缺期留空 | line，缺失断线 |
| 双维交叉 | `matrix` | 行列头定位、零与缺失分别写 | 同量纲配 matrix |
| 逐条核对 | `detail` | 识别列在前，轻分隔线，超宽滚动 | 另配汇总图 |
| 行动分工 | `action` | 事项、负责人、时间、完成条件 | 有日期可配时间安排 |
| 判断依据 | `evidence` | 判断、材料、定位、范围 | 与图注来源对应 |

文字左对齐，数量右对齐并用等宽数字。单位写列头，相同量保持小数精度一致。行序按叙事决定，排序含义明确。跨口径数据分组，合计仅使用已有总量，排名注明展示范围与长尾。

`null` 默认显示“未提供”，可用 missing_label 指定“未观测”或“不适用”。实测 0 显示 0，空文本保留为空文本。状态用文字加色彩；比例给分母，“其他”须可核算。共享图稿自带的数值表完整保留，正文可另排注明范围的同源子表。[共享数据规则](../../chart-visualization/references/common-rules.md)

表格有 caption、`th scope="col"` 和标识列的 `th scope="row"`。宽表容器有可访问名称和键盘焦点，手机局部滚动。打印重复表头并检查实际分页。复杂表头用 headers/id 显式关联，或拆为简单表。[W3C 表格结构](https://www.w3.org/WAI/tutorials/tables/)
