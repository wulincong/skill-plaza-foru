# 智能分班使用指南

面向教务处与产业学院教学秘书，把新生名单变成**公平可审计**的班级安排：均衡分班用于平行班编班，分层分班用于岗位方向分流与分层教学。所有分班由带随机种子的确定性求解脚本完成，全过程留痕，任何一次结果都能原样复现，并允许在公示前做**一次**受控重掷。

## 适用场景与读者

- **均衡分班**：新生编平行班，目标是各班在成绩、性别等维度上均值接近、班内保持混合，适合阳光分班的公示要求。
- **分层分班**：按测评能力画像与方向志愿聚类组班（不是按总分简单排序），适合产业学院方向分流与分层教学。
- 读者是教务处与教学秘书；报告也可向院领导、督导或家长代表公开（自动隐去敏感个人字段）。

与中小学均衡分班软件相比，本技能多了三条：高职特色的画像分层与方向志愿、审计级留痕与复现、公示前一次受控重掷。测评画像字段可与岗位胜任力测评数据联动（当前直接使用名单中的测评列）。

## 准备材料

| 材料 | 必需 | 说明 |
| --- | --- | --- |
| 学生名单 | 是 | CSV 或 XLSX，含学号（或编号）、姓名；可含性别、生源地区、成绩、测评结果、方向志愿（志愿1/志愿2… 或一列按顿号分隔）。字段可部分缺失，运行时会给出完整性报告 |
| 班级数量与每班容量上限 | 是 | 如 6 个班、每班上限 50 人 |
| 分班模式 | 是 | 均衡分班或分层分班 |
| 特殊约束申请 | 否 | 双胞胎同班、住宿组团、民族餐饮等，需注明申请理由；只使用申报过的约束 |
| 需回避的同编组 | 否 | 两名学生分入不同班 |
| 上次分班结果 | 否 | 仅用于对照说明，不直接决定本次分班 |

均衡维度与权重默认按成绩与性别（0.7 / 0.3），可按要求调整或加入生源地区等列。测试可用技能自带的示例名单 `examples/sample-roster.csv`（60 人，含双胞胎同班申请与缺志愿行）。

## 运行流程

1. 上传名单并填写参数（或在对话中直接说明）。
2. 技能先做字段完整性检查，向你说明可用字段、缺失与异常取值；关键缺失（如分层模式缺测评）会先确认处理方式。
3. 求解脚本运行，生成候选分班。
4. **公示决策卡**：查看摘要后选择"确认本次分班结果"或"用新种子重掷一次"。重掷后不能再重掷，两次求解都留痕。
5. 确认后交付：每班名册 CSV、全员名册、班级画像对比报告网页、审计包。

## 交付物与解读

- **分班名册**：每班一个 CSV（Excel 可直接打开），含序号、班级、学号、姓名、性别、生源地区、成绩；分层模式含方向、层次与志愿满足情况。
- **班级画像对比报告**：各班人数与容量占用、每个均衡维度的分布图与均值差、班内异质性对照；分层模式含层次构成、志愿满足率与未满足原因（班级容量 / 画像分布 / 未填报），不静默调剂。
- **审计包**：随机种子、输入指纹（参数与名单的 SHA-256）、哈希链求解日志、复现命令。任何人拿到同一份名单、参数与种子，都能在空目录逐字节复现分班结果；日志链头与清单核对可发现事后篡改。
- **重掷记录**：若发生过重掷，两版结果的种子与去向都在审计与报告中可查。

## 公平、复现与隐私

- **公平**：分班只依据名单字段与申报约束；求解使用固定种子，排除人为挑选；回避约束在均衡模式中强制生效。
- **可审计**：种子、日志、指纹随交付归档，满足阳光分班的公开监督要求。
- **隐私**：生源地区、测评原始分等敏感字段只用于求解和班级聚合统计，不出现在对外报告正文；逐生信息只在名册文件（教务内部件）中。

## 成稿验收（技能内部执行，用户可对照）

1. 名册文件数量与班级数一致，人数合计等于名单总人数。
2. 报告中的班级统计与 result.json 完全同源，无手工改数。
3. 抽查约束（如同班申请）已满足；未满足项有明确说明。
4. 复现命令实际运行一次，结果与交付一致。
5. 报告网页在手机与桌面宽度下均可正常阅读。

## 设计参考

- 均衡编班采用「蛇形（snake）铺班 + 局部搜索微调」的常规做法：先按综合分高→低往返铺班保证均值接近、班内混合，再用受种子驱动的交换继续压缩各班均值差与构成差；这是各地"阳光分班"软件的主流思路，本技能将其固化为可复现脚本。
- 分层聚类采用 k-means（MacQueen, 1967）的标准实现（k-means++ 初始化、固定种子），聚类输入是测评画像向量而非总分，避免"按总分排条子"。
- 一次受控重掷沿用公开摇号流程中"当众摇号、最多重摇一次、全程留痕"的监督惯例，重掷次数由脚本状态机强制，不依赖自觉。

有疑问或需要调整维度权重、层次数量时，直接在对话中说明即可；改参数后重新求解属于新任务，会重新获得一次确认与重掷机会。
