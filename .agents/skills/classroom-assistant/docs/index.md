# 课堂助教

把指定章节整理成带出处的答疑、课堂要点或练习题。适合教师备课，也适合学生围绕同一份讲义复习。

## 准备课程材料

上传或粘贴允许使用的教材节选、课件或课堂记录。保留章节标题、页码或段落编号，注明本轮可用的范围、学生程度和教学目标。如果只提供书名，请先补充相关正文。

## 生成一份可核对的练习

> 所附讲义是本次允许使用的第 3 章材料。学生已经学过电池结构。请先列出本章的两个学习目标，再出三道故障辨析题。将学生版与教师答案分开，每道答案给出对应的小节或原句。

先核对答案引用的位置，再检查题干能否仅凭已授内容作答。如果材料没有覆盖某个故障原因，可以要求标记为待教师补充，并用本章已有内容替换题目。

## 接着做答疑

在原对话中贴出学生的实际提问，指定只解释其中一个概念。整理答疑记录时，可要求按「问题、解释、出处、待确认事项」排列。练习和参考答案由教师确认后再用于计分。
