# 简历优化警察

用面试官的视角逐句检查简历，找出读者看不出个人贡献的地方，拿到一版可以直接修改的文字。也可以用同一段经历生成面试追问。

## 审查一段经历

在广场点「简历优化警察 → 在线运行」，或在在线对话输入 `$resume-police` 选择技能。贴上匿名简历或一段经历，有目标岗位说明时一并贴上。当前广场的对话历史对测试访客共享，请先删去姓名、电话、邮箱和客户标识。

```prompt
目标是后端开发实习。岗位要求能定位 SQL 性能问题。
简历原句是“参与优化订单查询”。当时我用 EXPLAIN 对比了改动前后的执行计划，索引是同事加的，没有记录耗时。
请指出原句的问题，解释面试官会追问什么，再给我一句可以替换的写法。
```

拿到改稿后，逐句核对谁做了什么、是否真的观察到了所写的结果。比如你只比较了执行计划，改稿里却出现“扫描行数下降”，就删去这项结论，等找到记录再补。你可以在同一对话补充证据并继续修改。给整份简历时会得到完整 Markdown 改稿。只贴一段时就针对这一段。

## 把简历变成面试题

```prompt
沿用刚才的岗位和经历。请给我两道面试主问题，每题附追问和评价回答的依据，重点区分我做的分析与同事实施的改动。
```

想把一个项目问透，可以指定“项目深挖”，从问题、个人贡献、规模、技术选择、结果与复盘五个角度准备。题单和改稿都直接显示在对话里。
