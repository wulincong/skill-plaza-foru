# 排课智能体使用指南

面向教务管理者的排课沙盘：上传教学任务、教室资源和作息校历，得到零冲突的多套课表方案、指标对比与导出文件；学期中调停课走最小扰动增量重排。它不替换教务系统，定位是教务系统之前的前置推演工具，核心差异在企业轮岗、技能等级考试（1+X）窗口、产业学院混编班、双师协同同堂这些职业教育约束的建模能力。

## 从一个真实任务开始

在在线对话输入 `$course-scheduling` 或从工作台进入，直接粘贴这段提示词并上传模板数据（可用下方示例数据先试）：

```prompt
使用 $course-scheduling 为我校排 2026-2027 学年第一学期课表。
已上传教学任务、班级、教室、作息与校历五张表；体育教师尽量不排午后，
数控实训室周五下午被企业培训占用。生成三套方案并给我对比与推荐。
```

体验数据：下载技能内置的示范职业技术学院数据集（10 个班级、68 项教学任务、含企业轮岗与 1+X 考试窗口），上传后即可完整走通求解、对比、选方案、导出。

## 它会怎么工作

1. **数据校验**：按模板解析你的表格，缺关键字段（连排要求、台套数、轮岗周次）会先问你，不猜默认值。
2. **零冲突求解**：教师、班级、教室、容量类型、台套数、连排、占用时段等硬约束全部满足才输出；排不进的课程不进课表，而是逐条给出阻断原因和放松建议。
3. **三套方案**：教师集中型、负载均衡型、均衡折中型，同一份数据不同侧重，附冲突数（恒为零）、未排入、连排达成率、教室利用率、实训室负载分布对比。
4. **你来选**：对比网页 + 决策卡；有未排入时先在放松项（放宽教室、拆连排、协调教师）中取舍后重排。
5. **导出交付**：选定后导出课表 Excel（班级/教师/教室三视图 + 指标 + 归因）和 ics 日历（轮岗、考试窗口、假期周次自动剔除）。
6. **学期中调停课**：上传现有课表加变更需求，只动受影响的课程，变更清单留档，可回退上一轮。

## 需要你准备的

- 必需：教学任务清单（课程、班级、教师、周学时、连排）、教室与实训室清单（容量、类型、设备台套数）、作息时间表、校历。
- 可选：教师时间偏好、企业实训轮岗批次、1+X 考试窗口、双师协同安排、不可用时段、已有课表（增量模式）、软约束权重。
- 没有模板时直接说"给我模板"，会生成 Excel/CSV 模板给你填写。

## 需要你决定的节点

- 缺关键字段时：补充材料或按已给数据继续。
- 有未排入课程时：选择放松项（放宽教室要求、拆分连排、协调教师时段、核减班级负荷）或接受未排入。
- 方案对比后：选定方案一/二/三或要求重新生成。

等待你选择期间不会生成导出文件。

## 怎么验收

- 对比页与 Excel 的冲突数应为 0；未排入课程应能在归因表里找到阻断原因。
- 抽查 2–3 门课：教师、班级、教室时段与导出一致；连排课同天同教室连续节次。
- 轮岗班级的 ics 日历应看不到轮岗周次的课次；学时影响表数字与校历标记一致。

输入模板、约束语义与指标口径的完整定义在技能的 references 目录（输入契约、约束与权重、输出契约、工作流细则），会话内可随时查阅。
