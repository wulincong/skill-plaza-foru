# 约束与权重

求解采用「周课表模板 + 校历例外」模型：求解确定每门课的周模式（星期、开始节次、教室）；假期、考试窗口、企业轮岗等**部分周事件**不改周模板，影响体现在 ics 日历（EXDATE 剔除受影响周次）与有效学时统计。

## 硬约束（冲突数必须为零，由构造保证）

| 编号 | 约束 | 说明 |
| --- | --- | --- |
| HC-01 | 教师时间不冲突 | 同一教师（含双师的每位教师）同一节次只上一门课 |
| HC-02 | 班级时间不冲突 | 同一班级（混编任务的每个班级）同一节次只有一门课 |
| HC-03 | 教室占用不冲突 | 同一教室同一节次只有一门课 |
| HC-04 | 教室类型与容量匹配 | 类型精确匹配（指定时）；容量 ≥ 班级人数之和（或 minCapacity） |
| HC-05 | 实训台套数满足 | 指定设备时，教室设备名一致且台套数 ≥ 要求 |
| HC-06 | 连排节次连续 | 连排节数在同一时段内连续（不跨午休等时段边界），同天同教室 |
| HC-07 | 占用时段避让 | 模板级占用块内不排课（见下） |

排不进的教学单元不进入课表（绝不带冲突输出），进入归因：逐约束统计阻断证据（教师占用 N 处、可用教室 0 间、连排窗口不足等）并给出按代价排序的放松建议（放宽教室要求、拆连排、协调教师、核减班级负荷、增补实训资源、核对占用约束）。

## 占用块（blocks）统一语义

- `scope` 省略或 `weeks` 覆盖全部周 → **模板级**：每周生效的硬约束（教师例会、教室检修、企业导师非驻校日）。
- `weeks` 为部分周 → **日历事件**：假期、1+X 考试窗口、企业轮岗批次。受影响周次的课次在 ics 中 EXDATE，学时损失按班级汇总进对比页与 xlsx。
- `days`/`periods` 缺省 = 全天；轮岗批次通常只填 `weeks` + `scope.classes`。

## 软约束（加权优化，权重可在 权重设置 表配置）

| 权重项 | 语义 | 默认 |
| --- | --- | --- |
| teacherCompact | 教师偏好：集中（少占天）或分散（压低单日峰值），按教师 授课偏好 列生效 | 1.0 |
| afternoonPe | 午后不排体育（课程类别=体育） | 5.0 |
| categoryStagger | 同类课程错峰（同类别课程不挤同一时段，缓解实训/场馆压力） | 2.0 |
| roomStability | 教室稳定（同班同天尽量同教室，减少学生挪动） | 1.0 |
| balance | 负载均衡（班级与教师的每日节次离散度） | 1.0 |

三套方案 = 同一数据 + 三组权重侧写：A 教师集中型、B 负载均衡型、C 均衡折中型；用户权重作为基数缩放。同结果自动换种子去重。

## 增量模式语义

- 已有课表的排入默认**固定不动**（最小扰动）。
- 变更类型：`cancel` 停开、`unavailable` 临时不可用（转占用块，可带 weeks 表示限周）、`add` 新增任务。
- 违反新约束的原排入自动转为待重排，重排时偏离原时段付出大代价（换天 > 换节次 > 换教室），因此只在必要时挪动。
- 输出变更清单：沿用（不列）、调课（原→新）、停课（移除）、新增；每轮 solutions 留档，可回退到上一轮。

## 沙盘推演

不改求解逻辑，通过修改 problem.json 重跑对比：

- 压缩教学周：改 `calendar.weeks`（对比学时损失与连排达成率）。
- 校区搬迁：删减/替换 `rooms`（看未排入归因中的教室瓶颈）。
- 新增专业开课：追加 `classes` 与 `tasks`（看教师与实训室压力）。
