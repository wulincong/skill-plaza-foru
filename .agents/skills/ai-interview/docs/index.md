# AI 面试练习

选一个岗位，亲自回答面试官的第一题。下一问会跟着你刚才说的内容走。结束后可以回看哪句话体现了岗位要求，选同一道题再答一次。

## 开始一轮面试

在广场打开「AI 面试练习 → 在线运行」，或在在线对话选择 `$ai-interview`。只给岗位名称就能开始。有招聘说明时，贴一两条职责，或上传匿名岗位说明和经历。广场的测试访客共享对话历史，请先删去姓名、电话、客户名称等信息。

```prompt
我要应聘新能源汽车售后技术支持。岗位要求是定位故障，并向客户解释处理方案。我在校内实训中参与过充电故障排查。请做两道主问题的完整模拟，先问第一题。
```

## 选择练法

- **完整模拟**适合练一轮不同任务。默认 3 道主问题，追问不占题数，答完集中复盘。
- **专项突破**适合把一项能力练透，例如只练“用客户能理解的话解释故障”。答一遍，看一个具体改进点，再答原题。
- **压力追问**适合练取舍。面试官会在你的回答上加一项约束，例如交付时间缩短，让你说明决定的依据。

可以选中文、英文或中英混合。练到一半可直接说“提示一下”“跳过这题”或“结束，先复盘”。没有工作经验时可以讲课程或实训；没有做过的事也可以要求改为假设场景。

## 怎样看复盘和重答

比如你答“组长换了接头，我负责记录故障码”。这句话能说明你记录了什么；要练故障定位，还可以补充自己怎样根据记录判断下一步。换接头的功劳仍属于组长。遇到没记录的耗时或指标，可以直接说明当时观察到了什么。

```prompt
结束面试，请引用我的原话，指出哪项岗位要求还缺证据。选一道题让我重答，等我答完再比较两次回答。
```

复盘里的“部分展示”会写明已经说清的部分和还缺的依据。跳过或没来得及作答的题记作“未评估”。评价只针对这次回答，不预测录用结果。
