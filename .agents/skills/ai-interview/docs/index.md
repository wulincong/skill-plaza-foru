# AI 面试练习

选一个岗位，亲自回答面试官的第一题。下一问会跟着你刚才说的内容走。结束后可以回看哪句话体现了岗位要求，选同一道题再答一次。

## 开始一轮面试

在广场打开「AI 面试练习 → 在线运行」，或在在线对话选择 `$ai-interview`。只给岗位名称就能开始。有招聘说明时，贴一两条职责，或上传匿名岗位说明和经历。广场的测试访客共享对话历史，请先删去姓名、电话、客户名称等信息。

```prompt
我要应聘新能源汽车售后技术支持。岗位要求是定位故障，并向客户解释处理方案。我在校内实训中参与过充电故障排查。请做两道主问题的完整模拟，先问第一题。
```

## 选择练法

- **完整模拟**适合练一轮不同任务。默认 3 道主问题，追问不占题数，答完集中复盘。
- **专项突破**适合把一项能力练透，例如只练“用客户能理解的话解释故障”。答一遍，看一个具体改进点，再答原题。
- **压力追问**适合练取舍。面试官会在你的回答上加一项约束，例如交付时间缩短，让你说明决定的依据。

可以选中文、英文或中英混合。练到一半可直接说“提示一下”“跳过这题”或“结束，先复盘”。没有工作经验时可以讲课程或实训；没有做过的事也可以要求改为假设场景。

## 面试题和追问怎样设计

**先确定这道题要观察什么。** 美国人事管理局（OPM）的结构化面试指南从岗位任务确定所需能力，再设计问题、评价依据和追问。我们把这种方法用于练习。例如，岗位要求“向客户解释故障”，面试官可以请你直接向车主说一句话。评价时看这句话能否让车主听懂现状、知道下一步怎么做。故障诊断能力可以用另一道题单独考察。[OPM《结构化面试实用指南》，第一部分](https://www.opm.gov/policy-data-oversight/assessment-and-selection/structured-interviews/guide.pdf)

**让刚才的回答决定下一问。** Big Interview 的 PracticeAI 会结合岗位说明、简历和当场回答调整问题，并允许练习者按题回看反馈。在我们的练习里，如果你只说“我们解决了”，面试官会追问你本人做了哪一步。如果你已经说清个人行动，下一问就可以转向判断依据，或者直接换题。[Big Interview 的 PracticeAI 使用说明](https://support.biginterview.com/en/article/practiceai-qxju4/)

**保留自己的回答，用同一道题检验进步。** 曼彻斯特大学职业服务建议用岗位材料准备面试、一次回答一题，并用本人经历核对 AI 的反馈。我们的复盘据此引用你的原话。重答时沿用原题和评价依据，你可以看出第二次究竟补充了哪条事实。经历题看你做过什么，假设题看你打算怎样判断。[曼彻斯特大学《用 AI 准备面试》](https://www.careers.manchester.ac.uk/applicationsinterviews/interviews/practiceinterviews/aiinterviewprep/)

## 怎样看复盘和重答

**一例新能源汽车售后技术支持练习。** 这道题考察故障定位。练习者先答“我们解决了车辆插枪后不启动的问题，我是小组成员。”这句话交代了团队的结果，还看不出他本人做了什么。面试官因此追问了他的分工。

练习者补充了自己的分工。“我负责记录故障码，再对照实训手册核对车辆状态。接头是组长换的，我没有记录修复耗时。”对故障定位这项能力，这次回答属于**部分展示**。记录和核对是他本人做的。哪项观察让他判断应该检查接头，还需要他说明。重答时，他补充“我看到换后重新插枪可以充电，修复耗时没有记录。”这次多了一项可观察的结果，仍保留了对耗时的限定。

练习者跳过了向客户解释方案的那一题，因此客户沟通记为**未评估**。本技能用“已展示、部分展示、未展示”描述已作答的内容，用“未评估”标记没有作答的能力。这些用语只评价本次练习，不预测录用结果。

```prompt
结束面试，请引用我的原话，指出哪项岗位要求还缺证据。选一道题让我重答，等我答完再比较两次回答。
```
