# AI 面试练习

用一段真实经历练习回答目标岗位的问题。面试按轮进行，每次只需回答一道题，结束时可以回看自己的原话和改进建议。

## 开始一轮面试

贴上目标岗位的职责、要求，以及一段你能讲清楚的项目经历。说明这次要练哪一轮、哪种能力。只有岗位名称时，先补上两三条招聘要求，问题会更贴近实际工作。

```prompt
我要应聘新能源汽车售后技术支持。岗位要求能定位故障、向客户解释处理方案。我在校内实训中参与过一次充电故障排查。请扮演技术面试官，围绕这段经历逐题提问，等我回答后再追问。
```

## 怎样回答和复盘

1. 第一题先交代当时要解决的问题。说明你本人做了什么、依据什么决定下一步、怎样知道问题解决了。
2. 收到追问时就在同一段对话回答。如果记不清具体耗时，可以直接说「没有记录」并提供可核对的现象。
3. 想结束时，可以用下面的提示词请求复盘。对照引用检查判断，再挑一题重新作答。

```prompt
结束面试，请引用我的原话，指出哪项岗位要求已有证据，哪项还缺例子。
```

练习中的评分只反映这次回答所展示的能力。要核实某个岗位的资格门槛，请以该岗位的实际招聘要求为准。
