## 一、公众号稿结构（build_article 的模仿基准）

1. **标题**：`产业观察|大湾区机器人产业人才需求观察报告`（系列|书名号报告名）。
2. **导语两段**：
   - 第一段·背景与样本：产业正从"技术验证"走向"规模应用"→为观察一线岗位变化，
     对XX招聘信息做了梳理，重点覆盖XX城市与XX方向。
   - 第二段·报告价值：本次形成的《报告》希望通过真实招聘数据，帮助企业、高校及
     人才培养机构了解岗位结构、需求变化与能力方向；欢迎关注、转发和交流。
3. `向下滑动查看更多`（报告图片开始）。
4. **核心趋势三分点**（"从本次招聘信息中，我们观察到几个明显趋势"）：
   `一是……；二是……；三是……`——每条都是**定性方向判断**（研发→研发+应用+交付+运维并重；
   新兴方向需求增长快、复合能力要求高；岗位分工细化成独立职业能力）。
5. **升华句**：人才竞争正从"有没有人"走向"有没有符合真实岗位要求的人"。
6. **行动号召**：协会牵头编制《XX职业规范》《XX能力评价标准》等团体标准，征集参编单位。
7. **联系方式**：参编咨询+电话/微信。
8. 往期推荐（相关精彩）。

⚠️ 口径红线：原文写"BOSS直聘、智联招聘、猎聘"，我们**一律写"优才知路平台的数据库"**。

## 三、可直接吸收的写法（已并入 copywriting.md，此处留档）

1. **摘要页三判断**：每条=一句可独立传播的判断（"岗位正由X向X转变"句式），
   不堆数字；数字留给数据章。
2. **概述段句式**："从XX看，……占比XX%；其次……"——一段讲完一个维度，
   不写方法论（方法全部在09报告说明）。
3. **"一是/二是/三是"**：公众号趋势段固定句式；摘要页则用编号卡片。
4. **图表呼应正文**：正文说"增长快"，图里就把该方向橙色高亮。
5. **薪酬用万元区间**（1万以下/1-2万/2-3万…），不用K。
6. **每图下固定注脚**：`数据来源：…｜统计周期：…`。
7. **岗位族群表**是面向培养价值的杀手页：岗位-能力-规模同屏。
8. **行动号召段**：把报告与"标准编制/参编征集"等实际动作衔接（我们可对应
   落到"报告定制/数据服务/联合研究"等真实提供的动作，禁止虚构）。
