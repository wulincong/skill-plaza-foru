# 报告图片规范（render_report.py）

## 总原则

报告以图片形式进入公众号正文。**样式一比一复刻**参考文章《广东省人工智能产业人才需求观察报告》的长图版式（参考样本存于 `../../wechat-article-ref/slices/`，实测参数如下）。渲染器是**大纲驱动**的：只读 `report_outline.json`（人工确认后的文案脚本），不直接碰数据库。

## 页面规格（实测自原文）

| 项 | 规范值 | 说明 |
|---|---|---|
| 页面宽度 | **943px**（`--scale 1` 默认） | 与原文完全一致。勿默认用 2x：1886 宽的图在公众号 677px 正文里字号视觉上只有原文一半 |
| 每屏高度 | 2000px（封面 1600px） | 原文每屏约 2000 |
| 左右边距 | 42px | 原文实测 40-45 |
| 上边距 / 底部预留 | 60px / 96px（页脚区） | |
| 内容宽度 | 859px | |
| 右侧装饰 | 10px 贴边渐变竖条（#1E3A8A→#3B82F6，纵向） | 原文有 |

## 字号表（实测自原文，943px 宽下）

| 元素 | 字号 | 补充 |
|---|---|---|
| 章节编号胶囊 | 26px | 深蓝底白字，圆角 12 |
| 章节标题 | 38px 粗体 | |
| 副标题 | 23px | 灰 #6B7280 |
| **正文段落** | **27px / 行高 1.85（≈50px）** | 两端对齐，段距 18px，每行约 30 字 |
| 数据卡数值/标签 | 36px / 19px | KPI 与分位数卡 |
| 图表标题(cap) | 21px | 卡片内居中灰字 |
| 图表轴文字/图例 | 19px | |
| 图表数值标签 | 21px | |
| 页脚 | 19px + 11px 圆点 | 机构名 + 页码指示 |
| 摘要判断卡标题 | **24px**（≤14字，单行） | 超长压缩文案，禁止浏览器随机折行 |

**章节页只有"编号+标题"两要素，不设副标题小字行**；结论由首段加粗句承担。

**每屏文字量基准：250-320 字（2 个段落）**，先文后图。这是"图文兼具"的配比：正文是深度分析，图表是证据。

## 配色

主色 `#1E3A8A`（深蓝）、次色 `#3B82F6`、强调 `#F97316`（橙）、辅助 `#06B6D4`（青）、卡片底 `#F5F7FB`、正文 `#1F2937`。图表调色板：`['#1E3A8A','#F97316','#06B6D4','#7C3AED','#3B82F6','#F59E0B','#94A3B8']`。强调规则：条形图 TOP2 用橙、柱状图最大值用橙、加粗数字用主蓝。

> 上面是**默认主题 zhengwu（政务藏青）**的取值。报告支持多套配色主题（见文末"主题库"），渲染时 `--theme <名>` 手选；色板数据在 `assets/themes.json`（编辑台可直接改），**只换配色不换版式**，热力图色带/图表调色板/封面渐变/总结框全套跟随主题，`render_check.py --theme` 像素判据与 `publish_draft.py --theme` 卡片封面同步。

## 屏类型与图表组织逻辑

大纲里每屏一个 `type`，渲染器按类型组装：

| type | 结构 | 用的角度 |
|---|---|---|
| `cover` | 渐变蓝封面：发布方/系列角标/主标题/副标题/数据 chips/落款 | — |
| `kpi` | KPI 卡 2×2 → 段落正文 → 橙色口径说明卡 | 数据概览 |
| `chart` | 段落正文 →（可选 stats 数据卡）→ 主图（+可选副图） | 城市/赛道/城市×赛道/学历/经验/薪酬/速览表/关键词/趋势 |
| `duo` | 段落正文 → 左右双图（饼图 + 条形图） | 岗位结构 |
| `notes` | 说明块列表（来源/口径/核验/免责）→ 蓝色联系方式卡 | 研究说明 |

图表 `kind` 共 8 种（选型规范见 `references/chart-gallery.md`）：`hbar`（横向条形）、`vbar`（纵向柱）、`donut`（环形）、`pie`（小饼）、`heatmap`（城市×赛道热力矩阵，600px 高，**ECharts 数据必须传 [列,行,值]**）、`funnel`（仅限真实转化漏斗，**禁止用于学历分布**）、`line`（仅限真实时间序列）、`table`（HTML 数据表：主蓝表头/斑马纹/名次徽章/末列橙色高亮）。图表数据直接内嵌在大纲 JSON 里，渲染器不回查数据库——**改大纲即改图**；每张图卡底部带一行来源脚注（数据来源：优才知路｜样本 N｜统计周期），口径细节集中末页"研究范围与方法"。

## 渲染管线

HTML 模板（内联 CSS，微软雅黑）→ Edge 无头截图（`--virtual-time-budget=6000` 等 ECharts 画完）→ 每屏一张 PNG → 可选拼接长图（PIL 纵向拼接，输出 PNG+JPG q88）。

输出：`output/report/pages/page_NN.png`（943 宽，单屏）、`report_full.jpg`（长图，微信上传用 JPG 更稳）、`manifest.json`。

## 修改入口

| 想改什么 | 改哪里 |
|---|---|
| 某屏文案/数据/增删屏 | `output/outline/report_outline.json`（改完重跑渲染即可，不动代码） |
| 字号/边距/配色 | `render_report.py` 顶部 CSS 常量区 + 字号表 |
| 新图表类型 | `chart_js()` 加一个 kind 分支 |
| 新屏类型 | `render_screen()` 加一个 type 分支 + gen_outline 生成对应段 |
图的位置：单图在第一段后，多图靠后但都在总结框前

## 主题库（多套配色，人工手选；2026-09 新增）

**用法**：渲染时 `python scripts/render_report.py --theme <键名>`；质检 `render_check.py --theme <同名>`；推草稿 `publish_draft.py --theme <同名>`（卡片封面同步）。默认 `zhengwu`，与历史报告完全一致。色板存 `assets/themes.json`（编辑台可改，改完重跑渲染即可，不用动代码）。

**原则**：①只换配色不换版式——943px、字号、屏类型、图表形态全部不变（一套版式多种配色，FT 式品牌一致性）；②热力图色带、图表调色板、封面渐变、总结框/洞察框、斑马纹、准入高亮区**全套跟随主题**，不允许"主题换了一半"；③"橙色语义"在各主题里由 `accent` 承担（"最值得注意"项专用）；④封面插画等图形元素不随主题变色；⑤同一系列报告中途不换主题。

| 键名 | 主题名 | 主色/强调 | 感觉与适用场景 |
|---|---|---|---|
| `zhengwu` | 政务藏青 | 深蓝 `#1E3A8A` / 橙 | 默认。政府报告、综合产业观察 |
| `deep_purple` | 深空紫 | 紫 `#4C1D95` / 青 `#06B6D4` | 前沿科技专题：AI/大模型/机器人/低空经济；系列多期后换装区分 |
| `bamboo` | 青竹绿 | 青绿 `#0F766E` / 橙 | 生态语义行业：新能源/环保/农业/生物医药 |
| `crimson` | 绛红典雅 | 深红 `#7F1D1D` / 金铜 `#B45309` | 年度盘点、政校合作、金融财经；庄重场合 |
| `ink_gold` | 墨金年鉴 | 墨黑 `#1C1917` / 金铜 `#B45309` | 高端峰会、白皮书、年度特刊；黑底金铜封面 |
| `warm_sand` | 暖沙杂志 | 深赭 `#7C2D12` / 橙红 | 职教故事、人物/院校专题；米纸底 `#FAF6EF`（唯一换页面底色的主题），人文软性题材 |

**themes.json 每套主题的完整取值**（新增/修改主题照此结构填全，缺一不可）：

- `primary/secondary/accent`：主色/次色/强调——章节胶囊、表头、条形底色、TOP2/峰值强调
- `text/sub/head`：正文/次要灰/标题字色；`page_bg`：页面底色（一般纯白，暖沙例外）
- `card/insight_bg/zebra`：图卡底/洞察框底/表格斑马纹
- `sbox_bg/sbox_title/sbox_text`：章末总结框底/标题/正文；`zone_bg`：准入矩阵★高亮区
- `cover1/cover2/cover3`：封面渐变三停点；`glow1/glow2`：封面两个光晕；`chip_num`：封面 chips 数字色
- `chart_palette`（7 色系列调色板）、`heat`（热力图 4 停色带，浅→深）、`pie3`（小饼 3 色循环）、`funnel`（漏斗 6 色）、`line_grad1/2`（折线面积渐变两端）

**对照约定**：一个主题只用一个"深色系"（primary 同族）承载量级，一个"暖/亮色"（accent）承载注意力；`heat` 色带最深停与 primary 同族。新增主题流程：themes.json 建好全套取值 → 渲一页样页人工过目 → 再进正式报告。
