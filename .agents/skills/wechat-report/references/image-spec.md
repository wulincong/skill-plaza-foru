# 报告图片规范（现行）

本文件与 scripts/chart_layout.py、render_report.py 为当前代码契约。历史参考报告仅用于版式研究，不覆盖本规范。

- 设计宽度943px，左右边距42px；页面按字体就绪后的实际内容测高，不设固定页高，不裁掉文字以适应页数。
- 正文38px，章节标题47px，图注30px，主要坐标轴约25–26px，密集计数/矩阵标签21–24px，来源25px。颜色来自assets/themes.json；按图元密度明确缩放，不把增加输出倍率当字号优化。
- 图形优先使用ECharts的SVG渲染器再截图为PNG；提高输出倍率不改变正文在相同显示宽度下的视觉字号。
- 横向排名图按数量降序；薪酬分档保留区间顺序，必须说明不等宽分档不是密度直方图。计数可用带数值的面积、气泡或关联图元；全篇仅允许一张联合三指标的柱状组合图。比例必须有绑定分母和值，不能自动把数值改成百分比。
- 分位区间图线段表示P25至P75、圆点表示中位数，单位K/月；有效样本不足三十的组不进入该图。仅呈现分布，不解释为学历或技能带来的因果回报。
- 热力矩阵按数据维度调整高度；长标签换行，不能删掉后半部分。颜色和数值方向需一致；大纲cells是行、列、值，ECharts需转成列、行、值。
- 双图采用纵向排列保证移动端字号，不压入固定小面板。表格按实际行高排版，章节长文可以长页，后续必要时再做保持语义的分页。
- 渲染器必须收集图表实例就绪、SVG图元、页面边界、正文横向溢出、图表标签越界与实际尺寸；发现错误即停止。manifest绑定图片指纹，最终质检后打包。
- 公开成品为有序PNG与纯图片网页。分析、排版数据、SQL和核查表只留内部。成品图片末尾应保留来源、时间、口径和局限。

程序检查不能替代最终图片的人工观感验收；本期不声称已检查全部文字重叠或完成OCR语义核验。


参考文献、资料来源与方法说明等 notes 正文使用左对齐并允许长网址在任意位置换行。不要对含长网址的说明段落强制两端对齐，以免把上一行少量中文拉开成大字距。图后分析正文仍遵循原有版式。
