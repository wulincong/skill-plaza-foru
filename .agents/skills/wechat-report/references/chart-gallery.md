## 二、已支持的图表类型（kind 配置即用，V3 扩充至 12 种）

选图必须先过 `scripts/chart_recommender.py`（FT Visual Vocabulary 规则代码化）：
构成类最大份额 >85% → 强制 `bignum` 大数字卡，禁饼/环；>7 类禁环形；排名必须有序。
2026-11 起构成类图表已由大纲的 `composition` 投影自动选型（`bound_report.py`），
`verify_data.py` 数据阶段再以 `check_chart_choice` 复核；本节规则即其执行依据。

### 1. `hbar` 横向条形 ✅ — 排名对比
```json
{"kind": "hbar", "caption": "在招岗位数 · 城市TOP10", "unit": "条", "top": 2,
 "data": [["深圳", 7496], ["广州", 3196]]}
```
规范：类别轴 19px；值标签 21px 右侧；`top:2` 前两名橙色；`pct_label:true` 时显示占比标签；`highlight:"本科"` 指定单条高亮。适用：城市排名、细分方向、关键词频次（≤15 条）。

### 2. `vbar` 纵向柱状 ✅ — 分布形态
```json
{"kind": "vbar", "caption": "月薪区间分布", "pct_label": true,
 "data": [["5-10K", 4.2], ["10-15K", 12.3]]}
```
规范：最大值橙色、其余主蓝；标签顶部 21px；类别名 ≤6 字。适用：薪资直方图、经验分布。

### 3. `donut` 环形 ✅ — 多分类构成（5-7 类）
```json
{"kind": "donut", "caption": "技术赛道分布", "data": [["大模型/生成式AI", 4600, 32.1]]}
```
规范：环形 46%-72%，图例右侧竖排"名称 占比"；中心不放文字（改用屏内 stats 数据卡）。适用：赛道构成。

### 4. `pie` 小饼 ✅ — 3 类以内小构成
```json
{"kind": "pie", "caption": "岗位性质", "data": [["社招", 13956], ["实习", 300]]}
```
规范：双图并排（duo 屏）时用；<3% 的扇区不显示引导标签。适用：岗位性质。

### 5. `heatmap` 热力矩阵 ✅ — 双维交叉（参照用户参考图1）
```json
{"kind": "heatmap", "caption": "城市 × 技术赛道：各城市内部岗位占比（%）",
 "rows": ["深圳 7,496", "广州 3,196"], "cols": ["大模型/生成式AI", "计算机视觉"],
 "cells": [[0, 0, 31.2], [0, 1, 18.5], [1, 0, 25.0]]}
```
规范：单元格=行内占比（每行口径独立，行合计≈100%）；色带浅蓝→深蓝（#EFF6FF→#1E3A8A）；单元值白色描边圆角、18px；行标签带城市岗位量；类别名按"/"换行。**渲染器将大纲 cells[行,列,值] 换位为 ECharts 的 [列,行,值]——曾因未换位发生行列转置（数据对图错），render_check.py 会用色深矩阵秩相关复检**。适用：城市×赛道、学历×岗位性质等交叉。**解读只说结构差异，不说时间动态（"扩散"需多期数据）**。

### 6. `funnel` 漏斗 ✅（受限使用） — 仅限真实转化漏斗（参照用户参考图3）
```json
{"kind": "funnel", "caption": "XX环节转化率（%）",
 "data": [["投递简历", 100], ["初筛通过", 45], ["入职", 8]]}
```
规范：**数据必须是同一批体的逐级转化（单调不增）**，色带深蓝→橙；标签右侧引出。**禁止用于学历/经验分布**——学历结构不是漏斗过程，各级之间无转化关系（P0 教训：曾用"累计可投递漏斗"包装学历门槛，语义误导，已禁用）。学历分布用 `hbar` + 职教岗位池数据卡。

### 7. `line` 折线 ✅（受限使用） — 真实时间序列
```json
{"kind": "line", "caption": "月度XX量（条）",
 "data": [["2025-10", 823], ["2025-11", 905]]}
```
规范：平滑曲线+渐变面积；峰值橙色标注；月份旋转。**仅限真实业务时间序列（如首次发布时间）**——`update_time` 含批量同步伪影，禁止用于招聘趋势（P0 教训：单月占90%+的批量更新被误读为"持续释放的常态化需求"）。月度计数建议用柱状/直线折线，不用 spline 平滑。

### 8. `table` 数据表格 ✅ — 多指标并列（参照用户参考图3的文本矩阵）
```json
{"kind": "table", "caption": "重点细分方向人才需求速览",
 "columns": ["细分方向", "在招岗位", "占比", "薪酬中位数"],
 "rows": [["图像算法", "3,876", "27.1%", "25.0K"]],
 "rank": true, "align_num": [1, 2, 3], "hot_col": 3}
```
规范：表头主蓝底白字 21px；斑马纹偶数行 #EDF2FA；`rank:true` 前三名橙/深蓝/浅蓝徽章；数值列右对齐等宽数字；末列默认橙色高亮；"—"表示样本不足（薪酬样本<30 不出数）。适用：赛道×（岗位量+占比+薪酬）、城市×（岗位量+薪酬+代表企业）等多指标速览。**每份报告至少一张表格**，信息密度最高。

### 9. `bignum` 大数字卡 ✅（V3） — 极端不均衡构成
```json
{"kind": "bignum", "label": "在招岗位为社会招聘",
 "top": {"name": "社招", "count": 13956, "pct": 97.6},
 "rest": [{"name": "兼职", "count": 231, "pct": 1.6}]}
```
规范：96px 大数字+迷你比例条+次要项小卡。**FT 规则：最大份额 >85% 的构成型数据禁用饼/环图**（标签必然拥挤），改用本形态。

### 10. `scatter` 散点/气泡 ✅（V3） — 量价对照
```json
{"kind": "scatter", "caption": "细分方向：岗位量 × 薪酬中位数",
 "data": [["算法研究员", 3507, 23.5, 4355]], "unit_x": "在招岗位数（条）",
 "unit_y": "薪酬中位数（K/月）"}
```
规范（V6）：**气泡按方向分色（调色板循环），底部图例两行内排布"色点+方向名"；取消每个气泡顶部的文字标签，仅岗位量最大的1个气泡保留名称标注**；气泡大小=第三变量；纵横轴均为数值。适用："量大"vs"价高"这类二维定位——分色+图例是 FT/BBC 处理多系列散点的标准做法，零重叠零歧义。

### 11. `heatmap` 复用为 LQ 矩阵 ✅（V3） — 专业化指数
`"unit": "×"` 时单元格显示 `1.85×` 这类指数。LQ=本市赛道占比÷全省占比，>1 高于全省平均；适合"区域分工"叙事（学 UK GOV 的 Location Quotient 分析）。

### 12. `table` 复用为准入矩阵 ✅（V3） — 学历×经验门槛
`"hot_cells": [[3,0],[3,1],...]` 高亮职教可进入区域（橙色★），配合 `hot_col:-1` 关闭默认末列高亮。单元格=岗位数；这是"两道门槛是否同时放松"的直接答案。

## 四、配图组织原则

1. **一报告 ≥4 种图表形态**：条形/环形/柱状之外，必须有 热力矩阵、漏斗、表格、折线 中的至少 2 种，避免"全是柱状图"的单调感。
2. **每屏图随文走**：图表 caption 与正文结论呼应；正文里提到的数字，图里必须看到。
3. **同一维度不重复用同一形态**（如赛道已用环形，速览表就按另一指标排序）。
4. **表格优先于多系列图**：当指标超过 3 个（量/占比/薪酬/增速），用表格而不是塞满一张图。
5. **颜色语义一致**：橙色只给"最值得注意"的项（TOP2、峰值、高亮列）；深蓝为主、浅蓝为辅；不用红色系表达负面向未发生的事。

### 13. `map_choropleth` 分档填色地图 📋 — 地区空间对比（升级第三节同名条目）
示例图：`chart-examples/ref_01_城市版图对比.png`（各省 GDP 分档填色，8 档棕红色带 + 区间刻度图例 + 省名/数值标注）。
- **适用**："岗位都集中在哪"的空间答案——广东省 21 市在招岗位量、某赛道岗位密度、LQ 专业化指数上地图。比 hbar 排名多了地理直觉：双核引领、梯度集聚一眼可见。
- **数据前提**：市级聚合值（共享查询适配器已产出 city 维度）+ 广东省市级 GeoJSON 注册 ECharts 地图组件；**必须配南海诸岛角标（地图合规红线）**。
- **要点**：`visualMap` piecewise 分 5-8 档蓝色系（深=量大，与我们主色一致；不用参考图的红棕系）；城市名+数值 label；只有地级市粒度时不画区县；某档样本<30 的市归"样本不足"灰档。与 hbar 排名配套用（地图给空间，hbar 给精确名次）。
- **延伸**：两个年份/两个行业各一张并排（duo 屏），色带同档对比——"版图对比"的本义。

### 14. `sankey` 桑基流向 📋（升级第三节同名条目，含组合面板用法）
示例图：`chart-examples/ref_02_桑基漏斗.png`（2×3 组合面板：2 个桑基 + 1 个数据大字 + 3 个漏斗变体）。
- **适用**：**流向/归属结构**——城市→岗位性质、技术赛道→学历层次、行业→职能。"深圳的岗位流向了哪些性质/学历档"这类二段归属用桑基，比交叉热力图更强调"从哪来、到哪去"。
- **数据前提**：双维交叉计数表（city×track、track×edu 等现有聚合直接可用）。
- **要点**：ECharts `series.type='sankey'`；**节点 ≤8×8**（防意大利面线）；只取头部节点、长尾合并为"其他"；线色取源节点色半透明；节点标签左侧。漏斗变体（居中/左对齐）仍受第 6 条约束：**只用于真实转化，禁止包装学历分布**。示例图的面板排法（桑基+大字+漏斗同屏）可用于"方法论"屏。

### 15. `range_dot` 分位区间图 📋 — 分布全貌（中位数 + 带宽）
示例图：`chart-examples/ref_03_中位数图A.jpg`（按行业：细线=中间80% P10-P90，粗条=中间50% P25-P75，圆点=中位数）；`ref_04_中位数图B.jpg`（同形态按学历六档分组，空心圆点标中位数，副标题注明口径"税前工资折月"）。
- **适用**：**薪资分布对比的完全体**——比只报中位数多出"带宽"信息：同样中位 20K，P10-P90 是 12-35K 还是 18-24K，含义完全不同（前者"上限靠机遇"，后者"稳定预期"）。两张参考图是同一形态的两种分组：按赛道（图A）看行业价差、按学历（图B）看同一赛道内的学历阶梯。
- **数据前提**：每分组薪资样本的 P10/P25/P50/P75/P90——现有 min/max_salary 取 (min+max)/2 作岗位点估计后分组计算即可；**样本<30 的组不出**（与 table 口径一致）。
- **要点**：横向每行一组、按 P50 降序；细线 2px（80%区间）+ 粗矩形（50%区间）+ 圆点（中位数）三层；横轴单位 K/月、起点含 0 或标注截断；副标题必须写清口径（"税前月薪、取岗位薪资区间中值"）；图B 行序固定"学历从高到低"。ECharts 用 custom series 或 overlay（line+bar+scatter 同轴叠加）实现。
- **配套叙事**：图B + 第 16 种 delta_matrix 组合使用——B 看分布全貌，16 看"每升一档多挣多少"。

### 16. `delta_matrix` 相邻组差额×倍数矩阵 📋 — 增量收益（增值倍数图）
示例图：`chart-examples/ref_05_增值倍数图.jpg`（19 行业 × 5 组相邻学历对；单元格上行=月差额、下行=倍数；蓝色深浅=正差额、橙色=负差额、灰字"未公布"；脚注写清差额/倍数定义）。
- **适用**：**"值不值"问题的直接答案**——每升一档学历/每多要 3 年经验/城市升一线，中位数多多少、是几倍。比罗列各组中位数更有决策价值（读者真正想问的是增量）。
- **数据前提**：相邻分组中位数（可算）；差额=前组−后组，倍数=前组÷后组（**倍数分母为 0 或样本<30 时显示"—"，禁止出∞**）。
- **要点**：复用 `table` 渲染路径扩展条件着色；**双色语义与我们全局规则对齐：正差额=蓝系深浅、负差额=橙色**（橙=值得注意，含"倒挂"警示）；单元格双行排版（上行差额大字、下行"×1.8"小字）；脚注固定句式"差额=前组−后组；倍数=前组÷后组；样本<30 不出数"。

### 17. `small_multiples` 小型倍数时序面板 📋 — 多组×多期分布演变（工资变化图）
示例图：`chart-examples/ref_06_工资变化图.jpg`（18 行业 × 4 年 网格；每子图浅色带=中间80%、深色带=中间50%、黑线=中位数；副标题"各图同轴"；底部标各年中位数数值）。
- **适用**：N 个分组各自的时间演变横向扫读——"哪些行业带宽在收窄、中位数在抬升"。一图装 18 组×3 层信息而不乱，靠的是**同轴+重复形态**。
- **数据前提（硬约束）**：**多年份独立、均匀采样的薪酬样本**。当前数据库 update_time 非均匀（SKILL 注意事项 2），**本期禁用**；待积累多期独立采样（如按季度重跑入库）后启用。
- **要点**：ECharts 多 `grid` + `series.gridIndex`；**全部子图共用同一 x/y 轴范围**（"各图同轴"是可读性前提，否则变成 18 张独立的图）；子图标题 20px 置左上；每子图底部小字标各期中位数；单页 18-24 子图为上限。

### 新增选图速查（衔接第一节）

| 分析目的 | 问题示例 | 首选图表 |
