# 现行图表选择与能力边界

选图必须由生成代码调用chart_recommender.py和已绑定投影，不依赖Pi自行实现临时图表。图表类型多少不是验收指标，不为凑种类添加无数据图。

|目的|现行路径|规则|
|---|---|---|
|城市、学历、经验、方向、关键词比较|hbar|数量降序；长标签换行；计数标注条|
|招聘类型构成|composition投影→bignum/pie/donut/hbar|使用完整分母重新计算份额，最大份额超过85%用大数字卡；过多类别用横条|
|薪酬分档|vbar|保留区间顺序；不等宽分档标明是分类计数，非连续密度直方图|
|方向薪酬分布|range_dot|P25–P75线段及中位数点；有效薪酬样本≥30；无足够组时保留小样本说明表|
|学历×经验、城市×方向|table|绑定实际交叉计数，表格不冒充流量过程|
|方向×技能|heatmap|方向内提及率；技能可重叠，不把一行相加为100%；标签完整|

散点、折线、真实过程漏斗保留显式渲染分支，当前默认人才报告不自动选它们。未知kind立即报错。没有真实时间序列不画趋势，没有同一批对象的逐级过程不画漏斗。

地图、桑基、差额矩阵、小倍数图尚未接入本技能，不能因为共享Skill文档列出了它们就声称可直接生成。共享chart-visualization的行政区资源和证据原则可复用，但其HTML/SVG独立报告契约与本技能PNG截图交付属于不同输出适配层，不向Pi同时注入互相矛盾的绘图指令。

像素参考图仅作研究资料，不能搬运其数字、趋势、因果结论或水印。本期统一字号、动态尺寸和质检规则以image-spec.md为准。
