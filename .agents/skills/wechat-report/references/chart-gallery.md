# 多维人才报告图表

当前wechat-multivariate/1要求整份报告至多一张柱状图：city_combo联合城市薪酬中位数、本科要求占比、岗位规模；地区是比较维度。薪酬分母与全部岗位分母分开标明，不将学历要求解释为学历因果回报。

| 研究比较 | 视图 | 必要证据与边界 |
|---|---|---|
| 城市需求与岗位定位 | 上下对齐的柱状/比例点组合 | 城市薪酬+城市学历，同城基数对账；n为全部岗位，薪酬另列有效量 |
| 学历与经验如何叠加 | 门槛连接图、条件点图、气泡矩阵 | 同一完整交叉频数；连线不是人员流动，经验上界桶不累加 |
| 岗位方向规模与薪酬 | 矩形面积图 | 面积为方向岗位数、色深为中位数；未分类与小薪酬样本单列 |
| 薪酬区间与有效量 | 分位线段+中位点 | 线为P25–P75、点为中位数、大小映射有效量；不画成置信区间 |
| 城市方向结构与集中度 | 气泡矩阵、LQ点图 | 同范围城市×方向全频数；相对份额不代表增长或因果区位优势 |
| 方向与能力组合 | 双部关联图、提及率矩阵 | 提及频数/方向内比例；词可重叠，不表示人才流量 |
| 候选入口的方向定位 | 多维散点 | 池内中位薪酬、方向进入池比例、池内规模；不是录用概率 |

图形由joint_report_charts/joint_chart_layout与统一渲染器产生，未知/缺失独立保留，比例分母有定义。小图元可用最小可见尺寸，大小映射不能被口头解释成精确面积比；图内编号对应完整图例。无足够统计时保留研究缺口，不为凑图型编造关联。

实际浏览器系列、矩阵方向、区间端点、可见标签、DOM越界和PNG指纹一起验收。ECharts完成事件与字体就绪后截图；视觉检查仍要看字是否可读、裁切和分析是否对应图。公开网页与ZIP只含最终图片。
