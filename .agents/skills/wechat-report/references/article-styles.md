# 文章导语（总结）风格库 — build_article.py 及人工撰写参考

> 用途：公众号文章开头"总结/导语"怎么写。**不模仿任何特定公众号**，形成自己的风格库。
> `build_article.py` 内置 3 种可直接生成（`--style data|voc|scene`），其余风格供人工撰写或后续扩展时参照。
> 写作方法论参考：摘要四要素（目的-方法-结果-结论）、引言五部分（背景→综述→空白→目标→结构）、研究机构报告的"研究亮点+核心数据"结构。

## 通用规则（所有风格共用）

1. **数字全部来自 report_data.json**，禁止凭印象写数；写完跑 `verify_data.py` 溯源。
2. **读者是中职/高职院校**的师生、专业负责人与管理层：导语必须让职教读者看到"这个产业与我有关、我有通道"。
3. **数据来源口径**只写"岗位数据来源于优才知路平台的数据库"，不出现任何外部渠道名称。
4. 导语正文 300-500 字（不含图片），让读者不点开报告也能带走 3 个结论。
5. 固定收尾：价值段 → 金句 → 联系方式（brand.json）→ "阅读报告全文"+分屏图。
6. 标题公式 `产业观察|《地区+行业+人才需求观察报告》发布`（≤32 字）；摘要取核心信号第 1 条（≤120 字）。

## 风格 1 · 数读速览式（默认，`--style data`）

**结构**：三个大数字开局 → 一句话点题 → 报告介绍 → 3 个核心信号 → 职教通道段 → 价值 → 金句。
**适用**：绝大多数数据报告；信息密度高，适合"干货型"读者。
**要点**：开局数字要挑最有冲击力的三个（总量/企业数/覆盖率），用顿号并列，破折号引出主题。

> **范文**（数字以当期 report_data.json 为准，下同）：
>
> 1.43万条在招岗位、5089家招聘企业、21座城市——过去365天，广东省人工智能岗位市场的三个切面。《广东省人工智能产业人才需求观察报告》把这三个数字背后的结构拆开给你看。
>
> 这份报告由产业人才数据观察课题组联合优才知路发布，岗位数据来源于优才知路平台的数据库，从企业真实招聘需求反推产业人才变化。
>
> 数据呈现出几个值得关注的信号：
>
> 1.深圳、广州两市招聘记录占全省样本74.8%，广东人工智能人才需求呈现明显"双核引领、周边梯度集聚"特征；
> 2.通用算法工程等四大技术方向合计占80.8%，研发岗位依旧是主战场，但数据标注/AI训练（3.5%）、应用落地等岗位已形成完整的人才需求链；
> 3.岗位薪酬中位数达22.5K/月，推荐算法方向中位数37.5K/月领跑，高薪背后，企业更看重"来了就能打仗"的实战能力。
>
> 更值得职教圈关注的是：人工智能产业并非只有"高学历算法人才"这一条就业通道。值得一提的是，要求大专及以下学历的AI岗位占比达到9.2%（1316条）……

## 风格 2 · 院校视角式（`--style voc`）

**结构**：以职教读者的问题开场 → 报告给出回答（观点先行）→ 信号与通道 → 价值。
**适用**：面向职业院校推送、招生季/就业季节点；读者代入感最强。

> **范文**：
>
> 人工智能产业，中职、高职的学生进得去吗？这是很多职业院校老师、学生和家长最关心的问题。产业人才数据观察课题组联合优才知路发布的《广东省人工智能产业人才需求观察报告》，用1.43万条在招岗位的真实数据给出了回答：**进得去，而且通道清晰。**
>
> 报告基于广东省1.43万条人工智能相关在招岗位记录，围绕城市分布、技术赛道、岗位结构、学历经验、薪酬水平及能力关键词进行系统分析。
>
> （后接核心信号与职教通道段，同风格 1）

## 风格 3 · 场景切入式（`--style scene`）

**结构**：一个真实工作场景白描 → 场景与数据挂钩 → 报告介绍 → 信号。
**适用**：想让文章"有人味"、转发率高时；切忌场景里编造数字（场景可以泛化描写，数字必须落到报告数据）。

> **范文**：
>
> 一间数据标注车间里，几十名年轻人正给图像打标签、为模型"喂"数据——他们中的大多数，来自职业院校的人工智能技术应用等专业。这样的一幕，正在广东省的智能工厂与数据公司里反复上演。它背后对应多少岗位机会？产业人才数据观察课题组联合优才知路发布《广东省人工智能产业人才需求观察报告》，用数据说话。
>
> 报告基于广东省1.43万条人工智能相关在招岗位记录……（后接核心信号）

## 风格 4 · 问题清单式（人工撰写参照）

**结构**：抛 3 个具体问题（不是抽象疑问）→ "报告对这三个问题都给出了数据答案" → 每问一段带数字作答。
**与风格 2 区别**：不预设立场，用问答推进；问题要具体到"哪类学生、哪类岗位"。

> **范文（开头两段）**：
>
> 高职学历能投人工智能岗位吗？哪些城市对中职生最友好？数据标注员算不算入行AI的第一步？这三个问题，《广东省人工智能产业人才需求观察报告》都用数据给出了答案。
>
> 先说结论：大专（含高职）及以上学历即可投递96%的在招岗位；东莞、佛山等制造业强市的落地型岗位浓度高于深圳；数据标注/AI训练类岗位1316条在招、经验不限与应届通道合计占比可观——它们正是职业院校毕业生的起跳板。

## 风格 5 · 政策呼应式（人工撰写参照）

**结构**：一句产业/职教政策背景 → 数据印证 → 报告价值。适合与"产教融合、数字化转型"等政策节点联动推送。
**注意**：政策表述要泛化准确（如"职业教育法修订、产教融合政策持续加码"），不精确引用文件号，避免政策日期出错。

> **范文（开头两段）**：
>
> 产教融合、职业教育适应产业升级，是近年政策反复强调的方向。对人工智能这样的新兴产业，职业院校到底有多大空间？产业人才数据观察课题组联合优才知路发布《广东省人工智能产业人才需求观察报告》：1.43万条在招岗位中，大专及以下学历岗位占9.2%，叠加学历不限岗位，职业院校毕业生的对口空间是真实存在的。
>
> 报告基于广东省1.43万条人工智能相关在招岗位记录……（后接核心信号）

## 风格 6 · 趋势判断式（人工撰写参照）

**结构**：观点先行（一句可辩论的判断）→ 用数据论证 → 引出报告。适合系列报告的第 N 期、有了历史数据对比后使用。

> **范文（开头两段）**：
>
> 人工智能产业的用人结构，正在从"金字塔"走向"陀螺"：顶尖算法人才仍是塔尖，但支撑产业转起来的是大量应用、部署、数据训练人才。这个判断来自产业人才数据观察课题组联合优才知路发布的《广东省人工智能产业人才需求观察报告》——1.43万条在招岗位显示，本科及以上占87.5%，但大专及以下与学历不限岗位合计超过12%，且数据标注/AI训练类岗位需求稳定。
>
> 报告基于广东省1.43万条人工智能相关在招岗位记录……（后接核心信号）

## 风格 7 · 榜单悬念式（人工撰写参照）

**结构**：用一个"第一名"数字勾住 → 拆解排名 → 报告介绍。慎用：榜单容易标题党，数字必须严谨。

> **范文（开头两段）**：
>
> 广东省哪座城市最缺人工智能人才？答案是深圳——7496条在招岗位，一城占了全省的一半还多。但真正的机会可能在榜单之外：东莞、佛山正在承接越来越多的落地型岗位，它们对学历更友好。

## 风格选择建议

| 场景 | 推荐风格 |
|---|---|
| 日常发布、追求信息密度 | 数读速览式 |
| 推送给职业院校师生/招生就业处 | 院校视角式 |
| 想提升转发率、故事化传播 | 场景切入式 |
| 答疑式选题（学历/城市/岗位怎么选） | 问题清单式 |
| 政策节点、产教融合会议前后 | 政策呼应式 |
| 系列报告第 2 期起、有同比数据 | 趋势判断式 |
| 城市榜/薪酬榜等单点数据突出时 | 榜单悬念式 |

## 分享卡片摘要（digest）写法 — 2026-09 补充

> 本节细化上文"摘要取核心信号第 1 条（≤120 字）"的旧口径：**摘要不再抄分点信号**，改为专门写一句"钩子句"。摘要是聊天卡片、预览链接里标题下方那行小字，和标题、缩略图一起决定打开率。

**公式**：时间范围/身份钩子 + 一个问题或断言 + 数字承诺。

- 硬限制：≤120 **字节**（一个汉字 3 字节，约 40 个汉字）；数字必须可溯源（同导语规则）。
- 例（好，实测用于机器人报告）：`过去365天，广东的机器人产业要什么人？报告把2392个岗位拆给你看。`
- 例（差）：`2392条在招岗位、1437家企业、21座城市，广东省机器人产业人才需求全景拆解。`——数字罗列没有钩子，且与标题、封面数字三处重复。
- 反面模式：抄正文第一句（卡片和正文开头一模一样，读者没有点开的理由）；照搬核心信号第 1 条（"1."开头出现在卡片上很生硬）。
- 摘要要**补标题没说的信息**：时间跨度、读者收益、悬念问题，三选一。
- `publish_draft.py` 不传 `--digest` 时默认取导语段并按标点优雅截断；重要稿件建议显式 `--digest` 写钩子句。
- 与摘要配套的缩略图规范（900×900 卡片封面合成）见 `wechat-publishing.md` 第四节。

## 质量自检（导语生成后）

- [ ] 开头 2 行内出现至少 1 个数字（风格 3 除外，其数字须在第 2 段出现）
- [ ] 3 个核心信号各有数字、互不重复角度
- [ ] 职教通道段完整：大专及以下占比+条数、入门经验通道占比、"值得一提的是"句式
- [ ] 全文无外部渠道名称；数据来源只写"优才知路平台的数据库"
- [ ] `python scripts/verify_data.py` 通过（数字溯源无 UNVERIFIED）
