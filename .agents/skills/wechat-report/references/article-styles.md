# 公众号开篇与短导语

参考：MJL629/Official-Account-Skill 的 `wechat-report/references/article-styles.md`、`copywriting.md`（授权仓库，参考提交 286cee93072e1b8e8539a88b80487967440a2f74）。采用“开篇引入—三个数据信号—阅读价值—完整图片报告”的编辑结构，避免把所有图片文字再抄一遍。

开篇约五百至八百字。每个信号在同一段里融合判断、数据和解释；数据来自当前范围，观点不得跨省套用。全文只在一处说明来源和研究边界。短摘要补充文章标题，避免流程口吻、虚构联系人、增长趋势或人才缺口。

移动端采用深蓝标题、暖色细线、足够行距和少量浅底块。正文左对齐，完整报告图片统一放在导语之后。广场分享页仍只展示图片。

下面是程序实际读取的样式规则。默认按地区和产业稳定选择四种适用的开篇方式；政策、趋势、具体场景需要独立材料支持，不因标题自动生成政策效果、产业因果或时间变化。

```json
{
  "schema": "wechat-article-styles/1",
  "defaultStyles": ["data", "voc", "question", "ranking"],
  "styles": {
    "data": {"label":"数读速览","hook":"{positions}条岗位，读懂{region}{industry}的人才需求","opening":"岗位机会集中在哪里，企业设置了哪些进入条件？本次从{companies}家招聘企业的在招记录出发，把城市、岗位方向、学历经验和薪酬放在同一张观察地图中。"},
    "voc": {"label":"人才视角","hook":"{region}{industry}，人才从哪里切入？","opening":"产业名称很大，真正的求职与培养决策却落在具体岗位上。本次观察{positions}条在招记录，重点辨认机会分布、进入条件和工具要求，连接岗位画像与人才准备。"},
    "question": {"label":"问题切入","hook":"{region}{industry}的机会，怎样看得更具体？","opening":"先看城市还是先看岗位？高薪方向是否也有足够的入口？围绕这些具体问题，本报告以{positions}条在招记录为基础，串起招聘格局、门槛、薪酬与能力组合。"},
    "ranking": {"label":"格局切入","hook":"{region}{industry}：规模排名之外，还有哪些线索？","opening":"招聘量能帮助找到机会密集区，但进入条件、薪酬分布和方向结构还会改变岗位选择。本次从{companies}家招聘企业的在招记录中，提炼值得一起看的三个信号。"},
    "scene": {"label":"场景切入","hook":"从岗位现场读懂{region}{industry}","opening":"围绕实际工作任务阅读岗位，才能把产业概念转化为可比较的选择。本报告观察{positions}条在招记录，结合另行核实的业务场景讨论人才要求。"},
    "policy": {"label":"政策呼应","hook":"从产业背景走向{region}{industry}岗位观察","opening":"公开产业资料提供背景，岗位数据提供当下可观察的招聘结构。两类证据分别阅读，才能辨认政策方向与企业岗位之间有哪些可以继续研究的连接点。"},
    "trend": {"label":"结构观察","hook":"{region}{industry}的岗位结构，有哪些值得关注的信号？","opening":"本报告从当前岗位快照观察规模、条件和能力组合。结构差异提供进一步研究的线索，时间趋势仍需独立的多期证据支持。"}
  }
}
```

`article_content.build_lead` 在生成时读取本文件并记录指纹；导语随大纲重新验算。`build_article.py` 与真实草稿桥消费同一份导语，保持预览和后台内容一致。
