# 当前分析约定

以 `report.py` 和原生报告工具为生成入口。当前分析使用 `wechat-analysis/2`、`wechat-analytic-reasoning/2`，融合段落使用 `wechat-editorial-prose/3`。用户只审核图片成品。

## 同口径证据

所有岗位量、比例、薪酬分位和交叉比较均由保存的地区结果计算。企业关联地址用于地域筛选，不能直接称为实际工作地。职教入门池保留已声明的学历与经验条件交集，不代表全部毕业生。单城、单学历和空交集分别处理，不借用其他地域或人群补齐。

本地官方资料由 `regional_research.py` 按地区与产业选择，保存来源、统计期、性质、原文证据和绑定指纹。政策目标、已发布统计和应用构想分别保存。默认使用有效期内已对照原文的资料；显式刷新有请求超时与总预算。没有适用资料时不借用别省数据。

## 摘要与正文

摘要页是一段摘要和三条分结论，每条在同一段中融合测量、解释和判断。城市结论比较总量与条件匹配，薪酬结论讨论对应岗位区间与求职预期，方向结论同时观察分类岗位量和方向内入门条件覆盖。课程广覆盖与专项项目依当地结构分支处理，不能只替换省份名。

标题、事实选择、结构解释、研究范围以及融合段落的数字由程序重算。Pi 仅填写各章 action 和核心阶段的 closing；内部边界、判断条件和核心融合文字由程序完成。方向薪酬、城市方向、相对集中与方向能力章节的建议须包含本章实际比较对象，不能改用全省排名替代。模型文本不能另写测量数值，Unicode 数字同样受校验；观察到的工具名称等实体标签可保留。学历、薪酬或城市名称不能直接决定技术任务层次。

任务提供按本地城市、方向和能力词选择的项目示例。文案连续两次校验失败时，采用对应项目文本恢复，并通过同一校验；拒绝改写受保护事实，记录恢复原因，不放宽质量规则。原生工具调用总数有上限，构建失败保留进度并停止循环。

每章短评聚焦本章证据对读者的意义，最后集中讨论任务、学习产出与合作。方法边界集中到研究方法页。成品不写待核验、待审核、占位或内部流程。

## 可追溯性

`report_research.json` 保存本地资料快照；`report_analysis.json` 绑定同口径聚合；正文数量投影绑定来源路径；构建收据记录脚本与资料目录指纹。参考文献位于成品末尾，官方原文标题完整保留。修改建议回到写作输入后重新构建，不能直接修改 HTML 或 PNG。

历史分析仅兼容读取，不自动成为新版默认缓存。新版缓存使用 `education-readable-editorial-v4.2`，自定义筛选保持独立范围。

摘要中的职教入门口径给出阅读指引，完整条件在方法部分逐项列出。数据规模接近但条件覆盖不同的方向采用差异化路径；不把原始岗位量与入门条件覆盖混为同一排序。非交互文本审校可通过Pi的无工具调用执行，批注必须再与真实证据核对，不能自动充当审核结论。

公开短评另检查证据范围：不从提及比例推断偏好、重要性或熟练度，不从条件交叉推成影响机制，不增加本章未测量的城市交叉结论。旧文案重新组装时，只替换违反这些边界的短评，并在 analysis.editorialRepairs 记录原因；事实、范围和数量不变。
