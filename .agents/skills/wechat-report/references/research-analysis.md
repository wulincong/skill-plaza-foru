# 当前分析约定

以report.py和原生报告工具为唯一入口，当前成品使用wechat-analysis/2和wechat-analytic-reasoning/1。内部排版结构由程序生成，不给用户审核大纲。

受信字段：各章title、findingIds、interpretation，核心opening及三项claims的title、findingIds、interpretation。它们从保存统计和analytical_reasoning.py重算，不能由模型改写。工资分位相对位置、单城/单学历范围、可选入门池、分类覆盖和相对集中度均按实际数据分支处理。assemble会重新规范这些字段，拒绝手改analysis绕过规则。

Pi可编辑字段：每章action、validation、decisionRule；三项claims的implication、核心closing与limitations。行动应具体到院校/企业对接团队、目标岗位和可交付清单或项目；验证应说明真实岗位原文、企业反馈、实际接收条件或学生作品怎样核查；调整条件应说明哪些结果会改变当前安排。不把统计表字段完整当成企业实际需求已经验证。

核心发现按总体判断—三条跨维度论证—综合启示组织。每条由二至三项不同维度事实支持，不能只放排名清单。总体与目标人群薪酬不得互相替代；上四分位是区间边界，不是薪酬上限；学历、经验和薪酬都不能直接测量技能难度。条件满足不等于录用，单城筛选不等于集聚，词频不等于能力深度或课程缺口。新调查可提出待验证机制，不能把机制写成已观测事实。

任何建议变更都回到写作输入或原生工具，再build；禁止直接修改报告HTML、PNG或report_analysis.json。旧wechat-analysis/1仅供历史结果兼容，不进入新版默认成品缓存。
