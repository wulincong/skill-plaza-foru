# 微信公众号人才需求报告

按地区、产业和读者生成一组有顺序的报告图片。适合院校或园区在公众号上解释一个具体的人才需求问题。

## 发起任务

先明确地区和产业，然后给出读者与希望作出的决定。有学历、经验或岗位名称限制时也要写清。比如「人工智能产业」与「岗位名称含人工智能」对应不同范围。

```prompt
给广东省高职院校的专业负责人做一份人工智能产业人才需求图片报告。希望比较入门岗位的学历、经验和薪酬结构，用于决定下学期校企实训的重点。请直接生成图片成品。
```

## 核对成品

若想比较两个城市、却只有一地的同口径岗位数据，会先让你选择补齐另一地、调整比较范围，或只写已有地区。选定范围后会继续生成，摘要先回答读者的问题，各页用同一份数据解释结论。

从对话里的网页入口按顺序阅读成品，或下载图片压缩包。先核对封面的地区和产业，再看每张图的单位、样本范围和结论。薪酬分位数描述样本分布，不能直接作为个人求职报价；单城报告中的结构也不能直接推到全省。

## 修改或存为草稿

在同一对话引用具体的图或结论，说明想保留什么、想调整什么。

```prompt
保留原统计范围，把课程建议改为面向实训教师。
```

若把地区从广东改为广州，则需要按新范围重新取数。希望保存到公众号草稿时，再明确确认保存；审核后发布由公众号运营者完成。


## 设计原则与报告逻辑

先确定地区、产业和目标人群，再使用同一范围的岗位数据分析城市分布、学历经验、薪酬、方向与能力要求。地域来自企业关联地址，读者可在研究方法页查看完整筛选、读取时间与统计单位。

摘要先概括报告，再用分点把数据、解释和结论连成完整段落。城市结论关注条件匹配后的对接对象，薪酬结论使用对应岗位区间，课程结论兼顾方向规模与适用条件。任务安排依据岗位职责和学生作品，不由学历或薪酬直接推断能力层次。

报告将本地官方资料用于产业语境与应用场景，并在文后列出参考文献。广东、山东、浙江、江苏、湖北、福建已有适用于人工智能或智能制造的地区资料；其他范围按可取得的证据呈现。政策目标与已实现统计分别说明，省级背景保持省级口径。国家统计局研发投入用于创新环境背景，与平台招聘样本分别解释。

生成过程连续完成分析、绘图和排版。相同范围可复用有效的报告成品；改变地区或人群时按新范围生成。报告中的数字与图片来自同一份统计结果。

## 阅读新版报告

正文从招聘格局、岗位入口、学历经验门槛、薪酬、方向和能力组合展开。摘要用分点融合数据与判断；相关的学历经验、城市方向和能力图表合并阅读，减少重复。培养与校企合作建议集中放在结尾，各章不再套用相同的教学实施总结。

广东的人工智能、机器人、智能网联汽车、跨境电商、智能硬件、直播电商和半导体已声明各自的分析规则。相同省份与产业可复用有效成品；改变地区、条件或分类规则时使用对应证据，旧版成品继续保留。

公众号收到的是带标题、短摘要和封面的报告卡片，点击后仍为纯图片报告。确认保存草稿后，后台文章采用短导语在前、完整图片在后的形式；导语不会把图片文字再复制一遍。重复保存同一版本会复用原草稿。
