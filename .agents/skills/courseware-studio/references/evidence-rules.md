# 证据与安全操作细则

状态：已实现（校验落在 `scripts/spec_model.py`，交互落在 plaza-question 协议）。

## 逐页出处

1. 出处单位是「材料 + 页码/条目」：`sources: [{materialId, pages, note}]`。教材给页码（`p.58–60`），指导书给任务号（`任务三·安全须知`），课标给条目号（`GQT-3.2`）。
2. 事实性页型（objectives / intro / concept / diagram / procedure / safety-warning / quiz / rubric / summary）sources 必填；封面、目录豁免。测验题的每道题在表格中带出处列。
3. 页脚短标注由 `slide_source_line` 截断生成；完整出处（含 note）在网页预览侧栏与附录「材料与逐页出处总表」页。
4. 引导性文字（过渡句、提问）不需要出处；只要陈述课程事实（定义、参数、步骤、数据）就必须有。

## 课证对齐

1. `standards` 只登记教师提供的条目（T05 课程标准或教师粘贴），逐条带来源说明；模型不得自拟课标编号。
2. 每个知识点要么挂 `standardId`，要么 `extension: true`（页内渲染为「拓展」标签，附录不混入课标覆盖统计）。
3. 学习目标页优先直接使用课标行为动词原文；改写时保持可对照。

## 安全强制位

1. 触发条件：课件涉及设备操作、用电用火、化学品、高空/受限空间等实训内容。触发时必须在实训演示页之前插入 `safety-warning` 页。
2. `safety-warning` 页同时满足：callout(warn) 警示卡、`safety.items` 逐步骤清单、`pendingConfirmations` 的 `safety-order` 条目。步骤必须来自实训指导书/教材原文，顺序不得凭经验调整。
3. 确认交互：首轮交付校订稿后，正文按顺序逐条复述安全步骤，再发 plaza-question `confirm` 卡。教师答复「确认」才在 spec 写 `confirmations` 并 `final: true` 重建；答复「调整」按新顺序修订并再次确认。
4. 校订稿阶段所有产物带「校订稿 · 待教师确认」标记；不删除标记、不提前定稿。

## 素材与版权

1. 图片来源仅限：教师上传图片、教材 PDF 提取图（material_tools images，保留页码）。外部图库与生成图片一律不用。
2. 示意图（流程、原理框图）用 steps/two-col/表格等结构块表达；确需图形时标 `schematic: true`，渲染为「示意图，非设备实图」。
3. `copyright` 覆盖所有引用素材：内容、来源材料、授权说明（如「课堂合理引用（校内教学）」「教师自备并授权使用」）、状态。授权不明标 pending，在档案与预览中提示教师确认。
4. `resources` 登记生成过程中产出的可复用资源（流程图、评分表、案例、图片），供课程资源库后续入库；登记项写明来源（「依据实训指导书任务三生成」）。

## 缺口处理

材料未覆盖的要点用 `gap` 块：写清缺什么（如「教材图 4-5 电子版缺失」）与建议补充方式。gap 不算失败交付，但必须在首轮回复中汇总告知教师；教师可选择补材料或按占位定稿（后者在 confirm 卡中一并确认）。
