# 智能课件生成

面向任课教师的课件生成智能体：把您允许使用的教材章节、教案、实训指导书与自带素材，变成**课证对齐、逐页出处可查**的课堂教学课件。生成可编辑的 PPTX 成品与网页预览版；涉及实训安全操作的内容，逐条列出待确认清单，您确认步骤顺序后才导出定稿。

## 它适合做什么

- 按教学单元生成完整课件骨架：学习目标、任务导入、知识讲解、实训演示、课堂测验、小结与考核评分表。
- 每个知识点挂接课程标准条目；没有对应条目的内容明确标注为「拓展」。
- 每页事实性内容标注出处（教材页码、指导书任务号、素材提供方），网页预览侧栏与附录页可逐页核对。
- 实训设备操作、用电用火、化学品内容自动插入安全警示卡，并进入教师待确认清单。

## 开始前需要准备

| 材料 | 是否必需 | 说明 |
|---|---|---|
| 教学单元主题与课时数 | 必需 | 例如「工具坐标标定，2 课时」 |
| 允许使用的材料范围 | 必需 | 教材章节、教案、实训指导书、课程标准条目；电子版直接上传 |
| 学生程度说明 | 可选 | 影响讲解深度与测验难度 |
| 课件风格偏好 | 可选 | 简约蓝 / 暖橙 / 墨绿 / 黑白打印 |
| 教师自备素材 | 可选 | 设备照片、企业案例（图片支持 png/jpg/webp） |
| 课程标准条目 | 可选 | 粘贴条目编号与原文，用于课证对齐 |

只给主题、未给材料范围时，智能体会先向您索要材料，不会用模型记忆补课程事实。

## 交付物

1. **课件成品（PPTX）**：可在 PowerPoint / WPS 中直接编辑。
2. **课件网页预览**：浏览器打开，键盘翻页，侧栏含逐页出处、材料范围、版权授权、待确认与资源入库清单。
3. **课件档案（Markdown）**：版权与授权状态清单、教师待确认清单、资源入库清单。
4. 材料未覆盖的要点以「待教师补充」占位呈现，并在回复中汇总告知。

## 使用方式

在在线对话输入 `$` 选择「智能课件生成」，或直接粘贴示例提示词后上传材料：

```prompt
$courseware-studio 为《工业机器人现场编程》单元「工具坐标标定」生成 2 课时课件。允许材料：教材第 4 章 4.1–4.3（已上传）、实训指导书任务三（已上传）、课程标准 GQT-3.2 / GQT-3.3 条目（见附文）。学生为高职二年级，风格用简约蓝。
```

## 工作过程与确认环节

1. 读取您上传的材料并按页建立出处索引。
2. 知识点结构化并挂接课标条目，生成课件骨架与页面内容。
3. 构建校订稿（PPTX + 网页预览 + 档案）交付给您核对。
4. 涉及实训安全时，回复中逐条列出安全步骤顺序，通过确认卡请您核对：确认无误即导出定稿；需要调整则按您的意见修订后再次确认。
5. 定稿后附录页与档案中的确认清单显示「已确认」，生成资源入库清单供课程资源库登记。

## 边界与须知

- 课件内容只来自您允许的材料；材料未覆盖的要点标注待教师补充，不以通用知识顶替。
- 图片只用教师素材与教材原文图；示意图明确标注「示意图，非设备实图」，不生成图片冒充设备实图。
- 涉及实训安全的内容未经您确认步骤顺序，不会导出定稿。
- 教材为扫描件（无文本层）时无法提取文字，请提供文字版或改用教案材料。

## 验收建议

拿到校订稿后建议按四步核对：① 网页预览侧栏逐页抽查出处是否指向您给出的材料与页码；② 核对知识点课标挂接是否正确；③ 重点核对安全警示页的步骤顺序是否与实训指导书一致；④ 在 PowerPoint / WPS 中打开 PPTX 确认可编辑与排版。全部无误后再确认定稿。
