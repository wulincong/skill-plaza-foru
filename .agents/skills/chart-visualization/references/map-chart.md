# 行政区地图

用地理位置展示覆盖范围、地区分类或区域指标。专门展示省内岗位记录数时，选[城市热点图](heatmap-chart.md)。

- 图表标识为 `map-chart`。按[离线资源说明](../resources/README.md)先按省份定位资源包，再按该包编码体系匹配本级单元和边界。每个着色区域都应能追溯到对应记录。
- 标明范围、单位及每种颜色的含义。未覆盖或未返回的区域用中性色。实际为零的区域只有在图例标明零值时才用最低数据色。
- 缺少对应边界或编码时，图块标“未评估”并给出原因。仍有可靠的地区数值时，可另用排序柱状图展示。

全国尺度按省比较数值时可直接用 `province-map`，输入列和色阶见[独立图稿规格](figure-spec.md)。
