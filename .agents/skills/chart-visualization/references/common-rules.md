# 通用绘图规则

## 数据与图注

- 图注明确来源、观测单位、统计范围和筛选条件。实验图写测量条件、独立样本和重复测量的区别。数据库切片写适用地区、查询日和快照日，缺少快照日时注明。
- 比例给出分母和有效样本数。分数或权重说明量表和方向。归并“其他”前核实总量和类别是否可加。
- 分清实测零、缺失和整项未评估。断线、独立的缺失色或未提供区间的点，分别表达相应状态。整图没有依据时给出原因。
- 写清一条线、一个点、一段区间分别代表什么。样本离散程度、估计精度和预测区间各有含义。图注须与分析方法一致。

## 报告嵌入

1. 从独立成品取出完整的 `<figure>`，或按专题规则生成含内联 SVG 和可见 `<figcaption>` 的图块。设置 `data-chart-skill` 和报告内唯一的 `data-chart-id`。每次嵌入使用不同的规格 `id`，使 SVG 内的 ID 也保持唯一。
2. SVG 提供 `role="img"`，用 `aria-labelledby` 关联本图的 `<title>` 和 `<desc>`。使用可读数值、摘要或数据表，让读者能从颜色以外的线索读图。字体和样式须支持离线展示。
3. 交付前对照原数据核对实际位置、长度、线宽或单元格。报告的标签结构检查只覆盖图块协议。未评估图块保留图表标识，增加 `data-chart-status="unassessed"`，在图注写原因并省去 SVG。
