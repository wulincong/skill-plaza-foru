# 桑基图绘图 Skill

用于展示两类节点之间的流向关系，例如技能演进路径：左侧传统技能、右侧新兴技能，连线宽度表示演进关联强度（关联岗位规模、共现度或迁移权重）。

先读取 [通用图表规则](common-rules.md)：统一处理来源、筛选、快照、分母和小样本说明。

输出要求：

- 使用 `<figure data-chart-skill="sankey-chart" data-chart-id="CH_SANKEY_xxx">`。
- 包含 `<figcaption>`，写明图名、流量语义（宽度的定义与单位）、筛选口径、数据来源与快照日期。
- 使用内联 `<svg viewBox="0 0 760 440" role="img" aria-labelledby="...-title ...-desc">` 绘制：节点用矩形、连线用水平方向的三次贝塞尔曲线路径，连线宽度与流量数值成比例。
- 加入 `<title>`、`<desc>`，`<desc>` 中用文字描述主要流向（例如“传统技能 A 主要演进为新兴技能 B 与 C”）。
- 左右两个阶段固定：左侧为来源侧（如传统技能），右侧为目标侧（如新兴技能）；阶段语义在 figcaption 或列标题中写明。
- 单图节点总数不超过 20（左右合计）；超限时按流量取每侧 TOP 并把其余归为“其他”，并在 figcaption 说明归并规则。
- 每条连线的流量必须可追溯：来自岗位库查询、内置证据文档或明确标注的分析推断；推断权重的图必须在 figcaption 写“流量为分析推断”。
- 节点标签直接标注在矩形旁；空间不足时用引出线，不得省略标签。目标侧可用颜色区分技术领域并配图例。

## 色彩要求

- 图形主体**禁止整体呈灰色或深灰蓝单色调**：来源侧节点与目标侧节点各用一种可区分的高辨识度色相（如来源侧蓝 `#1f6feb`、目标侧橙 `#c2410c`，或按技术领域分配色相），饱和度明显区别于背景。
- 连线用对应来源节点的**半透明同色系**（如 `fill-opacity 0.35–0.5`），随目标侧色相渐变或保持来源色，不得使用灰色／黑色线。
- 灰色（如 `#64748b`）仅允许用于"其他"归并节点或未评估状态；正文文字色（如 `#0f172a`）不得作为图形填充色。
- 节点色与连线色需在图例中说明语义。
- 缺少流量数据时不绘制无依据的连线；整图无数据时使用未评估状态块。
- 图下保留流向排序的文字版（如“传统技能 → 新兴技能（强度）”）作为可访问回退。

## 未评估状态块

整图无法评估时，使用：

```html
<figure data-chart-skill="sankey-chart" data-chart-status="unassessed">
  <figcaption>…桑基图未评估：<可读失败原因或数据缺口>…</figcaption>
</figure>
```

不绘制无数据的 SVG 几何。
