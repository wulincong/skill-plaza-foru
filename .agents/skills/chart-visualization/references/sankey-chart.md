# 桑基图

用两列节点展示从来源到去向的关联。图表标识为 `sankey-chart`，图编号可用 `CH_SANKEY_1`。

- 每行输入包含来源、去向、非负权重和依据。图注说明线宽代表的量和单位，例如“同时要求两项技能的岗位数”。共现只能说明关联。如果权重来自推断，在图注写“流量为分析推断”。
- 左右各画一列矩形节点，列标题说明两端含义。用水平贝塞尔曲线连接，线宽与权重成正比。节点旁直接写名称，空间不足时用引出线。
- 两侧用易区分的色相，例如来源蓝、去向橙。连线沿用来源色并设为半透明，图例说明配色。灰色只用于“其他”或未评估项。
- 两侧合计最多 20 个节点。超限时按每侧总权重保留主要节点，将剩余节点归入该侧“其他”，合并同向连线并说明规则。图下按权重列出主要流向和数值。
- 跳过缺少依据的连线，说明缺口。整图没有可用权重时，输出未评估图块。
