# 雷达图绘图 Skill

用于多维指标对比，例如新兴技术成熟度分析：把每项技术按技术成熟度、产业影响力、人才缺口、生态完善度等维度放在同一雷达图中比较。

先读取 [通用图表规则](common-rules.md)：统一处理来源、筛选、快照、分母和小样本说明。

输出要求：

- 使用 `<figure data-chart-skill="radar-chart" data-chart-id="CH_RADAR_xxx">`。
- 包含 `<figcaption>`，写明图名、维度定义、评分口径（刻度范围与归一化方式）、数据来源与快照日期。
- 使用内联 `<svg viewBox="0 0 760 440" role="img" aria-labelledby="...-title ...-desc">` 绘制：同心网格多边形至少 3 层、维度轴从中心等角放射、每个数据多边形描边并半透明填充。
- 加入 `<title>`、`<desc>`，并在图例或标签旁写明每个维度的取值。
- 维度数量 3–8 个；维度超过 8 个时拆成多张雷达图，不压缩刻度。
- 单图最多叠加 3–4 个数据多边形（用可区分的颜色与图例）；技术项更多时按评分或优先级分面为多图，每图重复完整口径说明。
- 所有维度使用同一刻度（建议 1–5 级），不得每轴自定义范围；同一张图内不混用计数与评分。
- 每个评分点必须可追溯：来自岗位库查询、内置证据文档或明确标注的分析推断；figcaption 或随图表格写明每个维度的证据等级。
- 某维度无数据时该维度标“未评估”，不得画成 0 分中心点；整项无数据时不生成图。
- 图下保留同维度评分表或排序文字版，作为可访问回退；不得只输出表格替代图。

## 未评估状态块

维度或整图无法评估时，使用：

```html
<figure data-chart-skill="radar-chart" data-chart-status="unassessed">
  <figcaption>…雷达图未评估：<可读失败原因或数据缺口>…</figcaption>
</figure>
```

不绘制无数据的 SVG 几何。
