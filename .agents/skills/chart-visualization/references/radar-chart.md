# 雷达图

比较多个对象在同一组维度上的评分，例如技术成熟度、产业影响力和人才缺口。图表标识为 `radar-chart`，图编号可用 `CH_RADAR_1`。

- 每图 3–8 个维度、最多 4 个对象。超限时拆图，各图保留相同的量表说明。同一张图的各轴使用相同范围（建议 1–5 分），图注说明维度、评分方向和归一化方法。
- 维度轴等角排列，至少绘制三层网格。每个对象用独立描边、半透明填充和图例，图下附逐项评分表或文字排名。
- 每个分数保留依据和证据等级，区分查询结果、文档记录与分析推断。按报告要求在图注、评分表或开发侧证据中记录，读者应能看出评分依据。
- 缺少某个分数时在表中标“未评估”，图中保留缺口，不连成完整多边形。整图没有可用评分时，输出未评估图块并说明缺少哪些依据。
