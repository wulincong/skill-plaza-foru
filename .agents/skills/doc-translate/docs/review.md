# 怎样核对一份双栏译文

先从原文挑一页同时包含跨栏标题、图和图注的页面。用小节名和图号定位译文中的对应内容，即使重排后页码已经变化，也能逐项核对。

| 检查对象 | 核对方法 |
| --- | --- |
| 阅读顺序 | 从左栏末段读到右栏首段，看是否仍属于同一段论述。 |
| 图片与图注 | 找到相同的图号，核对原图的坐标轴和图例是否完整，再读译文图注。 |
| 术语与公式 | 选一个反复出现的术语和一个公式，核对译名、变量、单位及上下标。 |

如果发现问题，在原对话说明原文页码、小节名、图号和需要调整的内容。

```prompt
第 4 页图 2 的图注中 capacity 指电池容量，请统一这个译法。
```

新文件生成后再检查该处，并保留确认过的版本。
