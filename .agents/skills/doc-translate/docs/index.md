# 文档翻译

把带文本层的 PDF 译成指定语言，保留原图、翻译图注，并生成可下载的译文 PDF。适合翻译课件、论文和技术资料。

## 提交前检查

在原件里试着选中并复制一段正文。准备一份可提取文字、可打开的 PDF，单个附件最多 6 MB。写明目标语言，可附上课程术语或产品名的指定译法。需要节选时注明 PDF 中的页码范围。

> 将附件第 2–5 页译成简体中文，保留图 1 和图 2，把 controller 统一译为「控制器」。请保留原有的双栏和小节层级。

## 查看交付

提交后，在当前对话的资源中打开或下载译文 PDF。核对段落顺序、图注编号和术语，尤其注意跨栏表格和行内公式。图片里的文字随原图保留，图注进入翻译范围。译文变长时会重新分页，同一幅图可能移到相邻页。

## 输入受限时

图片型扫描件需要先准备带文本层的版本。加密文件请提供有权使用的可提取版本。文件过大可以按完整章节拆分，分次上传，并在每次任务中沿用同一份术语表。
