# 岗位智能匹配

为学生决定优先投哪些岗位、为什么适合、还缺什么。目标岗位必需，城市选填，未填时不传city、按不限城市查询，不猜测学生所在地；薪资、工作性质、行业、学历、毕业状态、经验选填，简历可上传或粘贴，补充说明承接个性化约束。已有信息直接使用，不重复询问。不承诺录用。

## 查询候选

只用原生工具 job_candidates，接口为 https://job.foru-ai.com/api/business/front/lookForWork/queryListForPage。按表单的“岗位接口筛选”JSON原样提交 filters；自然语言请求按本技能 references/dictionaries.json 选择真实Key。选“不限”的字段通常省略，学历/经验的BUXIAN为上游真实编码。请求由工具填顶层size/current，自动分页去重，最多100条，不把API默认10条当成全部。

工作性质传positionType。毕业状态没有独立接口字段：经验未选择时，在校/应届映射experience=ON_CAMPUS/GRADUATING；明确经验选择优先，毕业状态仅作个人画像。学历查询是岗位要求的精确筛选，不是学生最高学历自动覆盖所有低门槛岗位；学生只写本人学历但未明确要求筛选时，用于匹配，不擅自限制接口。薪资档位用真实字典，如LESS_THAN_5K为3–5k；不使用猜测的枚举或min/max交集规则。

resumePath只能用用户上传的uploads文件路径；resumeText逐字引用用户粘贴的简历摘要。简历只在会话本地处理，不能送给招聘平台。读取简历前先遵循附件路径说明；PDF没有文字或DOCX无法解析时请学生补文字，不编造经历。未提供简历时可以按条件推荐，skills/experience设null，不声称完整人岗匹配。

查询失败说明原因并等待用户选择，不用旧快照掩盖失败。返回空或候选不足100时用实际数量。需要放宽城市/薪资等条件先请用户选择；不自动改关键词扩围。不执行投递、收藏、联系或登录操作。

## JD与简历匹配

逐条阅读工具返回的所有候选JD，检查硬条件、结构化字段与正文冲突。列清“已证明、部分证明、存在差距、信息不足”。项目经验不自动当正式工作年限，未知不当零分。实习标题与全职字段冲突、经验门槛冲突、薪资结算不清时列待确认。

每个候选有四维0–4等级：skills技能40%、experience经历30%、direction职责方向20%、preferences偏好10%。等级含义：0明确不符、1明显差距、2部分符合、3大体符合、4有充分证据，未知null。程序计算分数，任何维度null时不输出完整总分。资格eligibility为pass（已核满足）、review（资格待确认）、exclude（明确不符）。优先pass，再按分排序，最多20条；不得按分数把明确不符合硬条件的岗位排入优先推荐。

只依据真实简历与岗位原文，不能臆造证书、年限、学历、项目成效。无简历时资格也须保留未评估，reason写明条件推荐。

## 构建报告

先写 job-assessments.json，完整内部格式见 references/report-format.md。填工具原样返回的snapshot/sha256、summary、全部候选的简短assessments。运行：

```sh
python3 <技能目录>/scripts/matching.py preview job-assessments.json
```

按程序返回的排序补齐前20个（或实际数量）details，每条有真实JD引文（只摘一条10–60字的短要求，避免复制整段和改写）、简历证据、差距和投递建议，再运行：

```sh
python3 <技能目录>/scripts/matching.py build job-assessments.json
```

不改写候选来源文件、请求或状态。来源已由工具管理，不用反复检查隐藏文件。每轮新建报告或改动筛选条件时重新调用job_candidates，不沿用上一轮候选快照。程序核对全部候选、排名、引文和来源指纹，用共享report-rendering minimal生成报告并登记delivery.json。正文开篇给结论，中段用JD和经历论证，结尾给投递顺序和适用条件。匹配度是规则分，不是概率；推荐不足20条不凑数。原始简历、电话邮箱、住址、内部文件不放公开目录；证据摘录避免联系方式，只保留相关技能和经历。报告含岗位真实详情链接和文末资料日期，不编造招聘状态、发布时间或薪资薪数。公开报告不出现检索条件、筛选参数、接口总数、去重数量或工具过程，summary也不复述这些过程。报告量化对比展示四维权重得分、综合分和已评估维度数，另列可优先考虑与资格待核验的岗位数量。所有指标由现有评估计算，未知不补零；不能编造录用率、成功率或技能命中率。

浏览器验收桌面/窄屏及链接，平台返回实际网页后才称交付。最终回复简短，不再复述整份20岗报告。不需要统计图时不凑图，不重复生成HTML和固定字段。
