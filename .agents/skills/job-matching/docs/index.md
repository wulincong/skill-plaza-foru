# 岗位智能匹配

填写目标岗位，可选填期望城市（留空不限城市），选择薪资、工作性质、行业、学历、毕业状态及工作经验，上传或粘贴简历，得到最多20个岗位的匹配报告。

## 查询与匹配流程

下拉选项显示招聘平台真实字典名称，提交对应Key。程序先查询最多100个去重候选，再对照每份JD和你的简历，检查条件、技能、项目与经历，计算匹配排序。少于100条就使用实际候选；不足20个合适岗位不凑数，需要扩大范围时先由你选择。

```prompt
使用 $job-matching，我想找广州市的前端开发实习岗位，有Vue课程项目经历。请根据我上传的简历查询最多100个候选，推荐最多20个岗位，说明匹配原因、能力差距和投递建议。
```

## 下拉字段的含义

工作性质包括实习、校招、全职、兼职。薪资按网站档位和K/月展示，3–5k与“5k以下”不同，奖金、薪数和实习结算以企业确认为准。学历选项筛选的是岗位要求，不是自动纳入所有低于本人学历的岗位。若希望不限岗位学历要求可不选，再用简历核验门槛。

毕业状态没有独立查询字段；未指定经验时，在校/应届使用接口对应经验Key。指定经验后优先采用经验筛选，毕业状态仍用于个人情况分析。行业“不限”和其他未选字段不额外限制结果。条件冲突或字段与正文不一致时会在报告中说明待确认。

## 报告包含什么

推荐结论、岗位量化对比、岗位排序清单，以及每个岗位的公司、城市、薪资、真实详情链接、JD依据、简历对应经历、能力差距和投递建议。文末保留资料日期与来源。报告不展示检索条件或接口过程，排序只适用于本次岗位资料，不代表全市场最优。量化对比包含技能（40分）、经历（30分）、岗位方向（20分）、求职偏好（10分）、综合分及已评估维度数；缺失维度标为未评估，不补零。

评分采用技能40%、经历30%、职责方向20%、求职偏好10%。明确不满足硬条件的岗位排除，资格不明的岗位标为待核验。任何评分维度信息不足时不显示完整总分，不把未知当零分。分数不是录用概率。

## 简历与证据边界

支持文字PDF、DOCX、TXT与Markdown简历，也可填写摘要。没有简历时仍可按条件推荐，但无法完整评估技能和经历。简历只在平台会话内处理，查询招聘接口仅传筛选条件；不把简历原文、电话、邮箱和住址放进公开目录。报告可能引用相关项目或技能摘录，分享前请确认内容适合公开。

## 设计原则和交付检查

先确定学生求职目标与约束，再查询真实岗位。区分接口和JD事实、依据简历作出的匹配判断与行动建议；来源不足、岗位已变或信息冲突如实提示。先回答优先投哪些岗位，中段逐岗论证，最后说明差距和行动。检查岗位ID去重、候选覆盖、字典、引文来源、评分排序、20条上限、链接与窄屏阅读。不会自动投递、收藏或联系企业。

接口和字典依据来自[优才知路招聘平台](https://job.foru-ai.com/)，2026-11-19已核实公开字典及分页。岗位有效性和薪资条件以企业最新说明为准。
