# 产教培养方案设计

**交付目标。** 按 [结构契约](references/program-contract.md) 生成 `program.json`，业务校验通过后构建方案正文、可编辑 Word、验证记录和 [T05 课程开发任务包](references/t05-package.md)，最终通过 [report-rendering](../report-rendering/SKILL.md) 交付可打开的网页并登记全部文件。任一[红线](references/redlines.md)不达标即阻断输出并说明原因；不以聊天摘要或业务构建完成代替最终交付。

**先补输入。** 必需项：专业名称与专业代码、办学层次与学制、服务区域（省/市）、目标产业范围。缺项逐项询问，不自行假设；「学院」不能自动解释为「高职」。可选项：上一版培养方案、本校办学条件说明（师资、实训室、合作企业）、订单班或产业学院约束——有则作为 sources 登记并在实施保障与课程设置中引用，未提供的实施保障条目标待补，不编造师资数量、实训室清单或合作企业名称。

**取数职责。** 岗位量、学历结构、薪酬区间等统计全部遵循 [talent-data-query](../talent-data-query/SKILL.md)：在线用 `talent_query` 提交地域、产业名称、真实筛选和所需指标，`talent_inspect` 核验。不写查询 JSON、SQL 或连接脚本。专业定位、岗位群、能力项、课程理由引用统计时按契约登记 metrics 与 binding，值由构建脚本回填核验。优先复用同会话、同范围、同口径的已核工件。

**岗位群与能力域。** 岗位名称只能来自查询返回、用户材料或标准职业面向原文。按「岗位群 → 典型工作任务 → 能力项」分解：岗位群区分初始岗与发展岗，workTasks 用真实工作过程语言，能力项归入能力域。每个能力项绑定至少一条真实查询口径或用户材料；样本量不足时说明已知、缺口和影响，用决策卡提供「补充材料」「扩大范围」「按现有证据继续」，结束本轮等待真实回复，不同时构建。用户明确选择继续才把原话记入 decisions，能力项标 insufficient。

**标准核对。** 国家专业教学标准逐要素核对遵循 [标准核对](references/standards-check.md)：环境提供知识库凭据时按 weknora-retrieval 检索原文；否则请用户提供原文或授权检索官方公开原文；都不可得的要素标 pending 并决策确认。标准条文一律以知识库或用户提供的原文为准，禁止凭记忆编写；培养目标与规格的校本改写在 note 说明依据。

**课程体系与证据链。** 课程按公共基础必修、公共选修、专业基础、专业核心（6–8 门）、专业拓展、岗位实习、综合实践分类；每门课的设置理由绑定能力域与岗位证据（rationale 引用可解析的 metricIds/sourceIds），能力支撑用 H/M/L 标注，每个能力项至少一门课程支撑。学时学分在契约中逐课填写，总数、占比与红线结论由脚本计算，不手填。

**红线校验与构建。** 用技能脚本绝对路径，不 cd 到技能目录。草稿先 `python3 <技能目录>/scripts/program.py validate program.json`；按 validation 输出修正结构与证据。定稿 `python3 <技能目录>/scripts/program.py build program.json`，产物在 `output/program-<短哈希>/`（正文、结构化方案、验证记录、T05 任务包、Word 与交付清单）。build 成功只代表业务交接完成。修订一律改 program.json 再重建，不手改产物；用户提供旧版时写 diff 逐项差异（附录 D）。

**需要人判断时询问。** 关键取舍——岗位群取舍、核心课程选择、学时结构方案、样本不足、标准待核对、校本红线覆盖——说清已知、备选与影响，问一个可回答的问题。支持决策卡时用单选或输入卡；缺证三选项固定。未获明确选择不出终稿，status 保持 draft；「请生成」、沉默都不等于授权带缺口定稿。所有关键取舍记入 decisions（含用户原话）。

**继续到最终交付。** build 后立即读取 report-rendering，把方案正文与结构化数据交给它完成网页；随后 `python3 <渲染技能目录>/scripts/register_delivery.py output/public/<站点目录> --name 培养方案网页版 --files-from output/program-<短哈希>/program-files.json` 登记网页与全部文件。只有平台产生真实网页入口才算交付成功；未成功说明停在哪一步并保留工件。最终回复简述结论、红线对照结果与未决项，使用平台返回的链接；不列工作区路径或工具过程。

**诚实边界。** 不编造数据、岗位名称、企业名称与合作事实；实施保障只引用用户材料。查询失败按查询技能状态停止，不自选降级。区分事实、推断与建议；证据支持与预期相反的结论时如实呈现（如区域岗位量不足以支撑该专业设置）。
