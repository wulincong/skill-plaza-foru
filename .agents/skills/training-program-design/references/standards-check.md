# 国家专业教学标准核对

国家教学标准条文一律以知识库或用户提供的原文为准，检索不到就标注待核对，**禁止凭记忆编写标准条文**。

## 标准体系背景

教育部 2025 年 2 月印发 758 项新修（制）订职业教育专业教学标准（中职 223、高职专科 471、职业本科 64），对接 2021 年版《职业教育专业目录》；每项标准含概述、专业名称（代码）、入学基本要求、基本修业年限、职业面向、培养目标、培养规格、课程设置及学时安排、师资队伍、教学条件、质量保障和毕业要求等要素。核对时按 `meta.majorCode` 找对应专业的标准，不拿相近专业的标准冒充。

## 核对顺序

1. **知识库**：环境提供 `WEKNORA_API_KEY` 与 `WEKNORA_KB_IDS` 时，按 [weknora-retrieval](../../weknora-retrieval/SKILL.md) 调用 `scripts/retrieve.py`：`bases` 确认授权库 → `documents --keyword '专业教学标准'` 定位文档 → `search --document` 检索要素 → `chunks` 翻页核对原文，记录文档标题、文档 ID、分块 ID 与序号。知识库盘点快照显示计算机类专业标准存于「纺织专业教学标准库」，库名比实际收录范围窄，先按主题检索再判断。
2. **用户提供**：用户粘贴标准原文或上传标准文件（`uploads/`），excerpt 逐字摘录，来源登记为该材料。
3. **均不可得**：要素标 `pending`，发起决策卡让用户选择：提供标准原文 / 授权联网检索官方公开原文（作为用户授权来源，引用须带官网 URL 与访问日期）/ 按待核对继续（draft 出稿，附录 C 列明）。

## 引用格式

standards 条目 status=verified 时，content 为原文摘录（与来源 excerpt 核对一致），sourceId 指向登记来源；知识库来源的 locator 写「文档标题 · 文档ID · 分块序号」，官网来源写 URL 与访问日期。培养目标、规格等改写内容写入方案正文时，条目 note 说明改写依据，原文摘录保留在来源里。

## 不得做的事

- 不凭模型记忆写「国家标准规定……」；未取到原文的要素只能标 pending。
- 不把相近专业（如「大数据技术」vs「大数据技术与应用」旧目录名）的标准当成目标专业的标准，目录版本差异要说明。
- 不把竞品平台或商业机构的转述当作标准原文。
