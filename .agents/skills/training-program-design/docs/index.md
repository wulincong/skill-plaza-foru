# 产教培养方案设计

面向高职院校专业负责人与教务处：以 696 份本地同类培养方案语料为底做对标设计，辅以服务区域的真实岗位统计与国家专业教学标准原文核对，生成或修订产教融合专业人才培养方案。每项岗位判断可回溯查询口径，每门课程可回溯能力与证据，学时学分对照国家红线硬校验，任一项不达标不会出稿。

## 需要准备什么

**必需**（缺项会逐项向你询问，不会自行假设）：

- 专业名称与专业代码（6 位国标代码）
- 办学层次与学制（如高职专科三年制）
- 服务区域（省、市）
- 目标产业范围

**可选**：

- 上一版培养方案（用于新旧版逐项差异对比）
- 本校办学条件说明（师资、实训室、合作企业）——实施保障章节只能引用你提供的材料
- 订单班、产业学院等特殊约束

## 工作流程

1. 补全必需输入（未提供院校名称时全文一律用「本校」，不出现具体校名）
2. **本地语料对标（主路径）**：按产业方向查本地培养方案语料库索引，精读不少于 3 份同类方案（不足 3 份不出稿），对标章节结构、课程体系、学时学分分配、课程简介写法与表述方式
3. 区域岗位轻量取证：按需一次性查询岗位量、学历结构、薪酬区间（真实人才数据库，口径可追溯），作为能力项证据补充
4. 岗位群 → 典型工作任务 → 能力域分解
5. 对照国家专业教学标准逐要素核对原文
6. 生成课程体系（公共基础 / 专业基础 / 专业核心 6–8 门 / 拓展 / 实践），每门课带课程简介与典型教学内容
7. 学时学分分配与红线校验、内容深度校验（任一不达标阻断）
8. 构建方案文档并渲染网页
9. 关键取舍以决策卡提交审阅
10. 版本归档，生成课程开发任务包（交课程开发环节）

## 学时学分红线与内容深度

对照教职成〔2019〕13 号：三年制总学时≥2500、实践性教学≥50%、公共基础课≥总学时 1/4、选修课≥10%、专业核心课 6–8 门、岗位实习一般 6 个月、每学年 40 周、16–18 学时计 1 学分。校本要求（如总学时上限、实习时长）按你提供的原话覆盖默认值。

内容深度同样硬校验：每门课程有简介与典型教学内容（核心课加严字数）、培养规格三维各至少 5 条、职业面向含初始岗与发展岗、教学实施与考核评价各至少 150 字、毕业要求至少 4 条、同类方案对标语料至少 3 份。任一项不达标，系统阻断输出并逐项说明原因——修数后重建，不会带病出稿，也不会交骨架加表格的空壳方案。

## 会收到哪些决策卡

- 区域样本量不足：补充材料 / 扩大范围 / 按现有证据继续（继续即标注待验证，不影响出稿但会列入待决清单）
- 标准原文不可得：提供标准原文 / 授权检索官方公开原文 / 按待核对继续
- 岗位群取舍、专业核心课选择、学时结构方案等关键取舍

未获明确选择不出终稿；你的每一次选择都会记入方案的编制说明。

## 怎么验收

打开网页版逐项核对：职业面向表中的岗位名是否与岗位库返回一致；附录 A 每条统计能否查到口径；核心课程的设置理由是否指向能力域与岗位证据；红线对照表是否全部通过。Word 版与网页内容同源，如需修改，回到对话提出修订，重新构建生成新版本。


## 设计依据

流程对标教育部 VEPPAgent（岗位数据驱动 + 合规校验）与行业通行的「岗位群→典型工作任务→能力分解」方法；红线数字核对自教职成〔2019〕13 号原文；正文结构对照 13 号文内容要素与公开院校真实方案样例。本地语料库来自产教语料第三批「培养方案」类 PDF 的 696 份清洗全文（2026-11-20 入库，按人工智能/智能制造/数字商科/智能网联汽车/具身智能五方向组织，带 sha256 索引）。详细依据见技能 references 目录（local-corpus、research-notes、redlines、program-contract）。
