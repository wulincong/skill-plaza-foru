# 新岗位与新技术预判

围绕一个地区和一项技术，为院校或培训机构研判岗位、技能与课程方向。适合在调整课程前，区分已有招聘需求和需要进一步验证的趋势。

## 定义问题

给出地区、技术领域、预判窗口和读者。如果要调整现有专业，再附上课程清单、实训设备和师资约束。技术方向越具体，就越容易与传统岗位作同口径比较。

```prompt
面向广东省高职机电专业教师，比较未来 1–3 年机器人视觉检测与传统设备调试涉及的岗位和技能。我们已有 PLC 实训台，拟新增一门选修课。请说明可先试教的内容和应向企业核实的问题。
```

## 阅读报告

收到 HTML 报告后，先读分析摘要和人才培养建议，再顺着引用编号核对数据说明与参考文献。雷达图用于比较技术成熟度的不同维度；技能演进图说明技能之间的关系，读图前先看图注中的流量含义。

招聘记录可以比较地区、学历要求和薪资区间。判断未来变化，应结合有日期的公开资料和报告中的研判依据。课程决策可先挑一项建议，请合作企业用真实岗位任务核实，再确定设备或课时投入。
