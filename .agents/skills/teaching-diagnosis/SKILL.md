# 学勤与教学诊断

**交付目标。** 完成一个周期的三层诊断（专业、教师/课程、班级），最终通过 [report-rendering](../report-rendering/SKILL.md) 交付可打开的诊断报告网页；用户确认授权后另交风险预警名单文件。周期口径、指标、措施与诊断正文写入会话档案，供下一周期同口径复诊。不以聊天摘要代替报告交付；关键问题等待用户时先停在询问，得到回复后继续。

**先对口径。** 从任务与数据确认诊断周期、覆盖班级或专业、读者角色，采用已明确的信息。时间范围或覆盖班级不明确、表内口径混用（跨学期、跨校区并存）会改变结论时，先用决策卡向用户确认，不猜。任何对比必须同范围、同分母、同时间口径；口径不一致的两组数据不并列比较，分开呈现并注明差异，除非用户明确确认可比。缺勤率、出勤率、及格率等每次出现都写明分母。

**数据接入与质量检查。** 必需考勤记录与成绩数据；评教、课堂行为、教学进度至少一项用于归因，缺项先说明对归因的影响，请用户补充或选择按现有证据继续。所有统计先运行技能脚本得出，不做心算：用 `python3 <技能目录>/scripts/analyze.py inspect uploads/<文件>` 逐文件检查列、编码、覆盖与缺失，把数据质量问题（缺列、重复行、日期越界、学号对不齐、口径不一致）先报告给用户并等待处理意见再继续。列名识别、格式容错与 config 写法见[输入识别](references/data-inputs.md)。

**单班诊断与归因。** 用 `analyze.py metrics` 生成三层指标，用 `analyze.py correlate` 计算缺勤与成绩、评教低分与教学结果的关联，结果存入 `analysis/`。每条归因结论写明分组、样本量与指标口径；分组样本量低于[分析规则](references/analysis-rules.md)门槛时只描述现状、明示样本量，不下归因结论。观察到的事实与据此的推断分开表述，相关性只写作"观察到关联"，说明方向与强度，不写成因果，并提示可能的混杂因素。不输出教师排名；教师层按课程与教学环节聚合呈现。

**三层报告。** 开篇回答本周期教学运行总体状况与最需要关注的问题；中段按专业、教师/课程、班级逐层给现状、归因与改进建议，每条结论附数据范围与样本量；结尾收束到建议优先级、适用条件与未决项。评教、行为或进度数据缺失的层如实写未评估及原因，不硬凑。图表按论证需要调用 [chart-visualization](../chart-visualization/SKILL.md) 绘制并复验，图注写明范围、分母与时期；成长档案仅在口径可比时绘制跨期趋势。

**隐私与名单。** 报告正文只出现聚合结果，不出现姓名、学号等可识别个体。风险预警名单默认不生成；周期数据中存在触发默认或用户阈值的个体时，主动以决策卡询问是否授权生成名单及所用阈值，等待真实回复。用户确认授权后，用 `analyze.py risk` 按确认的阈值生成，以独立 CSV 文件经 delivery.json 的 files 通道交付，不进入报告网页，交付说明提醒仅限授权角色打开。名单内容与表述边界见[分析规则](references/analysis-rules.md)。

**改进建议与决策卡。** 建议逐条绑定诊断证据、适用对象与核验办法。成稿后以决策卡（plaza-question）提交建议清单，让管理者逐项采纳、调整或暂缓；单卡选项不超过 12 项，超出分组多轮。用户回复后把采纳结果与调整意见写入本周期档案 `archive/<周期ID>/measures.json`；未经确认的建议只标待定，不写成已采纳，不替用户批准任何措施。

**复诊与成长档案。** 每个周期把口径元数据、指标、措施与诊断正文存入 `archive/<周期ID>/`（目录结构与 schema 见[档案约定](references/archive-schema.md)）。下一周期用 `analyze.py compare` 与档案对比：只并列同口径指标，范围、分母或口径不一致的拒绝并列并说明；受干预的组与未受干预的对照组分开呈现，注明对照口径。跨会话复诊接受用户上传的上一期报告或指标文件。成长档案按周期累积，趋势结论同样受口径纪律约束。

**继续到最终交付。** 业务内容经用户确认后，立即读取 report-rendering，将诊断正文、指标与图表规格完整交接，依该技能验收并登记 delivery.json（报告网页进 web，授权名单文件进 files，同一清单）。只有平台产生真实网页入口才算交付成功；未成功时说明停在哪一步并保留工件，不能声称已交付。最终回复简述结论、建议与未决项，使用平台生成的访问与下载入口，不列工作区路径、内部字段或工具验证过程。
