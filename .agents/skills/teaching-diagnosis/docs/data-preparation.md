# 数据准备

上传前按下表整理数据，可减少一轮口径确认。所有数据文件支持 CSV（UTF-8 或 GBK 编码）与 Excel（.xlsx；.xls 老格式请另存为 .xlsx）。单文件不超过 6MB，约数万行记录。

## 必需：考勤记录

每行一条考勤记录（一次课一名学生）。

| 列 | 常见列名 | 说明 |
|---|---|---|
| 学号 | 学号 / 学生学号 | 与成绩表一致 |
| 姓名 | 姓名 | 可选 |
| 班级 | 班级 / 行政班 | 分层统计依据 |
| 课程 | 课程 / 课程名称 | 教师层统计依据 |
| 教师 | 教师 / 任课教师 / 授课教师 | 可选，教师层诊断用 |
| 日期 | 日期 / 考勤日期 / 上课日期 | 建议YYYY-MM-DD |
| 考勤状态 | 考勤状态 / 出勤状态 / 状态 | 出勤、缺勤、迟到、请假、早退等，全表用词一致 |

考勤状态用词不需要完全统一到固定词表，智能体会按含义归类（如"旷课"归缺勤、"病假/事假"归请假），无法识别的状态会计入数据质量报告请你确认。

## 必需：成绩数据

每行一名学生一门课程的成绩（或一个成绩条目）。

| 列 | 常见列名 | 说明 |
|---|---|---|
| 学号 | 学号 | 与考勤表一致 |
| 班级 | 班级 | 可选（可从考勤表对齐） |
| 课程 | 课程 / 课程名称 | |
| 成绩 | 成绩 / 分数 / 总评成绩 | 百分制数字；等级制（优/良/中）暂不入统计，会在质量报告中说明 |
| 教师 | 教师 | 可选 |

同一学生同一课程多行（如平时/期末多项）会被按均值合并，重复情况会提示。

## 归因必选其一

- **评教数据**：教师、课程、评分（评教分数/得分）；有"评价人数/参评人数"列更好，小样本评教会被降级为仅描述。
- **课堂行为记录**：学号、日期、行为类型、行为描述；用于佐证课堂状态，不用于个体评价。
- **教学进度记录**：课程、计划进度、实际进度（"第 N 章/讲/单元"或数字）、周次；用于计算进度偏差。

## 可选

- **上一周期诊断报告或干预记录**：用于复诊对比与成长档案。最有用的是上一期的指标口径（出勤率分母、及格线）；只上传文字报告也可以，智能体先核对口径再做描述性对照。
- **课程与教师对照表**：课程→教师→班级对照，补齐考勤表中缺失的教师列。
- **预警阈值设定**：直接在对话中说明即可，例如"出勤风险定为缺勤率超过 15% 或缺勤超过 6 次；学业风险定为平均分低于 65 或不及格超过 1 门"。不给则用默认：缺勤率 ≥20% 或缺勤 ≥10 次；平均分 <60 或不及格 ≥2 门。

## 常见问题

- **列名对不上**：直接上传即可，智能体按含义识别并在需要时请你确认映射，不必改名。
- **一个 Excel 多个工作表**：上传后在对话中说明用哪个工作表（如"成绩用期末总评表"）。
- **多个班级分开的文件**：可以分开上传，也可以合并成一个；合并时保留班级列。
- **时间口径**：考勤与成绩须属同一周期；跨学期数据放一起会在质量检查中被指出。
