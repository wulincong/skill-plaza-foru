# 学勤与教学诊断

从一个真实周期开始：上传考勤与成绩数据，补充评教、课堂行为或教学进度，智能体完成数据质量检查、三层诊断（专业、教师/课程、班级）与证据链归因，交付可打开的诊断报告网页；改进措施经决策卡逐项确认留档，下一周期按同一口径复诊对比，形成成长档案。

## 一份完整的诊断交付

报告网页依次包含：总体状况与最需要关注的问题（开篇直接回答）、数据与口径说明（来源、范围、时间、样本量、质量检查结果）、专业层诊断、教师/课程层诊断、班级层诊断（各层含现状、归因、建议）、复诊对比（如有上一周期）与成长档案趋势。每条结论附数据范围与样本量；评教、行为或进度缺失的层如实写未评估。

风险预警名单（出勤风险与学业风险）默认不生成。你确认授权后，智能体按你给定的阈值生成独立名单文件交付，报告网页正文只出现聚合结果，不出现任何可识别个体，也不输出教师排名。

```prompt
使用 $teaching-diagnosis 诊断 2025-2026学年第一学期（2025-09-01 至 2026-01-15）大数据技术专业 2401-2403 班的教学运行。已上传考勤、成绩与评教三份数据，请先核对口径并报告数据质量问题；缺勤与成绩的关联分析注意样本量；改进建议成稿后用决策卡让我逐项确认。
```

## 谁负责哪个环节

本技能负责口径确认、数据质量判断、诊断结论、归因表述与措施留档；统计一律先运行技能脚本（`analyze.py`）算出，不做心算。绘图由共享 chart-visualization 技能按论证需要完成并复验；网页呈现与发布由 report-rendering 技能负责；平台保存成品并返回真实访问与下载入口。

统计口径（出勤率分母、及格线、缺勤认定）、样本量门槛与相关表述规范在技能的分析规则中约定；跨周期对比只并列同范围、同分母、同时间口径的指标，口径不一致时智能体会拒绝并列并说明差异。数据文件怎么准备见[数据准备](data-preparation.md)。

## 需要你决定的节点

时间范围或覆盖班级不明确、数据质量影响结论（重复行、学号对不齐、日期越界）、评教/行为/进度全缺导致无法归因时，智能体先说明已知、缺口与影响，请你选择补充材料、明确口径或按现有证据继续；等待回复期间不出终稿。风险名单生成前必须经你确认授权与阈值。改进建议逐条经决策卡采纳、调整或暂缓，未经你确认的措施只标待定。

## 怎样验收

成稿前核对：每个数字可回查到 `analysis/` 脚本输出；每条结论带范围与样本量；相关性表述为"观察到关联"并提示混杂因素；小样本分组只有描述没有推断；正文无个体信息、无排名。交付后打开实际网页核对标题、图表图注（范围、分母、时期）与名单文件权限提醒，确认证据链完整。
