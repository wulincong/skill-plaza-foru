# 分析规则：指标口径、样本量与表述纪律

状态：随 teaching-diagnosis 技能首次交付（2026-11-18）。本文约束指标定义、样本量门槛、相关与因果的表述方式、风险名单边界与定位纪律。所有数字以 `analyze.py` 输出为准，正文引用时连同分母与样本量一起引用。

## 指标口径

| 指标 | 定义 | 分母 |
|---|---|---|
| 出勤率 | 正常出勤记录 ÷ 有效考勤记录 | 有效记录 = 识别成功的全部状态记录（迟到、请假、缺勤均计入；口径可经 `caliber.attendanceDenominator` 调整） |
| 缺勤率（学生层） | 缺勤记录 ÷ 该生有效考勤记录 | 该生有效记录数 |
| 成绩均值/中位数/四分位 | 学生×课程均值后再按组平均 | 组内成绩条数 n 与学生数分别标注 |
| 及格率 | ≥ passScore 的成绩条数占比 | 组内成绩条数 n |
| 评教均分 | 教师全部评教记录的均值 | 该教师评教条数 n |
| 进度偏差 | 实际章节序号 − 计划章节序号 | 按课程列出，仅"第 N 章/讲/单元"或纯数字可解析 |

同口径纪律：以上指标在对比（班级间、周期间、对照间）时，分母定义、及格线与统计对象必须一致；`analyze.py compare` 校验 `caliber` 不一致时直接拒绝并列并输出 `caliber_mismatch`。

## 样本量门槛

| 分析 | 单元 | 门槛 | 低于门槛 |
|---|---|---|---|
| 缺勤-成绩相关 | 班级内学生数 | n ≥ 30（`rules.minCorrelationStudents`） | 只描述现状（如"该班缺勤最多 5 名学生成绩均低于均值"），不下相关结论；输出中 `inferenceAllowed=false` |
| 评教-教学结果相关 | 教师数 | n ≥ 10（`rules.minTeacherSamples`） | 只描述各教师指标，不写关联 |
| 分组描述统计 | 组内观测 | n < 10 | 正常呈现但必须明示样本量，措辞用"本组 N 条记录显示" |

小样本规则优先于"数据看起来很显著"的直觉：6 个人的班级 r=-0.99 也只描述，不推断。

## 相关与因果的表述

- 相关结果表述模板："在 X 班（n=42）观察到缺勤率与成绩均值呈中等负相关（r=-0.46，Spearman ρ=-0.51）；这是观察到的关联，不构成因果结论。"
- 必须提示的混杂因素示例：基础差异（缺勤多的学生本身入学分数偏低）、课程难度差异、评教参与偏差（低分课程参评人数少）。
- 归因段三层结构：**观察到的事实**（脚本输出的数字）→ **据此的推断**（明确写"推断"并给依据强度）→ **建议**（可执行、可核验）。三者不得混写。
- 归因方向存疑时（如无法区分"课程难导致缺勤"还是"缺勤导致成绩差"），两种解释并列表述，不选边。

## 风险预警名单

- 默认阈值：缺勤率 ≥ 20% 或缺勤 ≥ 10 次（出勤风险）；平均分 < 60 或不及格课程 ≥ 2 门（学业风险）。用户给定阈值时以用户为准，报告中写明所用阈值。
- 名单生成（`analyze.py risk`）只能在用户经决策卡确认授权后执行；输出 `--csv` 文件（utf-8-sig）经 delivery.json files 通道交付，文件名含"授权"字样。
- 名单字段：类别、学号、姓名、班级、指标明细。名单内个体只给触发阈值的指标，不给推断性评语（不写"学习态度差"）。
- 报告网页、决策卡正文、聊天摘要中都不得出现名单内容；聚合结果（如"出勤风险 6 人，占 6.2%"）可以出现。

## 定位纪律

- 不输出教师排名、班级排名；任何"最差/垫底"式表述替换为"低于专业均值 X 分（n=…）"这类有分母的对照描述。
- 教师层只按课程与教学环节聚合（某课程出勤率、某环节评教低分项），用于改进定位，不用于考核评价。
- 图表不使用按教师排序的条形图；跨班级比较图按班级名称或用户给定顺序排列。
- 建议面向措施（补什么环节、调什么节奏、关注哪些课堂行为），不面向"处理谁"。

## 图表选型参考（与 chart-visualization 对应）

| 论证需要 | 图型 |
|---|---|
| 各班出勤率/均分对比 | `bar`（按班级名排序，不按值排序） |
| 周期内出勤趋势 | `line` / `grouped-line`（时间单位一致） |
| 成绩分布 | `distribution` / 直方图（保留个体观测） |
| 缺勤-成绩关联 | `scatter`（图注写 n 与 r，样本不足时不画） |
| 干预前后同口径变化 | `paired` / `change-distribution` |
| 周期趋势（成长档案） | `line`（仅口径可比的周期序列） |
