# foru-web-ui · FORU 页面设计与前端开发技能

提取并复用 foru-ai.com(优才知路)官网的页面设计与前端交互,用于中文 AI、产教融合、人才服务、产业平台的官网、门户和资源展示页面:设计系统、配色配方、页面开发规则、源站实测观察(含截图)与可直接运行的风格起始模板。

- 技能入口:`SKILL.md`
- 设计/配色/前端/源站观察:`references/`(design-system.md、color-recipes.md、frontend.md、source-observations.md、截图与源 CSS 记录)
- 可运行起点:`assets/starter/`(重写的风格示例,非原站源项目)

## 项目内使用

本技能随主仓库检出，源码、资源和使用文档一起维护在 `.agents/skills/foru-web-ui/`。[使用指南](docs/index.md)

调用示例:使用 $foru-web-ui,为我的业务制作优才知路官网风格的响应式页面。
