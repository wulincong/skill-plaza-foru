# 使用 FORU 门户页面设计参考

面向制作产教融合门户、资源展示页和人才服务官网的开发者。开始设计前，先确定页面受众、首要任务和现有组件框架。

## 规划首页

例如要做一个校企合作门户，先列出企业找院校、院校找合作项目等真实入口。按角色安排首屏后的资源，再为各区块选用合适的卡片。保留可选择的文字标题和明确的主操作，装饰插画为内容留出空间。

## 用模板验证

在仓库的 `.agents/skills/foru-web-ui/assets/starter/` 打开 index.html，观察角色切换和产品区如何联动。复用时换成自己的栏目、品牌和数据，参考同一技能下的 references/design-system.md 与 references/frontend.md 调整配色、间距和交互。

分别在桌面和窄屏检查菜单、键盘焦点和卡片换行。需要核对某个视觉细节时，在 references/source-observations.md 里找到对应状态的截图，再对照实现。
