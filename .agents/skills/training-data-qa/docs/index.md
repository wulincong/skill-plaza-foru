# 训练数据构造与质检

从已经治理的业务数据中构造候选训练样本，并检查字段、标签、重复和评测泄漏。适合团队先审一小批样本，再决定是否扩增。

## 提交哪些材料

- 一份获准用于本次任务的数据节选，保留可追溯的记录 ID。
- 输入与目标输出的字段、取值范围和缺失值规则。
- 已确认的正例、容易混淆的反例，以及有争议时交给谁复核。

例如，构造就业意向分类样本时，「回答不明确」和「未填写」可能需要两个标签。在标注规则中先给出判定条件。

```prompt
根据附件中的调查记录与标签表，各挑一个明确样本和一个边界样本。保留来源 ID，说明标签依据。按同一受访者分组规划训练和评测划分，并列出疑似重复记录供复查。
```

## 怎样验收

先看每条候选样本能否回到原记录，再检查字段和标签是否合法。重点抽查同一来源经改写后是否跨越训练集与评测集，及少数类别是否被重复样本放大。让专家裁定争议标签后，把规则版本、修订记录和仍待抽检的样本一同保存。模型训练是后续独立步骤。
