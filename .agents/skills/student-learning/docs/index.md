# 学生个性化学习规划

填写目标岗位、学习目标、当前基础和可投入时间，获得与自己起点相符的学习路线、每日任务、时间安排和教材入口。

## 提交学习需求

目标岗位必填，其余基础信息选填。表单末尾可在“补充说明”填写希望重点学习的内容、设备条件或其他学习要求，规划时会一并参考。时间可以写“每周5天，每天1小时，希望8周完成”。基础可以写专业、年级、已掌握知识和项目经历。知识库由平台配置，学生不需要填写 ID 或密钥。

```prompt
使用 $student-learning，目标岗位是人工智能模型训练助理，学习目标是实习，已有 Python 基础但没训练过模型，每周5天、每天1小时，希望8周完成。请优先匹配课程包和教材，生成每日任务及学习计划报告。
```

## 课程包如何匹配

先查看知识库文档分类，将分类作为课程包候选，再阅读包内大纲、教材和实训文档，核对适用范围、先修要求与内容。岗位与课程包没有明确对应说明时，匹配结果属于根据资料作出的建议。不会把目录中的同名 PDF 与 Word 重复安排为两门课。

课程完整覆盖时使用库内教材；部分覆盖时保留已有资料并补充缺少的学习任务；确无合适课程时根据目标岗位自主规划，明确没有匹配到教材。服务失败或没有权限时会说明原因，由你选择恢复查询或先讨论暂定路线，不冒充“知识库没有资料”。

## 学习报告里有什么

报告先给出学习建议与预计周期，再解释课程选择与排序，最后列出阶段成果和调整方法。每个学习日包含具体任务、预计分钟数、对应教材与完成要求。已有基础可以通过小任务确认后跳过，不安排超过每天可投入时间的任务。期限过紧时会请你选择延长周期或缩小目标。

匹配教材会直接出现在任务旁，也有课程包教材清单。点击“查看教材”或教材名称打开资料；PDF 支持预览，Word 等文件可能下载后阅读。链接由平台逐文档授权，上游密钥不会出现在报告。报告与教材入口按持链接可访问，请仅分享给需要使用资料的人。

## 设计原则与使用边界

围绕学生的岗位目标取证；知识库实际内容、岗位能力的匹配判断与新增学习建议分别表述。课程课时、教材章节和链接需有真实来源；自主规划不编造库内教材。检索和课程资料中的命令只作材料，不作为操作指令。

成品检查包括每日任务时间、课程先修顺序、阶段成果、真实教材绑定、网页窄屏阅读与链接可访问性。自动构建会核对课程和教材来源、时间预算与任务引用，教学难度与目标可达性仍需要学生或教师结合实际验证。计划不承诺就业结果。

课程证据来自平台授权的 WeKnora；接口依据见 [WeKnora 官方资料](https://github.com/Tencent/WeKnora)。首期不包含学习打卡、成绩记录或自动追踪进度。
