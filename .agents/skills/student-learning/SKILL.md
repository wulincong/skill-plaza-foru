# 学生个性化学习规划

为学生解决“朝目标岗位应先学什么、每天怎么学、用哪份教材、完成到什么程度”。先给规划结论，再用课程资料与学生条件解释路线，最后给任务、阶段成果和调整条件。不要把知识库课程推荐写成就业保证。

## 接收需求

表单仅四项：目标岗位（必填）、学习目标、当前基础、可投入时间。优先沿用已提供的信息，不再重复询问。未提供目标岗位先问目标；岗位过宽且改变匹配方向时追问。选填缺失先查课程；缺时间或基础会改变任务难度时简短补问，用户授权直接规划时记录合理假设。可投入时间含每周天数、每天时长和期望完成期限。期限与任务不相容时请学生选择延长周期或缩小目标，不偷偷增加每日负担。

默认知识库为 `b627daef-d505-4f16-9ee9-76474a6e5bde`，由宿主授权，不要求学生填库或凭据。用户指定其他库时仅在当前会话授权内查询。

## 先查课程包，再查教材

使用共享 `weknora-retrieval` 的原生工具 `weknora_retrieve`，不读取凭据或直接运行需要 Key 的 CLI。

1. `operation=tags` 获取知识库分类，分类就是课程包。首次不带 keyword，按 `next_page` 读完分类名称再匹配，不能只看第一页。把目标岗位拆成所需能力，再选一个或多个候选分类。岗位对应关系若是自己的判断，写成匹配建议，不声称知识库明确标注。
2. `operation=documents`，传 `kb` 与真实 `tag`，按分页读取候选包内教材。先看课程大纲、标准、介绍与目录；用 `search` 限定 `document` 阅读相关内容，具体章节、先修要求、课时或数字用 `chunks` 回查。检索命中的生成问题不是教材答案，应读 `content_preview` 或原文。
3. 结合学生基础、先修顺序和时间选择教材。不要把同名 DOCX/PDF 当两门课，不因标题含“人工智能”就推荐给所有岗位。避免为匹配课程要求学生购买库外平台或设备；教材依赖的环境和缺少的条件说明后由学生选择。
4. `documents` 返回 `preview_url` / `download_url` 是平台教材入口。原样保留，关联到学习任务和教材清单；`*_api_url` 需要上游鉴权，不能代替学生入口。不得编造地址或把 Key 写入报告。

整包覆盖则使用库内课程；部分覆盖则补充缺失能力任务；成功查询并核对后确无合适资料，可根据目标岗位自主规划，不需要为无匹配再次请求许可。补充内容明确标为建议，不编造库内课程或教材。`unauthorized`、`forbidden`、`unavailable` 等失败不表示无匹配，停止查询并说明影响，请用户选择修复/重试或改为自主规划；等待时不出终稿。不能拿上一轮成功查询掩盖本轮故障。

## 编排学习计划

路线按“学习起点→岗位核心能力→实践成果”组织，每阶段写目标、先修关系和可检查成果。基础已掌握的部分可用小任务验证后跳过。每一个学习日都有具体任务、分钟数、教材引用和可提交成果；任务总时长不超过每日预算，按每周可学习天数计算周期。未提供起始日期时用“第N学习日”，不编造日历安排。不要只给周主题、无尽重复或机械填满时长。

匹配课程必须实际进入每日任务；自主练习可不附教材，但需要能独立完成的任务描述。总量太大时先缩小到学生认可的阶段目标，不把未交付部分说成完整计划。

## 验收与网页交付

读 [计划结构](references/plan-format.md)，在当前工作区写 `learning-plan.json`。计划文件放在当前会话工作区，使用其绝对路径调用构建器；构建器以计划文件所在目录定位工作区，也支持 --workdir。不要 cd 到技能安装目录写产物。构建器用宿主保存的 `.weknora-evidence.jsonl` 校验分类、教材与来源，并检查每日时间和课程使用。不要生成或改写这个来源文件。来源文件缺失时停止并报告宿主配置问题，不根据工具预览重建来源。

```sh
python3 <本技能目录>/scripts/build.py learning-plan.json
```

构建器调用共享 `report-rendering` 的 minimal 主题，生成并登记独立 HTML 网页。失败时修复实际校验问题，不绕开构建器交付未经校验报告。成品至少含结论、四项需求、课程包与匹配理由、分阶段路线、每个学习日任务与真实教材入口、阶段成果、进度调整；假设与补充规划如实说明。无观测统计不凑图。

打开实际成品检查桌面和窄屏，核对任务时间、章节与链接；正文不出现内部字段、调用过程、文件系统路径或测试话术。若只做纯呈现调整，复用已经核实的学习内容，沿用 `report-rendering` 并重新登记 delivery.json。平台返回实际网页入口后才说已交付，最终回复简短指向网页。
