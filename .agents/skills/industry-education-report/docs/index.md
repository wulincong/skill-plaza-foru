# 产教决策报告

专业负责人要决定是否增开一门实训课，园区要决定先培训哪类岗位，都可以从一个具体问题开始。写明谁来决策、要决定什么、研究对象与时期。只问某类岗位有多少或薪酬如何，可直接使用人才数据库查询技能。

## 一项决定，一份简报

默认简报分三节。**决策摘要**开篇回答读者的问题。**证据与判断**逐段给出判断、依据及其对决策的影响。**行动与适用条件**说明由谁采取什么行动，以及出现什么新证据时应调整。需要覆盖区域格局、岗位结构、薪酬与培养建议的全景观察时，可明确要求十二章报告。

```prompt
为佛山某高职院校的专业负责人判断，下学期是否应增开一个机器人调试实训班。用我上传的企业访谈和实训室排课表核对需求、工位和师资。先给结论，再说明依据和能够开班的条件。
```

## 从岗位需求到本校决定

报告与取数分别负责一个环节：产教报告提出证据需求并形成决策，`talent-data-query` 解析产业、执行统计并返回可核验结果。在线报告只调用共享查询工具，不自行构造数据库请求。查询超时或失败时，停止试查并说明缺口；查询阶段有独立的标识和分段耗时，可以定位问题发生在范围解析、排队、数据库还是结果校验。图表和网页继续由各自的共享技能处理。

招聘记录可以说明样本中有哪些岗位要求；学校能否增课还取决于本校课程、教师和实训容量。报告分别核对两类材料。使用统计时保留地域、时间窗、分母与指标出处，附件或访谈引用到页码、表格或段落。只要同一批数据能回答修订后的问题，就沿用原结果。若材料显示关键设备下学期已全部排满，即使企业确有需求，也可以得出暂缓开班的结论。

## 关键缺证时由你选择

例如访谈说明企业需要调试人才，但学校尚未提供工位与排课材料，无法判断能否新增一个班。智能体会先说明已知、缺什么以及缺口的影响，等待你选择。你可以补充排课表，或指定扩大到哪些校企共用场地重新评估；也可以明确选择按现有证据继续，让报告只回答岗位需求，把能否开班列为未决。与这项决定无关的缺项直接在对应段落说明。

## 怎样验收成品

你会收到 Markdown 正文、结构化报告、结构验收和逐条证据复核。先看摘要是否回答了原问题，再选一条关键判断，沿来源编号回查材料、样本和分母，最后检查行动是否有负责人和适用条件。岗位数据来自人才数据库查询技能，完整观察版沿用《产业人才需求观察报告》模板。2026 年 9 月广东快照专用于明确要求的历史复现。

## 需要可以打开的网页

提出“生成网页版报告，注意图文结合”即可。需要图文报告但未指定格式时，也会随四份下载提供网页版。网页版由 report-rendering 设计，使用同一份已核验的结论、数字和来源，正文中的图表应能说明对应判断。默认采用暖白、深绿的纸感简报，也可指定极简白或自定义风格。渲染技能负责主题、组件和表格，产教报告负责判断与证据。网页交付后可从报告资源栏打开，四份原文件仍可分别下载。

## 图表怎样支撑决策

人才数据库查询技能提供统计，产教报告选择影响决定的比较，`chart-visualization` 用这些指标绘图并复验。例如，判断一门实训课是否适合专科生时，可以用横条图比较同一地区、同一时期岗位的学历要求。图注说明岗位记录数和筛选条件，展开图下的数值表即可核对每一组。学校能否开班则要回到工位、课时和师资材料。

每幅统计图都从结构化报告中已核对的指标取值。修改图题、数字或筛选口径时，重新生成图稿并复验，图注和数值表随图一起更新。报告保留实际的零值，对没有数据的项目说明缺口。只有访谈或排课说明时，直接引用材料。绘图方法采用共享技能的《独立图稿规格 figure/1》和《通用绘图规则》。
