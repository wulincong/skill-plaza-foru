# 产教决策报告

为院校、园区或政府读者整理区域产业人才需求观察报告。技能使用内置招聘数据快照和十二章模板，适合调研专业建设时先核对已有证据与数据缺口。

## 给出报告范围

写明地区、产业、读者、用途和希望观察的时间范围。内置数据覆盖广东在招岗位快照，含人工智能切片，时间口径为 2026 年 6–7 月的导入批次。选择其中已有切片，可以看到哪些结论有统计支撑。

> 面向广东高职院校的专业负责人，用内置人工智能切片编写人才需求观察报告，重点解释岗位结构对课程调整的启示。请保留各图口径，并列出需要学校另行补充的数据。

## 读懂验收与缺口

技能生成报告 Markdown 和结构化 report.json，并核对章节、图表、证据和缺口。先读图注和附录中的取数范围，再看结论是否回答了自己的决策问题。验收时分开记录「模板结构是否通过」和「决策所需数据是否完备」。

如改为另一省份或要求更细的交叉统计，快照可能没有对应数据。可先把缺口交给数据负责人，说明需要的字段和用途。岗位记录描述招聘需求，院校就业率、实际录用人数等需另有证据。
