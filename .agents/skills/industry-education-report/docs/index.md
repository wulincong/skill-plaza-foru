# 产教决策报告

从一个真实决定开始：是否新增专业、调整课程、开设实训班，或优先培养哪类园区人才。智能体完成取证、分析、复核与呈现，最终交付可打开的完整报告网页，并附正文、结构化报告、结构验收和证据复核文件。无需再追加“做成网页”，也无需选择简报或完整版。

## 一份完整的决策报告

报告依次包含决策摘要、研究范围与证据口径、区域产业与岗位需求、岗位门槛与薪酬结构、工作任务与培养定位、实施条件与关键差距、备选方案与决策依据、行动计划与风险、结论与未决事项。统计口径和来源附录便于回查。

完整指的是论证覆盖了这项决定所需的依据。各节先给判断，再展开证据，最后说明对决定的影响。不能用重复摘要代替方案和行动，也不能为了篇幅编造数据。与当前任务无关的专题说明不适用原因；已获取且用于论证的分布、薪酬、岗位与条件材料完整保留。

```prompt
我们是广州的一所高职院校。请评估是否需要新设具身智能专业，并比较先做课程方向、校企实训或独立专业三条路径。先核对岗位需求，再核对我提供的师资、实训条件和课程材料，交付完整报告网页。影响结论的信息不足时请让我选择如何继续。
```

## 谁负责哪个环节

人才数据库查询技能负责范围解析、受管查询、口径校验和可追溯工件。产教报告负责证据是否足够、业务判断、备选方案、建议和内容复核。报告渲染技能负责完整映射成稿、页面与表格设计，并按数据关系调用 chart-visualization 绘图、复验和嵌入。平台负责保存成品并返回真实访问入口。

网页是默认最终交付，四份业务文件是可回查的原件。业务构建完成后仍会继续呈现与发布；发布失败会说明实际状态，不能把工作区里的文件说成已经交付。换主题、调整图表等纯呈现修订沿用已核内容，发布新的网页版本。

## 需要你决定的节点

学校层次、目标地区或研究时期有歧义且会改变判断时，先询问。核心证据仍不足、来源冲突会影响结论，或方案取舍依赖未给出的预算与优先级时，说明影响并等待你选择。智能体可以给建议，但不会替你批准建设、扩大取数范围或接受证据缺口。

证据不足时可选择补充材料、扩大到明确范围，或按现有证据继续。扩围后仍需重新评估；地区岗位数不能替代本校的师资和实训条件。选择按现有证据继续后，完整报告仍会交付，但只能回答有证据的部分，受影响的决定保留为未决并注明补证责任。

如果唯一实训场地已排满且不能调整，这个必要条件已足够支持本期暂缓开班，不必再问与本期结论无关的缺项。已粘贴的排课原句可以直接作为材料，无需重复上传。

## 怎样验收

先看摘要是否回答问题，再看需求与实施条件是否分别论证。沿一条判断回查来源、样本、分母和具体字段，确认指标支持这句话；学历比例不能绑定企业数，读取日期不能冒充查询时间窗。备选方案应说明取舍，行动应有建议责任方、下一步、启动或调整条件及核验办法。用户未提供的预算、阈值和建设安排不能写成既定事实。

打开实际网页核对全文、图表、数值表和来源。图表由渲染技能按真实关系选择，多种关系尽量使用不同图型；没有时间序列不能画增长趋势。纯质性材料无需凑图。自动校验能检查结构与绑定一致性，不能代替逐条语义审核。

## 设计依据

证据分级、关键缺证由用户选择、总分总论证及成品验收遵循本项目报告设计约定。统计口径以 talent-data-query 的实际结果为准，呈现设计沿用 report-rendering 的元素、主题与表格方法，绘图能力以 chart-visualization 最新入口为准。旧《产业人才需求观察报告》模板与 2026 年 9 月广东快照只用于历史回查；新报告统一采用完整决策结构。
