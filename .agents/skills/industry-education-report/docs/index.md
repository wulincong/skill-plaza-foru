# 产教决策报告

面向要调整课程的专业负责人、要规划人才培养的园区或政府部门。给出地区、产业和要做的决定，可以得到一份区域产业人才需求报告，以及支持建议的证据和仍需补充的材料。

## 报告怎么生成

1. **明确决定和范围。** 例如“为广州高职院校调整机器人实训项目”，先确定研究整个机器人产业，还是仅看名称含“机器人”的岗位。两者筛出的样本不同。
2. **取得对应证据。** 人才数据库查询技能负责范围解析、取数和指标校验。报告优先复用本会话同口径的已核验结果，缺少必要指标时才请求新统计。培养方案、企业访谈和毕业去向等材料可以另外提供。
3. **形成判断与建议。** 报告用摘要、十二个正文章节和附录呈现。先说明观察到的岗位结构和门槛，再解释对读者的影响，最后写具体动作和核实办法。例如学历分布可以帮助选择企业访谈对象；是否调整招生规模，还要看毕业去向和实训容量。
4. **核对再交付。** 分别提供报告正文、结构化报告、结构验收和证据复核。学历等分布直接列出各组的记录数与占比，读者可由图表回查样本、分母、原读取时间和指标定位。数据缺口说明由谁补、影响哪项判断。

## 可以这样提问

```prompt
为广州高职院校的机器人专业负责人生成产教决策报告。用当前在招岗位分析学历门槛，提出实训课程调整建议，并列出需要向合作企业核实的两件事。
```

已有统计时可要求“沿用本次结果，把建议改为园区培训规划”。如要换城市或重新取数，直接说明新范围。只问岗位数量、岗位目录或薪酬时，可直接使用人才数据库查询技能。

## 怎样理解缺口

一条招聘记录说明平台观察到一个岗位。它不能直接证明有人被录用、市场需求逐年增长或毕业生已经就业。请求历史基期时，需要与该时段匹配的证据。没有匹配样本、没有有效薪酬和查询失败分别说明；缺证的章节保留影响，不用其他地区的数填空。只有明确复现旧样板时才引用 2026 年 9 月的广东历史快照。

报告结构沿用《产业人才需求观察报告》模板。岗位统计遵循人才数据库查询技能的样本、时间和指标口径。结构验收核对章节与引用，证据复核另行判断每条结论能否由该样本支持。
