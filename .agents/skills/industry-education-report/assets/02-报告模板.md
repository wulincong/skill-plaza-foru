# 产教决策完整报告 · 内容模板

新报告统一采用 [templates.json](templates.json) 的 F01–F09，不再选择简报或观察版。以实际决定组织内容，避免为了章节填入无关数据。

| 章节 | 需要回答的问题 | 依据与边界 |
| --- | --- | --- |
| F01 决策摘要 | 现有证据支持什么结论？ | 回引正文，明确适用条件与未决决定 |
| F02 研究范围与证据口径 | 谁要决定什么，样本覆盖什么？ | 用户原话、真实地域、时期与来源；不猜学校层次 |
| F03 区域产业与岗位需求 | 需求在哪里，集中在哪些岗位？ | 同范围记录数、企业数、城市和岗位分布，说明样本代表性 |
| F04 岗位门槛与薪酬结构 | 入门门槛与人才定位是否匹配？ | 学历、经验、有效薪酬及可得分位数；边际分布不拼成交叉关系 |
| F05 工作任务与培养定位 | 需要培养哪些可核验的能力？ | 岗位任务、企业材料、职业标准、现有课程及真实技能统计 |
| F06 实施条件与关键差距 | 需求能否转化为本单位的方案？ | 与决定相关的师资、场地、容量、预算与资源；未知不视为满足 |
| F07 备选方案与决策依据 | 哪条路径更适合，取舍在哪里？ | 对比独立建设、渐进调整、合作或暂缓等实际可行路径；预算与偏好缺失时询问 |
| F08 行动计划、风险与调整条件 | 建议谁做什么，怎样确认有效？ | 责任方、下一步、启动或调整条件、核验办法；建议不等于用户批准 |
| F09 结论与未决事项 | 现在能做什么决定，还不能做什么？ | 回扣问题，收束条件、补证责任与适用边界 |

全文和每段均先给判断、再给具体依据、最后说明决策含义。指标、来源与统计口径由生成脚本追加为附录。与当前决定无关的专题说明不适用原因；关键缺证先询问，次要限制就地说明。只存在单次快照时不得编造趋势。

按 [报告契约](../references/data-contract.md) 完成逐条证据复核和业务 build，再交接共享渲染直到最终网页交付。取数仍由 talent-data-query 提供。旧版结构移至 legacy-templates.json，仅用于历史稿回查；历史快照不作为新任务的数据源。
