# 产教决策报告

从地区、产业与读者面临的决定选择证据，使用 talent-data-query 的统计或用户提供的材料生成三节决策简报，全景观察可选十二章版。关键缺证先等用户选择，明确继续才交付限定结论。技能负责解释、建议、缺口、语义复核与交付。[使用指南](docs/index.md) · [报告契约](references/data-contract.md)

在会话工作区运行 `python3 <技能目录>/scripts/report.py build report.json --review review.md`。既有 validate、render、verify 命令继续支持单独检查与历史样板复现。
