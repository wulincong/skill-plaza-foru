# 产教决策报告

**交付目标。** 生成完整报告，最终通过 [report-rendering](../report-rendering/SKILL.md) 交付可打开的网页，同时保留正文、结构化报告、结构验收和证据复核四份文件。不提供简报/完整版选择，不以聊天摘要或业务 build 完成代替最终交付。关键问题等待用户时先停在询问，得到回复后继续这条流程。

**先找决定。** 从任务提取读者、决定、对象、地域和时期，采用已明确的信息。会改变取证方向的歧义先询问；“学院”不能自动解释为“高职”，不猜办学层次、预算、容量或决策偏好。缺城市而本校材料已够用时采用“本校”。仅问数量、薪酬等统计时交由 [talent-data-query](../talent-data-query/SKILL.md) 回答。

**取数职责。** 本技能决定需要什么证据，查询全部遵循 talent-data-query。在线用 `talent_query` 提交地域、产业名称、真实筛选和所需指标，`talent_inspect` 核验已有结果。不自行写查询 JSON、SQL 或连接脚本，不执行 query/plan CLI，不套 timeout 或选择计划。整个产业交给查询技能解析，不能替换成名称关键词。无原生工具时先读查询技能，按其入口执行。优先复用同会话、同范围、同口径的已核工件；缺指标或明确刷新才取数。

**围绕决定取证。** 先读[报告契约](references/data-contract.md)，列出要验证的判断，再选材料。完整分析覆盖范围、需求、门槛与薪酬、任务与培养定位、实施条件、备选方案、行动及风险；与当前决定无关的专题说明原因，不能硬凑统计。岗位需求与本校能否实施分别核验。用户粘贴的原句就是材料，引用实际段落即可；授权附件或知识库回查原文。用户限定来源时遵守，不自行扩地区、换样本或改时间窗。仅复现广东历史口径时才读取 [05 快照](references/05-数据库字段摸底与口径.md)。

**需要人判断时询问。** 范围含糊、关键证据缺失、来源冲突会改变结论，或备选方案涉及用户未给出的预算/优先级时，说清已知、缺口和各选项影响，问一个可回答的问题。证据缺口提供“补充材料”“扩大范围”“按现有证据继续”；扩围选项写明建议范围，未明确范围先问清。支持决策卡时用单选或输入卡，普通文本入口列同样问题。结束本轮等待真实回复，不同时构建或交付终稿。查询失败按查询技能状态停止，不自选降级方案重试。补证或扩围后重新评估；“扩大范围”“请生成”、沉默都不等于允许带缺口交付。仅用户明确选择按现有证据继续，才记录原话并把受影响决定保留为未决。若必要条件已有证据否决，可直接形成暂缓或否定意见；次要缺项就地说明，不反复追问无关材料。

**写完整报告。** 统一 `edition=full`，按[章节表](assets/templates.json)和报告契约组织。开篇回答问题，中段每个判断给出具体依据和决策含义，末尾回到建议、条件与未决项。方案比较包含可行替代路径或暂缓方案，建议是研究结论，不能写成用户已批准。所有用于判断的分布、薪酬、岗位等数据完整绑定交接，不只保留总量。用户材料的量化事实也登记 metrics 并被 claim 引用，同口径数值保持单位与统计对象一致。缺少联合分布或时间序列时不能拼造交叉关系或趋势。校验出错修正字段及引用，不删掉已有论证以求过关。

**业务复核与构建。** 内容修订先复制已审稿为工作草稿，保留 output/report-* 原件及指纹。草稿、review.md 和命令都在当前会话工作区；使用技能脚本的绝对路径，不 cd 到技能安装目录。先运行 `python3 <技能目录>/scripts/report.py preview report.json`。按原材料逐条核对 claim 的含义、metric 绑定、单位/分母、推断和限制；检查各章是否回答不同问题、实施条件是否被需求总量冒充、F08 是否包含责任方/下一步/条件/核验办法。review.md 记录审核者、日期、每条 claim 的依据与审核理由，以及范围/需求/可行性检查结果。修订后运行 `python3 <技能目录>/scripts/report.py build report.json --review review.md`。build 成功只代表业务交接完成。

**继续到最终交付。** 立即读取 report-rendering，将本轮 build 输出目录中的正文和 report.json 交给它，沿用已核结论、完整指标、来源和未决项，完成呈现、实际成品验收及平台登记。只有平台产生真实网页入口才算交付成功；未成功说明停在哪一步并保留工件，不能声称已交付。纯呈现修订复用已核业务版本，按渲染技能重新登记新版本。最终回复简述结论和未决项，使用平台生成的网页及下载入口；不列工作区路径、内部字段或工具验证过程。
