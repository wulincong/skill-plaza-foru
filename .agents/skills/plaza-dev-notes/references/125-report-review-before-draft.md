# 报告成品预览、质量确认与公众卡片隔离

状态：已实现。广场真实浏览器预览、同一会话的Pi修订、新版本确认和真实草稿保存通过；公众号签名回调和客服消息UTF-8请求体通过。手机最终外观仍由用户验收。

## 动机

用户验收发现广场先询问存稿但看不到正文，公众号卡片夹带运营话术且出现字面Unicode转义，核心标题只引出主题而未给出结论。本记录修订117中“成品后立即询问存稿”的旧约定；固定出口继续使用122的已启用SSH专用服务。

## 约定与接入点

- `web/src/components/WechatReportPreview.vue:1` 在消息正文直接展开纯图片报告，保留完整页入口，原会话可继续修改；确认按钮只对应最后一份成品。缓存交付同时显示原数据读取日期。复用既有颜色令牌，窄屏可滚动阅读。
- `web/server/lib/reportLibrary.ts:40` 的 `reviewDelivery` 用于缓存和新成品，初次不附question；`localReportReply`仅在`reviewed`后发出存稿确认卡。`web/server/index.ts`对成功交付统一采用这个顺序。
- `scripts/report_library.py:51`新增独立`report_reviews(session_id,report_id,approved_at)`，不更改旧sessions列数。质量确认绑定当前report_id及可选精确成品URL，有效期一天。明确仍要求精简、修改的混合评价优先进入修订，不因“整体满意”提前批准；确认质量同时表示暂不保存则直接关闭存稿追问。旧URL返回review-stale；普通话题、修订、新报告绑定会清除确认。只有质量确认及保存指令都满足才进入pending=2；`scripts/report_drafts.py:132`再次检查，避免绕过Node接口保存未确认版本。
- `scripts/report_library.py:339`为缓存会话恢复同一证据的写作输入。来源只从服务端元数据/运行索引解析，不接受模型文件路径；验证数据指纹、绑定源文件和适配结果，拒绝符号链接和超限文件，只复制统计与文案，渲染资源取安装目录。恢复后仍走Pi和原始校验。恢复失败不改用其他地区，也不覆盖已存在目录。
- 公众号`wxbot/public_report.py`把历史字面\u序列转回中文，卡片只保留公众阅读摘要；`wxbot/customer_service.py:31`用ensure_ascii=False和UTF-8字节发送客服消息。首次异步、缓存被动回复、报告结果和降级文本均不附运营存稿问题。草稿仍在广场运营流程中处理。
- 文案版本`wechat-editorial-prose/4`、开篇`wechat-article-lead/3`、成品库`education-readable-editorial-v4.3`。摘要标题由绑定字段给出具体份额、主导类别或报价差异；单城首结论对照学历经验，不用自身100%当跨城发现。`editorial_prose.paths`同步声明新用字段，改数字或指标投影仍会拒绝。方法边界集中保留，未完成分析话术进入内容阻断检查。
- 默认范围快照缓存上限三十天，按原始data_at计算；更严格maxAgeSeconds仍有效，最新/时间/条件/地区变更绕过快照，不刷新读取日期冒充新数据。旧版本和已公开静态链接保留。
- `joint_chart_layout.py`入门气泡图对接近/重合点只标出空间分离的中心编号，全部点、颜色、图例和原始统计继续保留；最终SVG标签重叠检查不放宽。方向薪酬只有至少两个有效报价数不少于三十的类别才使用“报价领先”，否则展示量价分布而不声称排名。

## 成本与取舍

质量确认是每份成品独立状态，不用“确定”等含糊回复同时表达内容验收和存稿授权。选择隔离公众读者与运营广场的交付文案，不把运营问句塞进消息描述。保留确定性数据计算与来源绑定，由Pi负责图后短评和任务建议；不以隐藏方法限制或删图掩盖不确定数据。旧成品不原地覆盖，方便历史与已保存草稿保持一致。
