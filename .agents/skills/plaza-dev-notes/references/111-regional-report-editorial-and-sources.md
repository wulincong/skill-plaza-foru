# 地区证据、融合摘要与受控报告写作

**状态：已实现；最终成品待用户验收。**

## 动机

地区数字虽然来自不同查询，旧文字仍重复通用模板；摘要把事实、分析与结论拆开；模型会自行分配学历与技术任务，甚至用上标数字避开数值检查。首次生成还可能漏选产业规则，形成较短结果并被当成完整缓存。本轮将文案、取数完整度和资料来源作为同一证据链约束。

## 约定细节

- `wechat-analysis/2` 保留字段兼容，推理使用 `wechat-analytic-reasoning/2`。`regional_reasoning.py:32` 从本地统计重算标题、解释和方法范围，原 `analytical_reasoning.py` 只保留稳定导入桥。
- `editorial_prose.py:109` 输出一段摘要和三条融合分点；每点同时呈现数量、解释与判断。城市点比较岗位规模和条件覆盖；薪酬点保持匹配岗位与职教子样本；方向点联立方向规模与方向内条件覆盖，按广覆盖或差异化路径分支。`op=editorial` 的 inputs/metricIds 与保存的分析共同核对，不允许手改融合段落。
- `editorial_projects.py:4` 按本地城市、方向、技能及交叉比较选择项目示例；`:79` 检查方向薪酬、城市方向、相对集中与方向能力章节是否回应本章对象。Pi 补充行动、项目评价与分流建议；不能按学历、薪酬或城市名称直接指定技术层次。
- `_narrative` 对 Unicode 数字做规范化，也检查中文测量数值；观察到的实体名称和经验标签另行保留。方法范围由真实筛选生成，防止把读取日写成岗位发布日期。`polish` 删除无依据的承诺尾句，内容校验拒绝过程性措辞；参考文献保留原文正式题名。
- `writing_batches.py` 持久记录每批拒绝次数；连续两次文案失败采用对应的数据选择项目文本，仍通过相同校验，受保护事实错误不放行。原生请求总数上限为十八，构建失败停止循环。`reportWorkflowContext.mjs` 仅压缩模型看到的重复指标路径，保留原始历史、当前事实、范围和最新纠错；工具合并始终使用完整任务。
- `collect_data.mjs` 在调用方已明确选择唯一已知产业根节点且没有自定义 analysis 时补齐对应 profile，不修改用户筛选，不把叶节点或未知产业回退为 AI。明确自定义分析保持原有规则。标准缓存还须覆盖该产业完整章节；缺失方向、能力等内容的版本归入 custom-scope，不能作为默认完整报告命中。
- `refresh_policy.mjs` 由就绪判断与取数共用。明确最新/重新查询时强制 live；仅调整最新图片、代码、格式，或明确不刷新时保留原数据策略。collectionPolicy 与源 freshness 分别保存请求意图及实际执行模式。取数报错列出实际不支持字段和修复方式，不让模型猜 schema。
- 本地资料使用 `wechat-regional-research/1`，按地区与产业搜索已对照原文的政府文献目录；最多选两篇，默认七天有效缓存，显式刷新预算不超过十二秒。保存统计期、资料性质、原文证据与指纹，区分已发布事实、政策目标和应用构想。工作区快照不能改写、遗漏来源或延长有效期；深圳使用广东背景时标明省级口径。
- 国家统计局研发背景覆盖公报的三十一个省级地区，保留年度全社会口径，不能冒充 AI 专项投入或招聘人数。文后文献列出标题、机构、日期和原文地址。目录与官方背景文件均进入构建指纹。
- 默认成品使用 `education-regional-editorial-v3`；自定义地域、人群、范围或章节不混入默认命中。保留用户 humanReview=pending，智能体内容自查另行记录，不冒充用户验收。

## 成本与取舍

通用搜索包装在省级 site 查询中返回不相关站点，不能把搜索片段直接升为证据；本轮选择明确政府站点与原文校对目录。九篇来源可由原生抓取核对，一篇受站点访问限制使用已核对的官方文档阅读结果；不关闭证书校验。未知地区不借用别省文献。

不采用无限模型重试，也不自动信任模型审校意见。独立无工具短审校通过 Pi 执行，并限制输出；批注仍需与事实核对。非交互 print 调用必须关闭 stdin，否则会等待输入结束。原生 Pi 仍是模型客户端，没有新增第二套模型 SDK。

生成速度应区分首次取数、已有数据重写、校订后重绘和成品缓存。资料检索命中约毫秒级；官方刷新实测均在预算内。源库队列会影响首次耗时，不能把无排队耗时或不完整报告时间当成固定承诺；默认缓存只保留完整、已构建的成品。数据库全量读取与队列保护保持共享工具约定，不为速度削弱范围或指标。

## 验证与后续

内容完成三轮自查：范围与数字、融合文案与地区差异、全文与建议对象及图片一致性。程序验证覆盖融合段落、Unicode/中文数值、学历任务推断、章节建议对应、资料篡改与遗漏、刷新策略、产业根节点自动规则、完整缓存资格，以及原有图形和草稿协议。真实 Pi 覆盖六省两产业与深圳硕士限定；图片与仅 PNG 压缩包按实际指纹对账。绘图调用剖析确认 chart_recommender、report_charts、joint_report_charts、chart_layout、joint_chart_layout 均有实际函数调用。

后续扩展以增加可核对的地区来源和章节比较规则为主；资料目录需按有效期维护。其他产业先提供适用分类与能力词表，不复用 AI 规则。当前不把自动评语当作事实来源，也不把横截面外推为供需、增长或录用结果。

最终验证：Python报告测试四十四项、原生工具及取数策略十二项、成品库与草稿协议十八项通过。十三份成品中十二份覆盖完整产业分析，一份保留深圳硕士限定；共二百五十七张图片。默认缓存十二个组合均经真实广场API命中，耗时约0.14—0.89秒；明确拒绝保存后pending清除。完整AI新会话实测广东145.117秒、山东199.419秒；两个十四页早期样本已剔除。数据来源、原生生成与绘图调用的证据保留在会话和构建记录中。

补充精度规则：方向量差处于中间区间时按实际规模差表述，不把接近两倍称为规模接近；没有职教子样本时，薪酬核心优先使用已分类且有效样本充足的比较。标题控制可读长度，三项核心启示均进入融合段落并去除重复标题。
