## 动机

旧报告把“有什么可分析”固定成一份广东快照的供给清单，做其他地区时只能报缺。表单同时预填该历史样本、展示模拟知识库。运行详情要求九个院校版标题，与实际渲染模板的摘要、十二章和三份附录不一致。

## 职责和交接

- 报告从决策问题选择必要统计与院校材料，生成解释、行动建议和缺口。单项岗位统计交由人才查询技能回答。相同范围改标题或受众时读取当前会话已有结果，改变范围、补指标或明确刷新时才请求新统计。入口见 `.agents/skills/industry-education-report/SKILL.md:8`，运行依赖登记在 `web/server/lib/skills.ts:199`。
- `scripts/talent-data-query.mjs:58` 的 `inspect --result <path> --full` 复用共享层的工件校验并返回完整结果。省略 --full 仍返回预览。报告源引用 `data/tq-…/result.json`、contentHash、dataReadAt，直接观测绑定 metricId 与数值所在字段，省略的原值、指纹和读取时间从该已核验工件补齐。含标签的分组直接引用 rows 时，同一值表列出原分母、行标签、记录数与占比，超过二十组注明展示范围。报告校验只调用离线 inspect，核实事务、逐项对账、指标状态和数值。无法使用的结果留缺口，真实空样本允许零计数。见 `.agents/skills/industry-education-report/scripts/report.py:20`、`references/data-contract.md:24`（同技能目录）。
- `scripts/report.py:311` 在结构校验和人工/Agent 证据复核后生成 report.md、report.json、validation.json、review.md；构建前核实每个 claim ID 在复核记录中出现，内容完备性仍由语义复核决定。四份文件先写入继承会话共享组的独立修订目录，最后替换会话的 delivery.json。生成失败时已交付版本仍有效。内部查询工件不列入下载。
- `web/server/lib/skills.ts:245` 读取报告自用章节表，`web/server/lib/reportParse.ts:8` 优先解析本轮已发布的正文，旧入口仍支持回复中的 Markdown。单纯追问不沿用上轮的报告。表单 `web/src/data/useTaskConfigs.ts:88` 使用地区、产业、时期、读者和决策问题，可附真实材料。

## 成本与取舍

不在业务技能复制 SQL、指标计算或第二份快照。保存结果不限于在线缓存有效期，离线核验需要共享 CLI 和同一会话内的完整工件。不同指标的分母、行标签、解释与建议仍要语义复核。保留旧结构、三个单独的 CLI 命令和历史示例，避免已有报告或固定交付方因迁移失效。只按当前时间窗报告，缺历史或院校数据时不以当前在招记录替代。
