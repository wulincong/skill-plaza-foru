# 104 · 独立管理后台与运行控制

**状态**：已实现并在当前部署启用。适用于 Vue + Node/Pi 主应用。本条更新 048 的目录回退策略、072/077 的历史访问边界及 082 的模型默认值来源。

## 动机

运营人员需要在运行中上下架技能、选择模型和轮换凭据。原运行列表与完整工具入参、输出及原始文件使用同一组公开 API，公开对话侧栏也能枚举所有会话。管理和使用必须分别授权，同时保留已有 trace 和原生 Pi 续聊。

## 约定与接入点

- 网页入口为真实路径 `/admin`，后台使用 history 路由，广场继续使用 hash 路由。旧的 `#/runs/:runId?` 跳转至后台并保留深链。见 `web/src/router/index.ts:23`、`web/src/admin/routes.ts:3`。登录卡、工作台、设置分组、发布开关及表格采用 Zero4-UI 参考设计，适配明暗和移动端。
- `web/server/scripts/adminAccount.ts:1` 仅在服务机初始化或重置单管理员。后端以独立 SQLite 文件存储 `account(username,salt,hash)`、`sessions(token,expires)`、`configuration(data)`。密码使用随机盐和 scrypt，随机 256 位会话令牌仅存摘要，八小时到期。改密或重置事务内撤销全部会话。`web/server/lib/adminStore.ts:136`、`:211`，`web/server/lib/adminApi.ts:20`。Cookie 为 HttpOnly、SameSite=Strict、路径 `/api/admin`，HTTPS 下启用 Secure。修改接口校验来源、JSON 和专用请求头。
- 配置字段为 `revision / runtimeRevision / disabledSkills / settings / activeKey / keys`。写入带版本号，过期返回 409。技能限已注册的专业技能，通用智能体及内部开发技能不作为卡片上下架。首页、广场、表单深链、聊天选择器读取公开目录；入口不可达时显示空态。服务端在目录、网页入口和兼容入口统一验证发布状态，Pi 只加载显式声明的技能。见 `web/src/composables/catalog.ts:9`、`web/server/index.ts:290`、`:706`、`:785`、`web/server/lib/piRunner.ts:547`。
- 设置含默认模型、前台选模权限、思考档位、公众号报告使用优才时的可选专属档位、优才地址、两类任务超时及会话空闲回收。初始值继承部署配置，保存值持久化。CLI、目录、系统用户和数据库连接仍属于部署层。网页可选模型和默认值从健康接口取得。兼容 API 的 `skill` 字段语义保留，默认路由与网页一致。每轮固定一份配置，原运行完成后再应用凭据和进程配置变更，沿用工作目录及 Pi 的持久会话。见 `web/server/lib/adminStore.ts:154`、`web/server/index.ts:1128`。
- DeepSeek 有部署凭据和命名密钥两种来源，后台只返回命名密钥的 ID 和名称。使用命名密钥时，Node 为 Pi 进程开启独占的回环转发地址，只接收带随机路径的 Chat Completions POST。后端向固定上游加入选定凭据，拒绝重定向，沙箱参数、环境及 trace 不包含此命名 Key。Pi 退出时关闭转发。优才保留无认证调用。见 `web/server/lib/modelRelay.ts:8`、`web/server/lib/piRunner.ts:563`、`web/server/pi/youcai.js:6`。数据库及其备份包含可恢复的模型密钥，必须以服务账号私有权限保存。
- 全站 `/api/admin/runs` 从原索引读取，支持查询、分页、归档、恢复、删除索引和导出文件。无 trace 的旧记录显示已保存摘要。旧 `/api/runs` 返回 401。浏览器向对话、附件、恢复及 `/api/conversations` 发送本地随机能力值，服务器用摘要命名空间分隔公开会话，返回用户视图；其他能力值无法读写该会话。初版中旧数据没有浏览器归属，只在后台列出；当前读写规则见文末的共享测试会话修订。交付物链接仍按原协议分享。见 `web/server/index.ts:345`、`web/server/lib/browserHistory.ts:6`、`web/src/composables/browserHistory.ts:3`。Vite 禁止直接静态读取 server 目录，运行目录收紧为 0700，见 `web/vite.config.ts:25`、`web/server/lib/traceExport.ts:23`。

## 成本与取舍

SQLite 利用现有 Node 运行时，在单服务进程下持久化设置和登录状态。拒绝直接网页编辑 .env，其内容原本供低权查询工具读取，而且重启会干扰运行中的任务。密钥转发为每个使用命名凭据的 Pi 进程增加一个本地监听端口，换取真实密钥停留在服务端并避免 Pi 本地鉴权优先级意外覆盖选中的 Key。保留单管理员及匿名浏览器历史，避免猜测旧会话所有者或把前台演示手机号当作身份凭证。

## 后续扩展

若需要多人运营，再拆分账号与角色、增加个人操作审计。如果迁移到多实例，应把配置修订与会话进程编排统一到共享存储，并为密钥增加独立的密钥管理服务。公网 HTTPS 终止和进程托管由部署层配置。

## 历史阶段 · 共享只读对话（已被协作测试规则替代）

**状态与动机**：已实现。当前只有管理员有服务端账号。前台手机号登录保存在 localStorage（`web/src/composables/session.ts:3`）。原来的浏览器筛选让新浏览器看到零段对话，旧记录仍在运行索引。按用户要求，访客现在共享读取全部会话。

**读取与操作**：`GET /api/conversations` 和 `GET /api/conversations/:runId` 无需登录。读权限由入口判断，浏览器能力值只决定是否能操作此会话（`web/server/index.ts:313`、`:346`）。本浏览器仍可续聊、归档和删除。共享记录只发分组用的 `sharedKey`，隐藏真实会话标识、请求标识及工具执行内容，只提供对话正文、决策题和交付链接（`web/server/lib/browserHistory.ts:19`、`web/server/index.ts:475`）。完整运行留痕继续走管理员 API。

**展示与取舍**：侧栏分页取完整目录再分组，保留归档区域（`web/src/api/runsApi.ts:12`）。历史正文沿用原对话气泡，其他会话提示只读，可新建对话；窄屏增加历史入口（`web/src/pages/ExperiencePage.vue:976`、`:1112`）。保留浏览器范围的写权限，避免访客修改他人的归档、任务或工作区；新任务的输入区提示正文会出现在共享历史中。

**验证**：`cd web && npm run build` 通过。服务端和前端 composable 回归共 76 项通过，含共享读取、无原始文件权限、跨浏览器写操作被拒以及本浏览器归档后仍可在共享归档区看到记录。部署时将公网 API 的两页逐条对照运行索引，222 条一致。全新 Chrome 桌面显示 182 段会话，最早的会话可打开；390px 窄屏能打开历史、选择正文并收起侧栏。将来引入普通用户账号后再按真实账号归属和分享规则控制读取。

## 修订 · 测试人员共同续聊和整理会话

**状态与动机**：已实现。普通用户账号尚未上线，测试人员需要在另一浏览器继续原来的任务。先前只读分组只暴露摘要标识，无法定位真实 Pi 工作区或提交原问题的答案。

**当前约定**：公开会话接口返回 `clientSessionId`（旧索引缺失时以 `runId` 分组）、原始输入、`requestId`、问题和交付信息。网页读取到的会话可直接发消息、回答决策题、上传附件、继续中断任务或归档、恢复、删除。请求不以创建者身份授权；仍检查来源和会话路径。前缀仅用于新浏览器临时 ID 的命名及识别原浏览器的执行摘要。已登记的无前缀 ID 与旧 `web-…` ID 都复用原目录，兼容 API 也可用同一个 ID 续聊。见 `web/server/lib/browserHistory.ts:17`、`web/server/index.ts:190`、`web/src/pages/ExperiencePage.vue:738`。

**一致性与取舍**：`web/server/index.ts:359` 在执行或导出期间拒绝会话归档和删除，已有轮次互斥与过期回复检查仍然生效；归档会话继续收到的新轮次继承归档状态。保留 Pi 原生持久上下文。Pi 缺少历史时才以同组已保存的用户/助手消息、决策选项和交付链接补足首轮提示（`web/server/index.ts:1790`）；不重写旧索引，也不把 trace 当作公开下载。所有测试人员都能操作同一会话是当前产品选择。普通账号上线时再明确所有者与协作者，服务端独立授权。

**验证**：前端生产构建和 78 项回归通过。隔离 HTTP/SSE 验收从第二个浏览器标识上传附件、回答第一个标识创建的问题，核对相同引擎会话，覆盖过期回复、运行中拒绝归档/删除、归档续写、匿名恢复、兼容 API 续聊、跨浏览器删除及后台下载鉴权。全新 Chrome 在桌面与 390px 窄屏可打开其他浏览器创建的历史，桌面验证了可用的输入框、发送与归档操作。无 clientSessionId 且无 Pi 工作区的旧记录也可按原分组续聊，Pi 收到原消息转录。
