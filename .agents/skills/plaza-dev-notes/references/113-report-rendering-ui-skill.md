## 动机

## 职责和接口

- `.agents/skills/report-rendering/SKILL.md:12` 接受自由输入。Agent 理解内容后在工作区整理内部页面模型，不要求调用方改 schema。Markdown/TXT 可直接生成基础页面。新的 JSON 结构由 Agent 解释映射，脚本处理内部 title/blocks；这个内部结构不是对外 API。未知或不一致内容回查材料。`references/page-model.md` 定义通用元素和产教映射，未映射的有用内容需保留。
- `references/elements.md` 拆解标题、范围、摘要、指标、论证、图文、表格、摘录、限制、行动、来源。`references/tables.md` 采用 chart-visualization 的按问题选型方式，形成 key-value、comparison、composition、time、matrix、detail、action、evidence 八种表格。数字列、行列头、分母、缺测和窄屏滚动有独立规则。
- `assets/report.css` 提供公共组件，`assets/themes/paper.css` 与 minimal.css 提供 token 和主题布局。paper 以用户指定网页为依据；minimal 参考 zero4-ui 的排印与轻边框。`scripts/render.py:171` 支持内置主题和工作区 `--theme-css`，复制静态资源并原子发布到新目录。Markdown 使用 markdown-it-py，输入 HTML 转义；表格保留 0、null、空文本区别，内部行列不一致直接报错，已有修订目录不覆盖。
- `scripts/embed_chart.py:16` 从产教目录迁入共享渲染层，调用 chart-visualization verify 并取完整 figure。`scripts/render.py:86` 的 figure 块调用该函数，公开页保留原始 SVG、图注和数值表。样式只调整显示尺寸及滚动容器。原产教脚本保留 CLI 兼容入口，共享实现仍使用目录锁和原子替换支持重复与并行嵌图。
- 产教技能继续决定证据、结论和支撑判断的数据，完成 report.py build 后交接渲染。`web/server/lib/piRunner.ts:562` 同时挂载图表与渲染技能，`web/server/lib/skills.ts:141` 的逐轮提示指向共享层。旧绘图提示保留供历史剥离，`web/server/index.ts:357` 支持原后缀。四份原件、收据、网页发布检查与现有交付协议继续生效。
- 新 skill 作为内部共享能力进入仓库文档索引，产教入口可调用。`docs/index.md` 记录输入、元素、风格、方法来源和验收。组件样例、原始内部模型和实际主题页面在 examples/，示意数据明确标记。

## 成本与取舍

每个主题共用元素与内容，避免按业务复制模板。任意业务 JSON 的理解由 Agent 完成；程序自动猜字段含义会隐藏单位、范围和未映射的材料。渲染器只承担可重复的 HTML/CSS 组装，特殊布局允许直接使用组件 CSS 编写。主题数量可扩展，第一期提供两个可验主题。

图稿仍使用共享工具，渲染层不维护绘图库。纯文字成品无需凑图或指标。手机缩小整幅学术图会使标签不可读，因此按原图尺寸放大显示并在图幅区域滚动；图注和正文按屏幕排版。打印 CSS 提供分页基础，正式 PDF/Word 仍需另行导出与检查。

## 多样化图表选型

**状态**　已写入设计并更新可运行示例。用户要求报告尽可能使用多样化图型。`report-rendering/SKILL.md:20` 与 `references/chart-selection.md:5` 按比较、趋势、构成、分布、关联、变化、区间、矩阵、地域、流向和轮廓登记选型及数据前提。多图报告支持多种关系时组合图型，排版前复核全柱状图的原因；同类比较可以统一表达并在内部记录理由。颜色和横竖方向变化不算增加图型。

产教入口同步读取选型规范。主题和内部输入契约沿用现有实现，绘图仍交给 chart-visualization。独立出图脚本已支持的类型与仅有专题指南的类型分别说明，专题类型接入须先完善共享出图和复验。采用数据关系驱动的选型，舍弃固定图型配额，避免在单次快照中虚构趋势或由汇总值构造个体观测。
