## 动机

## 约定与接入点

- `web/scripts/skill-docs.mjs:26` 以 `docs/index.md` 作为收录条件。`:30` 扫描顶层技能与专业注册表，只读取有首页的技能及其同级专题。未写首页的技能可以正常安装、注册，已发布的 Markdown 继续校验格式和链接。三个原子模块已随 092 的后续迁移内置。
- `web/scripts/skill-docs-plugin.ts:47` 导出公开注册技能的 `{ [id]: boolean }` 文档可用状态。`web/src/pages/DetailPage.vue:53` 据此显示“技能文档”，详情页只加载状态表。读者打开已注册但无指南的书签时，`web/src/pages/SkillDocsPage.vue:157` 提供通用指南入口。
- `web/scripts/skill-docs.mjs:65` 解析同一份 Markdown，产出 `{ key, title, blocks, outline }`。正文片段按原顺序渲染，禁用原始 HTML。独立的 `prompt` 围栏作为文字块输出，原文中换行、缩进和尖括号都可复制。引用与命令沿用各自的 Markdown 语义。二级标题生成当前页的小节目录。
- `web/src/pages/SkillDocsPage.vue:73` 的左侧目录负责切换指南、技能和专题。`:131` 从当前文章的 outline 渲染独立的“本页章节”。宽度达到 1024px 时，它固定在正文右侧；较窄屏幕把同一组链接折叠在文章标题下。有章节时才分配这一栏。手机上的文档目录仍可单独收起。`web/src/router/index.ts:34` 处理 hash 路由下的小节定位。`web/src/pages/SkillDocsPage.vue:148` 为每个示例实例化项目已有的 Codebox，复制仅取该块文本。
- 网站随前端构建发布。项目级指南的原文为 `docs/guide.md:1`，`web/scripts/skill-docs.mjs:99` 复用技能文章的解析器生成小节、正文和可复制的终端命令。它单独列在文档首页与注册技能之间。旧 `#/guide` 经 `web/src/router/index.ts:26` 重定向到 `#/docs/guide`，内部技能继续从仓库索引进入。
- `web/scripts/docs-index.mjs:5` 从相同文档集合生成仓库索引，包含内部技能。维护者执行 `npm run docs:index` 一起提交索引；`npm run docs:check` 比较当前文件内容并验证公开页链接。写作流程见 [给技能写文档](../../../../docs/writing-skill-docs.md)。

## 成本与取舍

公开页随前端构建发布，线上更新需要发布新的静态文件。运行时从文件系统提供整棵技能目录会把阅读绑定到后端，并扩大可读文件范围。将每篇正文抄入 Vue 或数据注册表又需要双份编辑。当前约定只维护 Markdown，使用已有的 Vite、Vue 与 Markdown 依赖。

早期为三个子模块设置的配套文档目录已随技能迁入主仓库，后续只维护技能内的 docs。章节位置锚点按页内次序生成，调整标题顺序可能改变小节直链，技能与专题的地址由文件名决定。

项目 `AGENTS.md` 要求开发技能时随实现提交有实际用例的 `docs/index.md`，共享基础组件也遵循此约定。加载器继续兼容缺少首页的历史条目。添加首页时整组文档进入索引，移除首页时整组撤下。开发服务按公开技能以 500ms 间隔检查各自 docs 目录的状态，目录存在时监听其文件修改。新增整棵技能目录也能被发现，无需递归扫描技能资源。实现见 `web/scripts/skill-docs-plugin.ts:9`。

导航参考分层侧栏与独立的页内目录。示例块的复制按钮常态可见，作者明确标记可运行的提问，读者可以先看输入条件，再复制原文。[VitePress 侧栏](https://vitepress.dev/reference/default-theme-sidebar) · [Starlight 文档结构](https://starlight.astro.build/guides/authoring-content/) · [Docusaurus 示例复制](https://github.com/facebook/docusaurus/blob/main/packages/docusaurus-theme-classic/src/theme/CodeBlock/Buttons/CopyButton/index.tsx)
