# 数据约束的结构分析与适用图型

状态：已实现，六种真实范围经现有Pi/Qwen原生工具完成写作和完整构建；程序检查与人工图片自查通过，用户内容和审美验收待进行。

动机：自由长篇解释会把学历标签、薪酬和词频误写成技能深度、能力回报或真实录用。只加禁词会误伤合理限定句，且不能保证缺失子样本和单城报告口径一致。

约定：`wechat-report/scripts/analytical_reasoning.py:1`采用wechat-analytic-reasoning/1；结构分析、核心标题、事实选择和总体判断由当前保存数据与明确规则计算，模型保留行动、验证、调整条件、决策启示与综合启示。`report_analysis.py:1`装配时重新计算保护字段并严格核验，不能通过旧稿改标题绕过。不是用模型文案冒充数据分析。

`joint_findings.py:1`同时保留完整样本和已分类子集分母，比较学历组内经验、城市入门条件覆盖、入门薪酬分位及方向能力提及率。缺失职教池不生成零覆盖；实测空池仍可说明交集为空。薪酬、学历、频率、LQ不能单独推断因果、技能深度或录用概率。

`collect_data.mjs:24`在首次查询前固定overview和geography必要指标，不扩大用户筛选。可选--profile只填已声明产业的分析规则，须核对共享字典唯一根节点及明确的产业ID；不硬编码智能制造旧ID。`industry_profiles.json:1`是公开关键词分类规则而非官方产业标准。`report_preflight.py:5`在写作和构建前检查真实必需字段。`chart_recommender.py:1`记录wechat-chart-selection/2适用决策：单城不强行生成跨城图，单学历不做伪对照，最多一张薪酬×城市×学历份额×岗位数的柱状组合图，岗n与薪n分别可见。缺失值不补零。

`web/server/pi/report-workflow.js:1`将report_submit与report_core分开，按阶段限制真实工具参数；写作阶段关闭额外思考，取数规划仍沿用原模型设置。完成或构建失败后结束该阶段，保留原计费、流式、取消和最多两次有限继续。最终构建回执记录当前安装Python文件和输入指纹。

验证：共享取数72项、报告25项、服务端60项检查及前端构建通过。广东/山东/浙江/江苏人工智能、深圳硕士限定和广东智能制造均真实调用安装代码。单城无职教池保持原条件产出，不重复补查或伪造职业入口。完整首次智能制造样本八万余条约四分三十九秒，其中统计约二分三十八秒；已有数据写作构建实测约一分钟级，不能混称为所有冷请求速度。

成本与取舍：受信规则降低自由因果故事的风险并提高Qwen短批次稳定性，但仍是横截面岗位样本解释，不替代企业调查或多期趋势。模型只写可验证提案，不能据此保证课程结果。否决只靠提示词、放宽筛选和把缺失值填零的方案。

后续：按用户成品反馈改进图文密度和分析规则；需要纵向趋势或课程效果时另接独立证据，不能从当前快照推断。
