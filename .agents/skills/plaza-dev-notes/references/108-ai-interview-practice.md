## 动机与设计依据

旧入口用一段回落提示词驱动模拟。表单固有的题量、语言、练习模式缺少对应的行为约定，表单还展示了未实际接入的示例题库。需要让每道题考察明确的岗位任务，也需要让学生从复盘看出哪部分是自己已经讲清的，哪部分仍然缺证。

## 成本与取舍

练习在现有 Pi 对话中完成。网页可以直接在聊天框作答，出现自由输入卡时也可在卡内作答。兼容 API 使用自然语言。题目、追问和复盘沿用同一会话，不增加报告文件、评分数据库或新协议。放弃展示虚拟企业题库，也不采用产品参考中的音频指标、综合奖章或排名。参考资料用于设计，教材、简历和岗位事实只取自本次练习材料。

语言模型可以针对上一句灵活出题，但“题号/总题数”、单一观察点和评价边界都是语言约定。若后续要把题量用于正式考核或跨考生比较，须独立记录题目作答状态、确定评分样例，并由岗位教师校准。
