# 使用技能广场开发手记

维护者在修改运行链路、技能接入或前端协议前，可先查手记中已有的决定，再用当前代码核对接入点和验证状态。

## 开始改动前

打开手记的记录索引，按主题定位。例如要新增一个广场技能，先读 048 核对公开清单的来源，再按交付类型查对应记录。看到「待验证」时，把这一项列入本次可执行的验收范围。

## 留下一条可复用的记录

同一决策有变化时更新原记录。形成新决策时，取索引中注明的下一个编号，在 references 下新增一份文件，并把它加入相应分区。记录中说明动机、协议或字段、实际代码位置、成本与取舍，以及下一步。验证部分写明执行过的命令、结果和仍待验证的事项。
